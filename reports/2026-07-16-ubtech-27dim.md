## D1 — 执行摘要

优必选（9880.HK）是全球**首家年交付超千台全尺寸人形机器人的上市公司**。FY2025 收入 ¥20.01 亿（+53.3% YoY），其中人形机器人收入 ¥8.21 亿（+2,203.7%），超越传统教育机器人成为第一大收入来源。Walker S2 工业人形机器人已进入比亚迪、富士康、Airbus、西门子等产线，年化产能超 6,000 台。

**核心矛盾**：人形机器人赛道爆发力极强（全球 1,079 台交付创纪录），但公司仍深度亏损（¥7.9 亿净亏损）、R&D 强度 25.4%、估值承压（HK$83.55，较 IPO 价大幅下跌）。居家养老是其「故事线」之一，但距离实际收入贡献尚远。

| 关键指标 | 数值 |

| FY2025 收入 | ¥20.01 亿（+53.3%） |

| 人形机器人出货 | 1,079 台 |

**总体判断**：🟢 工业人形机器人全球第一梯队——交付量、客户质量、产能均领先。🟡 但居家养老非核心、深度亏损、估值承压。对 iHomeCare 的近期价值有限，远期价值取决于消费级人形机器人何时达到可部署阶段。

## D3 — 战略定位

### 一句话核心逻辑

**「工业人形机器人是第一战场——用比亚迪/Foxconn/空客的产线验证技术，再用规模化降本曲线把价格打到 ¥20,000 消费级，最终渗透养老、教育、家庭服务。」**

### 战略差异化

| 维度 | 定位 |
|------|------|
| **技术路线** | **全栈自研**——伺服驱动器、SLAM、大模型（Thinker）、BrainNet 群体智能、灵巧手——不做单点技术依赖 |
| **商业模式** | 工业 B2B（主力收入）→ 消费级 B2C（远期增量）→ 养老 B2G（政策驱动）三层递进 |
| **核心壁垒** | 人形机器人全栈 + 全球首个千台交付 + 6,000 台年产能 + 2,900+ 专利 |
| **竞争差异化** | vs 特斯拉 Optimus：优必选已交付 1,000+ 台（特斯拉未量产）；vs 宇树：优必选聚焦工业→消费全链路（宇树偏科研/开发者） |

### 战略演变三阶段

- **Phase 1 (2012-2022)**：从教育机器人起家 → Walker 人形机器人技术储备 → 港交所上市
- **Phase 2 (2023-2025)**：Walker S 系列进入汽车制造产线 → 千台交付里程碑 → 人形机器人超越教育成为第一大收入
- **Phase 3 (2026-)**：工业规模化（万台级目标）→ 消费级人形 ¥20,000 价位 → 养老/家庭渗透 → 海外扩张（Airbus/西门子/德州仪器）

## D8 — 工作流/旅程映射

### Walker S2 工业部署旅程

```
Phase 0: 场景评估
  └→ 客户产线评估 → 识别可自动化工作站 → 方案设计

Phase 1: 部署+训练
  └→ 3D 语义建图（VSLAM）→ 工作站任务编程（Thinker-VLA）
  └→ 数据采集（手持设备）→ 模拟训练（ISAAC 仿真）

Phase 2: 单机运行
  └→ Walker S2 自主导航到工作站
  └→ 视觉识别工件 → 灵巧手抓取 → 完成任务
  └→ 3 分钟自主换电 → 24 小时连续运行

Phase 3: 群体智能
  └→ BrainNet 2.0 调度多台 Walker → 多工作站协同
  └→ Co-Agent 工业协作智能体 → 生产级任务链

Phase 4: 持续优化
  └→ 数据回流 → Thinker 大模型优化 → OTA 升级
  └→ 产线效率监控 → 工作站增量扩展
```

## D16 — 对 iHomeCare 战略建议

### 直接竞品相关性：🟡 中低

优必选的康养产品（WELLI/WASSI/PATHFYNDER）目前贡献微小，但其 **技术平台** 值得 iHomeCare 关注：

1. **消费级人形机器人路线图**：优必选的 ¥20,000 价位消费人形是行业最激进的定价——如果成功量产，将对居家养老场景产生颠覆性影响。iHomeCare 应密切关注其 2026-2027 年消费级出货数据。

2. **Thinker 开源大模型**：具身智能大模型开源 → 任何开发者可基于它开发养老场景应用。iHomeCare 可评估是否接入 Thinker 做 HaH 场景的机器人控制。

3. **国家养老试点参与者**：优必选已入选国家养老机器人试点，了解其试点数据（200 台/200 户）对理解中国养老机器人政策方向有价值。

4. **「工业反哺消费」逻辑**：优必选的路径是先用工业场景打磨技术+降本（54.6% 毛利率），再下沉消费市场——这是中国硬件公司的经典策略，已被大疆/小米验证。
