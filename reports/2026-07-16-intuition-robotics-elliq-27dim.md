## D0 — 赛道真实性验证

**🚨 赛道定位**：Intuition Robotics 是 **AI 社交陪伴机器人**公司，**非**急性 HaH / 临床护理 / 物理辅助机器人。ElliQ 属于桌面式主动 AI 陪伴设备，核心价值主张为「减少孤独感 + 促进健康行为 + 连接家人」，不涉及任何临床诊疗、生命体征监测诊断或护理操作。

| 维度 | 判断 |
|------|------|
| 是否属于居家护理机器人？ | ✅ 是——但属于「社交陪伴 + 健康促进」子类别 |
| 是否属于医疗设备？ | ❌ 否——明确标注 consumer device, not medical device |
| 对 iHomeCare (HaH) 直接相关性 | 🟡 中低——非临床竞品，但作为「患者参与层」技术借鉴价值高 |

## D1 — 执行摘要

Intuition Robotics 是全球 **AI 老年陪伴机器人** 赛道的绝对领先者。旗舰产品 ElliQ 已在美国多个州政府老龄机构实现规模化部署（834 户活跃 + 3,500+ 等候名单），临床证据链完整——95% 孤独感降低、CSAT 4.6/5、日均 41 次交互——且已突破 Medicaid 报销壁垒（华盛顿州）。

**核心矛盾**：临床证据与用户满意度均属顶级，但公司仍处于早期商业化阶段——收入规模小（估 ~$1,500 万/年）、盈利路径不清晰、依赖政府合同作为主要收入来源。Toyota/Woven Capital 的战略投资暗示更深层的出行/服务生态整合，但尚未兑现。

| 关键指标 | 数值 |

| 员工规模 | 估 50-100 人 |

**总体判断**：🟢 赛道龙头 + 临床证据最强 + 政策通道已开。🟡 但规模小、盈利未验证、非 iHomeCare 直接对标。

## D3 — 战略定位

### 一句话核心逻辑

**「老龄化社会最大的流行病不是癌症，是孤独——用 AI 重建人与人的连接，从陪伴切入，逐步渗透健康管理和医疗支付体系。」**

### 战略差异化要素

| 维度 | 定位 |
|------|------|
| **产品形态** | 桌面式主动 AI 陪伴（非人形、非动物型、非屏幕-only） |
| **核心差异** | **主动性**——ElliQ 主动发起对话、建议活动、记住用户偏好，不同于被动应答的 Alexa/Google Home |
| **目标人群** | 75+ 独居老人，80% 女性（基于 NYSOFA 数据） |
| **付费方** | 政府（AAA/B2G）→ 医保（MCO/B2B）→ 消费者（B2C） 三层递进 |
| **技术壁垒** | 专有 AI 算法实现长期互动关系建模 + Cobot 量表（行业首个陪伴机器人 PRO 指标） |

### 战略演变三阶段

- **Phase 1 (2015-2021)**：Crowdfunding → Beta 测试 → 证明「老人愿意和机器人说话」
- **Phase 2 (2022-2025)**：NYSOFA 政府合同验证 → 规模部署 834 户 → 临床证据积累 → 多州扩张
- **Phase 3 (2026-)**：Medicaid 报销 → MCO 渠道 → 日本扩张（Kanematsu） → 从「陪伴」升级为「健康结果驱动」的价值付费模式

## D8 — 工作流/旅程映射

### ElliQ 用户旅程

```
Phase 0: 需求触发
  └→ 独居/孤独感 → AAA case manager 筛选 → 推荐 ElliQ → 申请

Phase 1: 部署与引导
  └→ 上门安装（1 小时） → 初始引导对话 → 学习用户偏好

Phase 2: 日常交互（持续）
  └→ ElliQ 主动发起每日对话
  └→ 健康检查（睡眠、心情、用药提醒）
  └→ 认知游戏 / 体能活动引导
  └→ 建议与家人视频通话
  └→ 记录生活记忆（数字回忆录）

Phase 3: 行为改变
  └→ Wellness Coach 设定目标（每周活动）
  └→ 渐进式增加活动量（50% 主动升级目标）
  └→ 生物反馈循环：目标 → 完成 → 庆祝 → 新目标

Phase 4: 家属/护理团队连接
  └→ Caregiver App 接收通知（用药遗漏/行为变化）
  └→ 家属发送消息/照片/视频
  └→ 多家属协调功能

Phase 5: 持续优化
  └→ 每 3-4 周软件更新
  └→ 根据交互数据个性化内容推荐
```

### 盈利路径

- **短期（1-2 年）**：政府合同规模效应——每增量州部署降低单位安装成本，政府合同年续约率预估高（>90%）
- **中期（3-5 年）**：MCO 价值付费——从「按设备收费」升级为「按健康结果收费」；若证明降低 ER 就诊/住院，人均节省 $1,000-3,000/年
- **长期（5+ 年）**：消费者 + 国际市场——日本（Kanematsu）、欧洲老龄市场

**综合判断**：商业模式具备单位经济改善路径（硬件成本 ↓ + 政府合同规模 ↑ + MCO 价值付费 ASP ↑），但当前亏损且需持续融资。

## D16 — 对 iHomeCare 战略建议

### 对 iHomeCare 的直接竞品相关性：🟡 中低

ElliQ 不做临床护理，不做急性 HaH，不做生命体征监测。但它作为**患者参与层**的技术路线对 iHomeCare 有借鉴价值：

1. **主动交互设计**：ElliQ 的核心壁垒不是 AI 本身，而是「何时发起对话」的时机判断——这对 iHomeCare 的远程患者监测（RPM）中的依从性至关重要。患者不打开 App，提醒就无用。

2. **长期行为改变机制**：Wellness Coach 60% 的 3 月留存率远超行业平均——iHomeCare 可借鉴其「目标设定 → 渐进升级 → 社交庆祝」的行为改变循环。

3. **家属连接层**：Caregiver App 的设计思维——让家属成为患者坚持治疗的外部动力——直接适用于 HaH 场景。

4. **政府合同获取路径**：NYSOFA 的案例对 iHomeCare 进入香港 HA/SWD 合同有参考——先小规模试点 → 收集临床证据 → 两年后要求续约 + 扩展。

## D26 — 销售与 GTM 效率

| 子维度 | 评估 |
|---------|------|
| **GTM 模式** | 三层 GTM：(1) **B2G 直销**——创始人/CSO 直接对接州老龄局决策者，政府 RFP 驱动；(2) **B2B 合作伙伴**——通过 AAA 网络逐步渗透，MCO 渠道通过行业会议和试点；(3) **B2C 数字营销**——elliiq.com 官网直销，依赖内容营销（博客：老人故事、孤独感科普）和 PR（NYT、Fast Company 等媒体报道） |
| **销售团队结构** | 估 10-15 人。政府 BD 团队（4-6 人，负责州级 RFP + 项目续约）+ MCO BD（2-3 人，新渠道开发）+ 客户成功（3-5 人，部署 + 培训 + 持续支持） |
| **CAC（政府渠道）** | 极高——完整政府周期 18-24 月：发现机会 → RFP 响应 → 试点（6-12 月）→ 续约谈判。隐含 CAC 估 $50,000-100,000/州合同 |
| **CAC（消费者渠道）** | $250 设备价基本覆盖硬件成本。获客主要依靠：(1) 媒体报道的自然流量 (2) 政府项目接触的家属转化 (3) 口碑推荐 |
| **LTV/CAC（政府）** | 估 3-5x：合同年值 $600-1,200/设备 × 834 设备 × 90%+ 续约率 × 3-5 年 = 总 LTV ~$150-500 万/州，相对 CAC $5-10 万/州 |
| **CAC 回收期** | 政府渠道：首年亏损（安装成本高），续约年开始回收。约 18-24 月回本 |
| **平均销售周期** | 政府：18-24 月（从初接触到首台部署）；MCO：6-12 月；消费者：即时（在线购买） |
| **赢单率** | 政府 RFP：推测较高——ElliQ 在老年陪伴类别中几乎没有直接竞品能提供同等临床证据 |
| **NDR（净收入留存）** | 估 >100%——政府合同续约率高（"we can't wait to see this program continue to grow" — NYSOFA Director），且新州加入带来增量 |
| **渠道伙伴经济** | Kanematsu 日本合作：未公开分成比例。推测 Intuition Robotics 提供技术平台 + 品牌，Kanematsu 利用 20,000+ 医疗/养老渠道分销 |
| **GTM 瓶颈判断** | 🚨 **漏斗顶部是瓶颈**——政府 RFP 周期长且可预测性差，不完全是 leads 不够（3,500+ 等候名单证明需求旺盛），而是政府预算审批速度慢。消费者渠道定价已足够低（$250+$30/月），但缺乏主动获客引擎 |

### GTM 阶段诊断

**规模化初期**——产品市场契合已验证（94% 孤独感改善、4.6/5 CSAT），核心挑战是：
1. **政府合同转化速度**：如何将 3,500+ 等候名单转化为实际部署（受限预算而非需求）
2. **MCO 渠道从 0 到 1**：首个 MCO 合同已签，但需要证明健康结果 ROI 才能规模化
3. **消费者渠道激活**：$30/月的定价已足够低，但未做大规模数字营销投放

### GTM 效率改进建议

| 方向 | 当前 | 建议 |
|------|------|------|
| 政府渠道 | 逐个州攻克 RFP | 推动联邦层面政策（孤独感法案）→ 释放全国预算 |
| MCO 渠道 | 试点阶段 | 与 MCO 做共享节约协议——从 CMS 节省中分成 |
| 消费者渠道 | 被动获客 | 与 Medicare Advantage OTC 福利合作——让 MA 计划为会员支付 ElliQ 订阅 |
