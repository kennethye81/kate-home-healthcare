# 重庆市长护险政策清单
**数据截止**：2026年6月30日 | **来源**：重庆日报 + 中国网 + 重庆市医保局

---

## 直辖市概况

| 维度 | 内容 |
|:----|:------|
| **试点启动** | **2019年**（国家第二批试点） |
| **覆盖范围** | 全巿统筹 |
| **当前状态** | ✅ **已全面运行** |

### 时间线

```
2019年 ─ 长护险开始在重庆试点
        待遇享受范围：重度失能人员

2024年3月1日 ─ 将中度失能人员也纳入待遇享受范围

2026年 ─ 试点6年，近10万人受益
```

### 核心数据

| 指标 | 数据 |
|:----|:----:|
| 累计受益人数 | **近10万人**（截至2026年4月） |
| 中国人寿经办6区县(渝中/璧山/开州等) | 累计支付**18.81万人次** |
| 待遇享受范围 | 重度+中度失能 |
| 职工医保缴费要求 | 累计缴满**15年**（含视同缴费年限） |
| 2026年缴费基数(个人身份) | 62,100元/年（5,175元/月） |
| 创新模式 | **璧山区网格化+智能筛查** |
| 经办模式 | 引入商业保险机构（如中国人寿） |
