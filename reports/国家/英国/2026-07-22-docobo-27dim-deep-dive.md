## D1 — 执行摘要

**定位**：📡 **英国 NHS 远程患者监测 (RPM) 先驱**——2001 年创立，DOC@HOME 平台支持 17+ 临床路径（心衰/COPD/糖尿病/MND/癌症/术后/卒中康复等）。2021 年 11 月被 Graphnet Health 收购，整合进 CareCentric 人口健康平台。客户含 Kent Community Health、Liverpool CCG、East London NHS FT、Tameside and Glossop 等。

**核心矛盾**：Docobo 的技术 DNA 已融入 Graphnet 生态——品牌正在消失，但在更大平台上延续。作为独立公司的评估意义有限，但其 NHS 框架准入路径值得研究。

**关键数据速览**：

| 指标 | 数值 | 来源 |
|---|---|---|
| 创立 | 2001 | HTN 2021 |
| 创始人/ MD | Adrian Flowerday | HTN 2021 |
| 收购方 | Graphnet Health（System C Care Alliance） | HTN 2021.11 |
| 收购时员工 | 50+ | HTN 2021 |
| 产品 | DOC@HOME → Graphnet RPM powered by Luscii | Graphnet 官网 |
| 临床路径数 | 17+（心衰/COPD/糖尿病/MND/癌症等） | Graphnet 官网 |
| NHS 认证 | GP IT Futures framework / MESH accredited | NHS Digital |
| 客户 | Kent/Liverpool/East London/Tameside 等 5+ NHS 组织 | 公开资料 |

**总体判断**：🟡 **技术参考价值中等**——Docobo 证明了 NHS 环境下 RPM 技术可行性，但作为被收购的小公司（50 人），深度数据极为有限。

## D3 — 战略定位

**核心逻辑**：**"远程监测不是孤立工具，而是人口健康管理的入口。"**——Graphnet 收购 Docobo 的战略：用 CareCentric 人口健康平台识别高风险患者→用 DOC@HOME 远程管理→减少非计划入院。

**战略差异化要素**：

| 维度 | Docobo（Graphnet） | Luscii | Current Health | Whzan |
|---|---|---|---|---|
| 人口健康集成 | 🟢 CareCentric 整合 | 🟡 独立 | ❌ | ❌ |
| NHS 框架认证 | 🟢 GP IT Futures + MESH | 🟡 | ❌ | 🟡 |
| 临床路径数 | 🟢 17+ | 🟢 84+ | 🟡 | 🟡 |
| 虚拟病房 | ✅ | ✅ | ✅ | ✅ |
| 独立运营 | ❌ 已收购 | ✅ 独立（但现为 Graphnet 伙伴） | ✅ | ✅ |

**战略演变三阶段**：
1. **Phase 1 (2001-2020)**：独立 RPM 技术公司——慢速建立 NHS 客户基础
2. **Phase 2 (2021-2024)**：融入 Graphnet 生态——CareCentric + DOC@HOME 协同
3. **Phase 3 (2025+)**：品牌退出——技术并入 Graphnet RPM，Luscii 成为技术伙伴

## D4 — 商业模式架构图

```
Graphnet CareCentric（人口健康平台）
  │
  ├── 识别高风险患者队列（预测性分析）
  │
  ▼
DOC@HOME / Graphnet RPM（远程监测层）
  ├── 患者端：App + 可穿戴设备
  ├── 临床端：Dashboard + 预警算法
  └── 通信：文本 + 视频消息（医患双向）
        │
        ▼
NHS 客户
  ├── Integrated Care Systems (ICS)
  ├── Community Trusts（社区托管）
  ├── ICB（前 CCG）
  └── Care Homes（养老院）
```

### 收入模式
- **B2G（政府对公）**：NHS 框架合同（GP IT Futures）→ 按 license/seat 收费
- 被收购后财务不独立——通过 Graphnet 的 NHS 合同间接变现
- **对 iHomeCare 启示**：进入政府框架（如香港 HA 采购清单）是 B2G 商业模式的核心壁垒

## D8 — 工作流/旅程映射

```
Phase 0 — 患者识别
  CareCentric 分析人口健康数据 → 标记高风险患者
        ↓
Phase 1 — 入组与设备部署
  临床团队邀请患者 → 配送监测设备 → App 下载
        ↓
Phase 2 — 日常监测
  患者每日自测（BP/SpO2/体重/症状问卷）
  → 数据自动上传 DOC@HOME 平台
  → 预警算法分析异常
        ↓
Phase 3 — 临床干预
  Dashboard 显示异常 → 临床团队评估
  → 双向通讯（文本/视频）→ 调整用药/安排面诊
        ↓
Phase 4 — 持续管理
  长期数据追踪 → 趋势分析 → 预防性干预
  减少非计划入院和急诊访问
```
