## D0 — 赛道验证（中国居家护理/长护险赛道）

### 赛道规模与结构性验证

| 指标 | 数值 | 来源 |

| 2026年长护险全国建制 | **2026年3月发文，3年全覆盖** | 中办/国办 |

### 赛道结构特征

1. **居家养老为绝对主流**：中国超90%失能老人选择居家养老，机构养老床位空置率约50%，居家护理赛道空间巨大。
2. **长护险从试点走向全国建制**：2026年3月25日中办国办发文《关于加快建立长期护理保险制度的意见》，3年内（至2028年底）实现全国全覆盖，为居家护理企业带来系统性红利。
3. **极度分散的市场格局**：中国居家护理市场由数千家地方性服务机构组成，尚无全国性龙头企业市占率超5%，头部整合空间巨大。
4. **人力成本低但快速上涨**：养老护理员平均月薪3,000–4,999元，远低于发达国家，但每年以5-10%速度上涨。
5. **政策驱动为主，自费渗透率低**：市场目前主要依赖长护险基金和政府购买服务，个人自费居家护理市场仍处于早期培育阶段。
6. **三源支付模式**：长护险基金 + 政府补贴 + 个人自费；未来全国建制后支付端将更为稳定和标准化。

### 赛道判断

**✅ 中国居家护理赛道验证通过** — 确定性人口驱动（老龄化不可逆）、长护险全国建制提供支付基础、极度分散市场提供整合空间、>90%居家选择率确保需求场景。福寿康作为中国最大居家护理企业之一，处于赛道核心生态位。

## D3 — 战略定位

### 核心战略要素

1. **长护险深度绑定政府**：作为各地长护险定点服务机构，深度嵌入政府购买服务体系，是收入基本盘
2. **全国化网络扩张**：从上海向全国61城市复制服务模式
3. **服务产品化与分层**：在长护险基础服务之上开发自费增值服务，提升ARPU值
4. **智慧养老平台赋能**：通过技术手段提升服务管理效率、保障服务质量和数据可追溯

### 支付机制特点

- **长护险服务给付制**：中国长护险以服务给付为主（不直接发放现金），确保护理服务需求直接转化为企业收入
- **政府统一定价**：长护险护理服务单价由各地医保局统一制定，企业议价空间有限
- **回款周期**：政府回款通常30-60天，对企业现金流管理提出要求
- **个人自付比例低**：与发达国家（20-40%自付）相比，中国长护险自付比例较低（约20-30%），用户价格敏感度受保护

|------|------|---------------|
| **护士** | 家庭巡诊、护理员管理、客户评估 | 核心医疗监督角色——负责上门巡诊、评估客户健康状况和失能等级、指导并管理护理员团队 |

### 使用者旅程（以上海长护险居家护理为例）

```
【认知/触发】
  家人失能 / 住院出院 / 社区通知
        │
【申请长护险评估】
  向社区事务受理中心申请 → 评估机构上门评估（Barthel指数等）
  → 确定失能等级（1-6级，对应长护险待遇）
        │
【选择福寿康】
  长护险定点机构列表中选福寿康 → 签约
        │
【制定护理计划】
  福寿康护理经理上门评估 → 制定个性化护理计划
  → 匹配护理员 → 确定服务频次
        │
【日常运营】
  护理员按计划上门（通常15-20次/月，每次45-60分钟）
  服务内容：生活照料（洗澡/更衣/协助进食）+ 基础护理（测体征/用药指导）
  服务打卡 → 系统记录 → 服务评价
        │
【月度结算】
  福寿康向医保局申报服务记录 → 长护险基金拨付
  个人自付部分按月向用户收取
        │
【护理等级变更】
  健康状况变化 → 重新评估 → 护理计划调整 → 费用变更
        │
【终末期/转机构】
  健康状况恶化 → 转至医院或护理院
  或：康复 → 减少服务频次
```
