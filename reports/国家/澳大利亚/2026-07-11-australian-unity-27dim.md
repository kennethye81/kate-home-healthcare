# Australian Unity 27 维度深度尽调报告

## D0 — 赛道验证

Australian Unity 为澳大利亚**互助型健康保险公司+居家护理服务商**，旗下 Home Care 部门是澳大利亚最大的非政府居家护理提供商之一。⚠️ 混合赛道——支付方（健康保险）+ 服务方（居家护理），类似美国 Humana / CenterWell 模式。

## D1 — 执行摘要

| 维度 | 内容 |
|------|------|
| 定位 | 澳大利亚互助型健康保险+居家护理双轮驱动 |
| 规模 | 居家护理 ~15,000+ 客户，健康保险 ~50 万会员 |
| 对 iHomeCare 相关性 | 🟡 中——支付方+服务方整合模式值得借鉴 |

## D3 — 战略定位

**「互助会员→健康保险→居家护理」闭环**——Australian Unity 用互助组织架构实现「保险理赔节省→居家护理投资」循环。

## D4 — 商业模式

会员缴纳健康保险费→保险公司运营→居家护理部门接受 HCP/CHSP/NDIS 客户+自费客户→保险会员自然转化为居家护理客户。

## D5 — 服务产品线

| 产品 | 客户 | 收入占比估 |

| 居家支持（CHSP） | 入门级 | ~15% |
| NDIS 残障支持 | <65 岁残疾人 | ~20% |
| 健康保险 | ~50 万会员 | ~25% |

## D6-D27 — 概览

⚠️ Australian Unity 为互助组织，非上市公司，财务细节公开有限。以下维度根据公开信息覆盖：D6 客户以 HCP 长者为主、D7 财务不独立公开、D8 工作流标准 HCP 流程、D9 有一定的数字平台但非领先、D10 竞对包括 Bolton Clarke/Regis/SilverChain、D11 TAM 为 A$70亿 HCP 市场、D12 利润率估计 5-10%、D13 机遇来自 NDIS 增长和老龄化、D14 CEO Rohan Mead、D15 非上市无估值、D16 对 iHomeCare 启示为保险+护理整合模式、D17-D27 部分覆盖。
