## D0 — 赛道验证

### 赛道定义
百本医护的核心赛道是**医护人力资源解决方案（Healthcare Staffing Solutions）**，属于香港居家医疗生态体系的上游基础设施层。该赛道与 Hospital-at-Home（HaH）有间接但关键的关联——任何 HaH 服务商都依赖可灵活调配的专业医护人力网络来支撑居家急性护理的交付。

### 赛道规模与增长
- 香港注册护士总数约 60,000 人（来源：香港护士管理局 2024 年报），但公立医院体系长期面临 10-12% 空缺率
- 安老服务需求：2024 年约有 74,000 名长者在政府资助长期护理服务轮候册上，院舍轮候时间中位数 24 个月
- 65 岁以上人口占比预计从 2024 年的 21% 升至 2040 年的 33%（来源：香港统计处《香港人口推算 2024-2046》）
- 医护人力派遣市场年规模估值约 HK$2-3 亿（基于百本 + 竞品收入推断）

### 赛道结构性驱动因素
1. **人口老龄化**——不可逆的结构性需求增长
2. **院舍供给瓶颈**——24 个月轮候→居家护理成为"被迫刚需"
3. **公立医疗人力短缺**——持续外判机构护理需求
4. **自雇经济兴起**——32,000 名医护选择灵活工作模式

### 赛道限制因素
1. **纯中介模式的低附加值**——27.6% 加价率在服务业中偏低
2. **人力供给天花板**——香港医护人才池有限
3. **技术替代风险**——数字健康平台可能绕过传统人力中介

### 赛道验证结论
✅ 百本处于香港医护人力市场的结构性增长赛道，与 HaH/居家医疗生态高度相关，但核心业务是**人力匹配而非临床服务交付**。对 iHomeCare 而言，百本的医护网络是潜在的人力供给渠道，而非直接竞品。

## D3 — 业务模式

### 商业模式画布

| 模块 | 描述 |
|------|------|
| **价值主张** | "关怀备至、专业实干、全心全意"——为医疗机构和个人提供及时、专业、灵活的医护人力方案 |
| **医护端** | 平台聚合 32,000 名自雇医护（护士/物理治疗师/护理员/保健员等），提供灵活工作机会 |
| **客户端** | 医院、安老院舍、社福机构、诊所、企业、个人家庭的医护人手需求 |
| **收入机制** | 差价模式——客户收费与医护付费之间的加价率约 27.6% |
| **服务交付** | 平台撮合 → 医护到岗 → 按小时/天计费 → 百本抽成 |
| **关键资源** | 32K 医护池 + 品牌信任 + 机构客户关系 + 牌照资质 |

### 收入结构三层拆解（FY2025）

**第一层：医护人手解决方案（82.9% 收入，HK$61.7M）**

| 子类别 | 收入 | 占比 | YoY |
|--------|:----:|:----:|:---:|
| 机构人手方案 | HK$35.2M | 47.3% | -26.2% |
| 私家看护方案 | HK$26.5M | 35.6% | -10.5% |

- **机构人手**：为公立/私家医院病房、安老院舍提供临时/轮替人手
- **私家看护**：24 小时上门护理、陪诊、居家照护（个人客户）

**第二层：外展个案评估 + 疫苗接种（~14.9%，~HK$11.1M）**
- 到校/社区/团体疫苗接种
- 境外游学团随团医护
- 健康专题讲座

**第三层：其他（~2.2%，~HK$1.6M）**
- 商品销售（保健产品 BamBoOs! Life）
- 诊所服务
- 广告收入、租金收入、股息收入

### 战略转型：healtHUB 健康生态系统

百本近年核心叙事从"医护人力派遣商"转型为「科技+创新」赋能的**一站式医疗健康及智慧居家服务平台**，提出覆盖六大环节：

```
预防 → 治疗 → 康复 → 居家照护 → 智慧养老 → 适老化生活
```

整合三大服务板块：
1. **预防医学**——疫苗接种、健康筛查
2. **中西医疗**——自营诊所、医护网络
3. **智慧养老及适老化生活解决方案**——复康器具、家居改装

### 业务模式评估

| 优势 | 劣势 |
|------|------|
| 轻资产、高现金流 | 低加价率（27.6%） |
| 32K 医护网络壁垒 | 收入依赖人力中介（83%） |
| 机构客户粘性高 | 新技术业务落地证据不足 |
| 不受医保控费影响 | 增长天花板明显 |

### 合作生态评价

- **公共医疗系统深度绑定**：HA 医院是最核心的客户群，这既是壁垒也是风险——公立预算削减直接影响百本收入
- **政府合同是亮点**：入境处 3 年合同证明了百本在政府招标中的竞争力
- **学术界合作强化培训壁垒**：理工大学认证课程提升了医护质量门槛
- **缺乏商业保险合作**：与香港商业医疗保险体系几乎零对接——这是 iHomeCare 可以切入的空白点

## D5 — 研发创新管线

### 百本非技术研发型企业

百本的组织基因是**服务运营**而非**技术研发**。其"创新"主要体现在业务模式延伸和概念包装，而非硬核技术投入。

| 项目 | 阶段 | 描述 | 技术含量 | 收入可见性 |
|------|:----:|------|:--------:|:--------:|
| healtHUB 平台 | 早期 | 整合预防/医疗/养老的一站式线上平台 | ⚠️ 未公开技术架构 | ❌ 无收入 |
| 医护撮合系统 | 运营中 | 32K 医护与客户需求的匹配平台 | ⚠️ 传统数据库匹配 | 含在核心收入 |
| 适老化解决方案 | 运营中 | 家居环境安全评估 + 复康器具租用 | 🟢 含 IoT 器具 | 少量 |
| 智慧养老概念 | 概念 | "科技+创新"赋能的养老方案 | ❌ 无实质产品 | ❌ 无收入 |

## D12 — 定价与支付

### 定价机制详解

**核心定价逻辑：差价模式**

```
客户收费（Client Billing Rate）
  - 医护付费（Healthcare Professional Pay Rate）
  = 百本毛利（Markup）
```

FY2025 加价率 = 27.6%（FY2024：26.4%）

**定价因素：**

| 因素 | 影响 |
|------|------|
| 医护职级 | 注册护士 > 登记护士 > 保健员 > 护理员 |
| 服务时段 | 夜班/假日附加费 |
| 服务类型 | 私家看护（高单价） vs 机构轮替（走量） |
| 客户类型 | 机构客户议价空间 > 个人客户 |

### 支付模式

**机构端：**
- 按月/季度结算
- 30-90 天账期（基于行业惯例推断）
- 合同制，提前约定费率表

**个人端：**
- 按次/按天预付或服务后即时支付
- 接受现金、信用卡、银行转账
- 暂无保险直赔通道

**政府端：**
- 招标确定总价
- 按服务里程碑分期结算

### 与保险/医保的对接

> 🔴 **核心空白**：百本服务不与任何商业医疗保险直赔对接。香港无公营长期护理保险，社区券（CCSV）可能覆盖部分安老院舍服务但百本未明确参与 CCSV 计划。**这是 iHomeCare 可以差异化切入的关键点——建立"保险直赔+居家护理"闭环。**

- 整合预防医学、中西医疗、智慧养老三大板块
- ⚠️ 概念宏大，实际落地证据薄弱

**2. 政府合同新增长极**
- 入境事务处青山湾 3 年医疗服务合同（2025 新签）
- 待开拓：其他政府部门（惩教署、社署、学校）
- ✅ 已产生实际收入

**3. "科技+创新"融合**
- 智慧养老及适老化生活解决方案
- 复康器具租赁 + 家居改装
- ⚠️ 收入贡献微小

**4. 战略合作/并购/跨地域**
- 年报提及"与战略合作伙伴结盟或合作以追求各种业务"
- 暗示可能的大湾区扩张
- ⚠️ 75 人团队规模严重限制扩张

### 增长战略评价

### 核心矛盾
百本的战略愿景（"全生命周期健康科技平台"）与组织现实（75 人 + 无技术团队 + 无 R&D 预算）之间存在巨大鸿沟。**更现实的路径是聚焦核心医护人力业务恢复增长 + 选择性布局高附加值服务（复康评估/家居改装）。**

## D27 — 对 iHomeCare 的借鉴价值

### 总分：🟢🟢🟡（6/10）

| 借鉴点 | 百本做法 | iHomeCare 可复用 |

| **机构客户关系** | HA 医院长期合同 + 政府招标 | 进入医管局体系的谈判策略和合同模板 |

| **加价率定价** | 27.6% 的合理区间 | 参考定价策略 |

### 应避免的陷阱

| 陷阱 | 百本案例 | iHomeCare 应做 |
|------|---------|---------------|
| **单一收入来源** | 83% 依赖人力中介 | 构建多元化收入（技术服务费+临床服务费+数据服务） |
| **技术投入不足** | healtHUB 概念无实质技术支撑 | 从 Day 1 就投资 RPM/AI/数据基础设施 |
| **资本错配** | HK$42M 买黄金 ETF | 融资后 100% 投入核心业务 |
| **创始人依赖** | CEO/主席合一，17 年无继任计划 | 建立独立董事会和继任机制 |
| **纯中介天花板** | PS 2.2x, PE 9x 低估值 | 通过技术服务层提升估值到 5-10x PS |

### 战略启示

```
百本模式：医护匹配（低附加值） → PS 2x, PE 9x → 天花板清晰

iHomeCare 路径：
    医护匹配（基础层）
  + RPM 远程监测（技术层）
  + AI 预警/决策支持（智能层）
  + 临床路径标准化（质量层）
  + 保险直赔对接（支付层）
  = 5 倍以上价值增量 → PS 5-10x
```

### 与百本的潜在合作方向

iHomeCare 不需要与百本竞争——可以建立**互补合作关系**：
- iHomeCare 提供 HaH 技术平台 + 临床路径
- 百本提供 32K 医护人力池作为执行层
- 共同向 HA 医院/保险公司提供"技术+人力"整合方案
