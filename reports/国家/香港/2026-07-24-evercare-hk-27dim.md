## D0 — 赛道验证

Evercare 核心赛道是**居家护理科技平台（Home Care Tech Platform）**——通过 App 撮合专业护理人员与需护理的家庭/机构客户。该赛道与 Hospital-at-Home 有直接交集：Evercare 的 30,000+ 护理人员池是 HaH 服务交付中不可或缺的人力基础设施。

**赛道特征：**
- 香港居家护理需求因人口老龄化 + 院舍供给瓶颈而持续增长
- 传统护理中介依赖电话/纸笔调度，科技平台（App 撮合 + AI 匹配）是结构性升级方向
- 赛道兼具 B2C（个人家庭）和 B2B（医院/院舍/NGO）两面，与百本医护（2293.HK）直接竞争
- DBS Foundation 2024 年将 Evercare 评为"Impact Beyond Award"得主——赛道的社会影响力被资本认可

**赛道验证结论**：✅ Evercare 处于香港居家护理科技化的结构性增长赛道，其"AI 赋能平台 + 30K 护理网络"模式对 iHomeCare 有直接对标价值。**与百本的关键差异化：Evercare 更侧重科技平台而非纯人力中介，客户群更偏 B2C。**

## D3 — 业务模式

### 商业模式画布

| 模块 | 描述 |
|------|------|
| **价值主张** | "Family First"——让长者有尊严地在自家安老，通过科技赋能而非替代人情关怀 |
| **护理端** | 平台聚合 30,000+ 经审核的专业护理人员，提供灵活自雇工作机会 |
| **客户端** | 个人家庭（B2C）+ 医院/院舍/NGO/政府（B2B） |
| **技术层** | App 撮合 + AI 匹配（DBS Foundation 描述为 "AI-powered platform"） |
| **收入机制** | 撮合抽成（类似滴滴/Uber 模式）+ B2B 合同服务费 |
| **差异化** | 技术驱动 vs 传统电话中介（如百本） |

### 服务矩阵

| 类别 | 具体服务 | 客户群 |
|------|---------|:------:|
| **居家私家护理** | 24 小时看护、术后康复、长期护理 | B2C |
| **机构人手方案** | 医院/院舍临时护理人手派遣 | B2B |
| **COVID-19 检测** | 香港首个上门鼻咽喉 COVID 拭子检测（2020年） | B2C/B2B |
| **企业健康服务** | HKBN 合作——HK$399/月居家护理套餐 | B2B2C |
| **护理认证培训** | 与理工大学合办香港首个家居护理认证课程 | B2B |
| **复康/理疗** | 上门物理治疗、职业治疗 | B2C |

### 收费模式

- B2C：按小时/天计费，平台抽成
- B2B2C（HKBN）：月费制 HK$399 起
- B2B 机构合同：按人头/时数计

⚠️ 精确抽成比例、客单价未公开披露。

### 盈利模式优势

与百本 27.6% 加价率相比，Evercare 的科技平台模式理论上可实现更高的毛利率——因为 App 自助撮合降低了人工调度成本。2021 年文汇报报道确认 Evercare 已实现盈利，这在 bootstrapped 初创公司中较为罕见。

## D27 — 对 iHomeCare 的借鉴价值

### 总分：🟢🟢🟢（7/10）— 三家中最高

### 核心借鉴

| 借鉴点 | Evercare 做法 | iHomeCare 可复用 |
|--------|-------------|-----------------|
| **创始人叙事** | "祖母的护理需求"→情感连接+社会影响力 | Kenneth Ye 的个人故事与使命绑定 |
| **B2B2C 渠道创新** | HKBN 电信套餐嵌入居家护理 | 与香港电信/保险公司合作 |
| **科技×人情** | "technology enhances empathy, not replaces it" | HaH 的 AI + 人文关怀双重叙事 |
| **Bootstrapped 盈利** | 证明了居家护理平台可以在不烧钱的情况下盈利 | 创业初期的资本效率标杆 |
| **影响力融资** | DBS Foundation Grant——非稀释性资金 | 申请各类社会影响力基金/奖项 |
| **App 平台效率** | 938:1 的护理/员工比 | 技术驱动的运营效率目标 |

### 应避免的陷阱

| 陷阱 | Evercare 案例 | iHomeCare 应做 |
|------|-------------|---------------|
| **缺乏 RPM** | 纯护理撮合，无远程监测 | 从 Day 1 整合 RPM + 护理 |
| **无保险对接** | 全自费 B2C 为主 | 建立保险直赔通道 |
| **规模化受限** | 自筹资金→增长速度天花板 | 适时引入战略投资 |
| **区域局限** | 仅香港 | 多市场架构设计 |

### 与 iHomeCare 的差异化空间

```
Evercare 模式：
    护理撮合（科技平台） → 居家护理服务

iHomeCare 差异化：
    护理撮合（科技平台） → 居家护理服务
  + RPM 远程监测（IoT 硬件） → 临床决策支持
  + AI 预警/干预（算法） → 减少急诊/住院
  + 保险直赔（支付创新） → 可持续收入
  = 更高价值链位势
```
