### 赛道结构特征

1. **极度分散**：前5位企业合计市场份额仅20-25%（推定）。31.3万事业所中多数为员工不足10人的中小零散事业者。
2. **公共LTCI全覆盖**：介護保険覆盖40岁以上全体居民，市町村为保险人，确保稳定支付源。
3. **收益性极低**：人工成本占收入70-75%且公定价格难以转嫁成本上涨。2024年访问介护破产81件创历史新高。
4. **政策驱动增长**：2026年介護報酬期中改定+2.03%，介護情報基盤2026年4月上线，DX化加速。
5. **人才为最大瓶颈**：2040年需280万介護職員，当前薪资水平难以达成。

### ツクイ 的赛道特殊性

与前三家（ニチイ/SOMPO/ベネッセ）不同，ツクイ 是**唯一纯粹介護专营的上市公司**，无跨界业务（教育/保险/出版）提供利润缓冲。这使得ツクイ在介護利润率仅为3-8%的大环境下承受结构性压力——**"规模不够大就亏"**的典型案例。

### 赛道判断

**✅ 日本居家护理赛道验证通过** — 但ツクイ 作为纯粹专营公司，赛道结构性的低利润率对其冲击最大。跨界集团的利润缓冲可有效吸收介護业务的薄利，ツクイ 则缺乏这种缓冲。

### 支払者 vs 利用者の分離

ツクイ の支払構造は業界標準と同じだが、**保険外収入の割合が極めて低い**：

- **介護報酬（公的）**：収入の約90-95%（推定）— 公定価格に完全依存
- **利用者自己負担（介護保険分）**：約5-10%
- **自費サービス**：**~5%未満**（推定）— 保険外サービス収入は極めて限定的
- **家賃収入**：**なし** — 居住系（有料老人ホーム）を持たないため

**比較**：SOMPO Care（保険外収入~25-35%） vs ツクイ（保険外収入~5%未満）

### 赤字根源分析：人件費負担 vs 収入水準

**ツクイ の赤字の核心メカニズム**：

```

  1拠点あたり収入：約¥1.0億/年（ニチイ¥1.43億、SOMPO¥2.9億より低い）

【コスト構造の問題】
  人件費率：約70-75%（業界平均並みだが収入規模が小さい）
  固定費（管理部門・本社）：事業所数が多いほど増加
  減価償却費：事業所拡大に伴い増加

【悪循環】
  赤字 → 投資余力低下 → 運営効率化できず → 収益性改善できず → 赤字継続
```

| **純介護専業の限界** | 公共LTCI制度下では、介護専業単体での持続可能な収益確保は極めて困難。居住系（施設）収入や保険外収入など「介護保険外の収入源」の確保が不可欠。 |
| **赤字の悪循環** | 投資不足→収益性低下→赤字→投資不足の悪循環に陥ると事業の持続可能性が問われる。iHomeCareは成長段階から資本効率を意識すべき。 |
| **スケールの罠** | 事業所数（791）が多いだけでは収益性は確保できない。1拠点あたりの収益性が鍵。 |
| **DX投資の遅れが致命的** | 技術投資を怠ると中長期的な競争力低下は避けられない。赤字企業はDX投資もできない。 |

### iHomeCareにとってのツクイとの関係

| 要素 | 評価 | 理由 |
|------|:----:|------|
| 買収対象としての魅力 | 🟡中 | 赤字だが791拠点のネットワーク価値はある。買収価格は低い可能性。 |
| パートナーシップの可能性 | 🟡中 | 技術導入による収益改善の余地あり。経営再建のパートナーとしての可能性。 |
| 競合としての脅威 | 🔴低 | 赤字で競争力低下中、積極的な競合ではない |
| ベンチマーク価値 | 🟢高 | **反面教師としての価値**：純介護専業モデルのリスクを如実に示す |

**提言：ツクイ は「反面教師」として最も価値が高い**。iHomeCare が日本市場参入を検討する場合、ツクイの失敗から以下の教訓を得る：
1. **居住系（施設）収入の確保**が収益安定化の鍵
2. **保険導流または他の導流チャネル**の確保が必要
3. **技術投資を怠らない** — 赤字になるとDX投資もできなくなる
4. **介護保険外の収入源を複数持つ**ことの重要性

## D27 — 临床质量与患者结局

### 品質管理体制

| 要素 | 内容 |
|------|------|
| **ケアプラン策定** | ケアマネジャーが個別アセスメントに基づき策定 |
| **サービス担当者会議** | 多職種（介護+看護）での情報共有・ケア方針確認 |
| **モニタリング** | ケアマネによる定期的モニタリング（月1回以上） |
| **医療連携** | 限定的（訪問看護の体制が弱い） |
| **記録・報告** | 訪問ごとの記録、状態変化時の報告 |
| **事故報告** | ヒヤリハット・事故報告の仕組み |

| 指標 | 推定水準 | 業界平均 | 備考 |

| 利用者満足度 | 70-80% | 70-80% | 業界平均並み |
| デイサービス継続率 | 80-90% | 80-90% | 安定 |
| 事故発生率 | 低 | 低 | 業界共通 |
| クレーム比率 | 中 | 中 | 業界平均並み |

### 臨床的アウトカムへの影響

- **在宅生活継続支援**：通所介護+訪問介護で在宅期間延長に貢献
- **認知症ケア**：GHでの専門ケアで認知症進行緩和・QOL維持
- **介護者負担軽減**：デイサービスで家族介護者の負担軽減
- **社会的交流維持**：デイサービスで閉じこもり防止・社会参加促進
