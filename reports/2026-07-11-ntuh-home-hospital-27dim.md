## D0 — 赛道真实性验证

### 核心判断：✅ 确认属于 Hospital at Home (HaH) 赛道

台大医院在宅医疗中心是台湾最早系统化开展「居家急性医疗」（Hospital at Home / 在宅住院）的三甲医院项目。其服务覆盖急性感染居家抗生素治疗（相当于美国 CMS Acute Hospital Care at Home 模式）、居家安宁疗护、慢性伤口照护等，属于 **True HaH（急性住院替代）**，而非单纯的慢性 RPM 或传统居家护理。

**赛道定位**：
| 维度 | 判断 |
|:------|:-----|
| 是否为急性住院替代？ | ✅ 是——提供肺炎/尿路感染/软组织感染的居家 IV 抗生素治疗 |
| 是否包含 24h 响应能力？ | ✅ 是——照护小组提供 24 小时电话咨询 + 紧急访视 |
| 是否由医院直接运营？ | ✅ 是——台大医院（公立医学中心）直接管理 |
| 对标美国 HaH 公司？ | ⚠️ 否——公立系统内部项目，非商业实体，但模式可对标 DispatchHealth/Contessa 的临床方案 |

> **赛道误分类警示**：部分台湾产业报道将传统「居家护理」（skilled nursing）与「在宅急症照护」混为一谈。本篇仅聚焦台大医院的急性 HaH 部分。

## D1 — 执行摘要

**一句话定位**：台大医院在宅医疗中心是台湾 Hospital at Home 模式的先驱——2016 年起以三甲医院资源系统化开展急性居家医疗，2024 年 NHI 全国试办计划即以台大经验为核心蓝本。

**核心矛盾**：
- **短期逆风**：台湾护理人力严重短缺，全台医院被迫关床，HaH 模式虽可释放床位但需要额外医护人力投入，短期内难以大规模扩张
- **长期逻辑**：2025 年台湾已进入超高龄社会（65 岁以上人口 >20%），97.7 万独居老人中 5 万人需照护；医院床位有限 + 交叉感染风险 + 长者在地老化需求 → HaH 结构性刚需

**关键数据速览**：
| 指标 | 数据 | 备注 |
|:------|:-----|:-----|
| 启动年份 | 2016 年 | 台大医院首创 |
| 运营模式 | 医院主导 + 多学科团队 | 医师/护理师/药师/呼吸治疗师 |
| 核心服务 | 在宅急症照护 / 居家安宁 / 慢性伤口 | 2024 年 NHI 试办后急性服务纳入健保 |
| 全国 HaH 收案 (2024.7–2026.4) | 7,788 人次 | 全台 192 团队 / 873 家院所 |
| 治疗完成率 | 89.9% | 照护后 14 日内急診率仅 2.9% |
| 台大医院院长 | 余忠仁 | 2025.11 公开呼吁扩大在宅医疗 |
| 关键学术领军 | 施至远 (金山分院) / 黄胜坚 (前院长) | 社区居家安宁模式开创者 |

**总体判断**：台大在宅是台湾公卫体系 HaH 的 **标杆项目**——具有临床创新 + 政策影响 + 学术输出三重价值。对 iHomeCare 而言，其最大借鉴在于「公立大医院如何在单一支付方体系下启动并规模化 HaH」。

### 治理结构

台大医院在宅医疗中心**无独立董事会/法人地位**，其治理嵌入台大医院体系：
- 台大医院院长 → 分院院长 → 跨科室在宅医疗协作团队
- 学术线：台大医学院 → 家庭医学科/公共卫生学院
- 政策线：台大团队 ↔ 卫福部健保署（参与在宅急症照护政策制定）
- 无独立关联交易/违规记录——所有财务经台大医院统一管理

## D3 — 战略定位

### 一句话核心逻辑

**台大在宅赌的是「超高龄社会的住院替代范式转移」**——当台湾 65 岁以上人口突破 20% 且独居老人逼近百万，传统「病人来医院」的模式不可持续，谁先建立可信的「医院级照护进家门」体系，谁就掌握下一阶段医疗资源配置的话语权。

### 战略差异化要素

| 维度 | 台大在宅定位 | 差异化特征 |
|:------|:-----------|:---------|
| 学术背书 | 台大医学院 + 公共卫生学院 | 台湾最顶级医学学术资源，论文发表于国际期刊 |
| 临床能力 | 三甲医学中心全科室支撑 | 可处理复杂共病患者的急性居家治疗 |
| 政策影响力 | 直接参与 NHI 试办计划制定 | 卫福部健保署核心咨询方 |
| 社区渗透 | 金山/北护两大分院下沉社区 | 从城市到偏乡的全覆盖 |
| 品牌信任 | 「台大」品牌 = 台湾民众最高医疗信任 | 患者接受 HaH 的门槛大幅降低 |
| 成本结构 | 公立医院非营利运营 | 无商业回报压力，可专注临床质量 |

### 战略演变三阶段

- **Phase 1（2015–2019）：社区居家安宁奠基**
  - 金山分院以「陪病人在家走到最后」的社区安宁模式建立品牌
  - 核心团队：黄胜坚 + 施至远
  - 关键词：在地终老、叙事医疗、社区营造

- **Phase 2（2020–2024）：急性 HaH 模式验证 + 政策推进**
  - 在宅医疗中心整合多学科急性照护能力
  - 积累居家 IV 抗生素治疗的临床数据
  - 2024 年 NHI 在宅急症照护计划以台大经验为蓝本
  - 关键词：急性住院替代、政策 sandbox、健保给付

- **Phase 3（2025–当前）：规模化 + 亚太领导力**
  - 2025 年余忠仁在总统层级呼吁扩大在宅医疗
  - 适应症从 3 种感染症扩展至心衰竭/呼吸衰竭/其他感染
  - 2026 年举办首届亚太在宅医疗大会
  - 关键词：适应症扩展、区域影响力、长照 3.0 整合

### 支付方 vs 使用方

| 角色 | 实体 | 说明 |
|:------|:-----|:-----|
| **支付方** | 全民健保 NHI | 单一支付方，在宅急症照护每日给付（含医疗费+护理+药品） |

### 在宅急症照护关键参数（2024 NHI 试办计划）

| 适应症 | 目标照护天数 | 上限天数 | 核心治疗 |

| 尿路感染 | 7 天 | 9 天 | IV 抗生素 ± 口服 |
| 软组织感染 | 6 天 | 8 天 | IV 抗生素 |

- 住院医疗（部分负担 10%）：约 NT$7,720
- 在宅急症照护（部分负担 5%）：约 NT$2,470
- **节省：NT$5,250（约 68%）**

         │
         ▼

  │         + 护理师安装远程监测设备（BP/SpO2/体温）
  ├─ Day 1–N: 护理师每日至少一次实地访视
  │           + 医师每 3 天实地访视或每日视频诊疗
  │           + 药师用药评估 + 呼吸治疗师（如需）
  │           + 必要时床侧检验（POCT）
  ├─ 24h 支持: 照护小组热线 + 紧急访视机制

## D12 — 盈利模型与路径

> ⚠️ 台大在宅为非营利公立项目，以下分析以「财务可持续性」替代「盈利」。

### 成本-收入平衡分析

| 项目 | 估算 | 说明 |
|:------|:-----|:-----|
| 每例 HaH 患者（9 天肺炎）NHI 收入 | NT$2–3 万（估） | 每日医疗费 + 护理 + 药品 + 检验 |
| 每例 HaH 直接成本 | NT$2–2.5 万（估） | 人力 + 交通 + 药品耗材 |
| 边际贡献 | 接近持平或微正 | 公立非营利定价 |
| 释放床位的间接效益 | 显著 | 每例 HaH 释放 6–14 天急性床位 |

### 财务可持续性路径

- **短期（当前）**：NHI 试办计划 cover 直接成本，基本可实现收支平衡
- **中期（1–3 年）**：适应症扩展 + 给付调升 → 规模效应摊薄固定成本
- **长期（3–5 年）**：若 HaH 占全台医疗支出从 1% 升至 3%（政策目标），年度市场达 NT$180–240 亿

### 综合判断

公立医院 HaH 的财务逻辑不靠「单项目盈利」，而靠 **「释放急性床位 → 收治更高净值患者 → 提升医院整体运营效率」** 的间接效益。这一模式在台湾 NHI 单一支付方体系下具有合理性。

## D16 — 对 iHomeCare 战略建议

### 1. 模式借鉴：大医院 vs 社区的 HaH 路径选择

台大在宅提供两条 HaH 路径：
- **大医院路径**（台大总院）：医学中心资源 + 全科室支撑 → 适合复杂共病患者
- **社区路径**（金山/北护分院）：社区医院下沉 + 本地化 → 适合以社区为单位的 HaH

**对 iHomeCare 启示**：香港同为单一支付方（医管局 HA）体系，**建议优先走「大医院 + 社区卫星」混合路径**——从 HA 联网医院启动，以社区健康中心/门诊为下沉节点。

### 2. 适应症起步策略

台大从「3 种感染症 IV 抗生素」起步 → 逐步扩展至心衰竭/呼吸衰竭 → 洗肾/化疗。

**对 iHomeCare**：建议以「COPD 急性加重 + 心衰竭利尿 + 蜂窝性组织炎 IV 抗生素」为起步适应症（高 incidence + 明确治疗终点 + 低意外风险）。

### 3. 支付设计：部分负担的经济杠杆

台大模式中，患者 HaH 部分负担仅为住院的 ~1/3（5% vs 10%），形成强经济诱因。

**对 iHomeCare**：建议向 HA 提议类似的部分负担分级——HaH 日额收费低于住院，刺激患者选择。

### 4. 不要忽略「在地终老」的人文价值

台大金山分院的社区安宁经验表明：**民众接受 HaH 的关键不在费用，而在「在家治疗的安心感」**。iHomeCare 需要从一开始就投资于家属教育 + 可信赖的 24h 响应系统。

### 5. 技术平台不可忽视

台大在宅的技术平台仍较基础（人工调度+通讯软件）。iHomeCare 若能在启动时即建立专用在宅信息系统（调度 + 远程监测 + 家属沟通 + 数据追踪），将成为差异化优势。

### 6. 护理人力是最大瓶颈

台湾面临严重的护理人力短缺——HaH 虽释放床位但需要额外社区访视人力。香港同样面临医护人力紧张，建议：
- 早期引入「护理师 + 健康助理」分层人力模型
- 评估用非医护人力（如社区健康工作者）承担部分非临床任务

## D18 — 单元经济模型

### 案例：肺炎患者 — 在宅 vs 住院对比（9 天疗程）

| 项目 | 住院 | 在宅急症照护 | 差异 |
|:------|:-----|:----------|:-----|
| **收入侧** | | | |
| NHI 住院日额给付 | NT$6,000–8,000/天（估） | — | |
| NHI 在宅日额给付 | — | NT$2,500–3,500/天（估） | |
| 药品/检验 | 含在住院给付内 | 含在在宅给付内 | |
| **收入合计（9天）** | ~NT$54,000–72,000 | ~NT$22,500–31,500 | **HaH 收入低 ~50–60%** |
| **成本侧** | | | |
| 病房/基础设施 | NT$2,000–3,000/天 | NT$0 | 节省 |
| 医护人力（分摊） | NT$4,000–5,000/天 | NT$1,500–2,500/天 + 交通 | 节省 |
| 药品/耗材 | ~NT$500–1,000/天 | ~NT$500–1,000/天 | 等同 |
| 交通访视 | NT$0 | NT$300–500/天 | 增量 |
| **成本合计（9天）** | ~NT$58,500–81,000 | ~NT$20,700–36,000 | **HaH 成本低 ~55–65%** |
| **边际贡献** | 接近持平 | 接近持平 | 均为非营利定价 |
| **床位释放效益** | 占用 1 床 × 9 天 | 释放 1 床 × 9 天 | 可收治更高敏患者 |
| **患者部分负担** | NT$7,720（10%） | NT$2,470（5%） | **患者节省 ~68%** |

### 关键假设

1. NHI 在宅日额给付水平为推估值（健保署未公开发布每日费率表）
2. 住院成本为台湾医学中心平均水平推估
3. 未计入「床位释放后可收治外科/重症患者的增量收入」——这是 HaH 的真正经济价值
4. 未计入患者/家属的非财务效益（避免往返医院的时间成本、降低院内感染风险）

### 经济可行性判断

**短期**：在宅急症照护在 NHI 试办给付水平下可达收支平衡
**中期**：若 NHI 提升给付 + 适应症扩展，单位经济改善空间有限但规模效应显著
**长期核心价值**：释放急性床位的间接效益远大于项目本身的直接损益
