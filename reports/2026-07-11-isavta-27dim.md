## D1 — 执行摘要

**一句话定位**：iSavta 是以色列最大的外籍护理员在线撮合平台——起步于创始人为祖母找护理员的个人经历，通过去中介化将传统护理机构（chevrat siud / tagid）的撮合功能搬到线上，连接 2 万+患者家庭与 3.5 万+注册护理员。

**核心矛盾**：
- **短期逆风**：以色列政府对双边协议国（菲律宾/印度/尼泊尔/斯里兰卡）护理员引入通道的强化管控可能收紧供给；传统护理机构（tagidim）的法律强制角色尚未被完全绕过——雇主仍需通过 tagid 注册。
- **长期逻辑**：以色列 392,000 名 NII 护理津贴受益人 + 快速老龄化（65 岁以上人口占比预计从 12% 升至 2040 年的 16%）构成刚性需求底座；去中介化降低家庭成本 5,000-25,600 NIS/年，价值主张清晰；多语言平台天然适配以色列多元移民社会。

**关键数据速览**：

| 指标 | 数值 | 来源 |
|:------|:-----|:-----|

| 融资总额 | $500K | Startup Nation Central |

## D3 — 战略定位

### 一句话核心逻辑

**iSavta 赌的是：以色列外籍护理员市场的信息不对称足够大、足够痛，一个在线撮合平台可以通过去中介化显著降低家庭成本，从而替代传统护理中介机构（tagidim）的撮合功能。**

### 战略差异化要素表

| 维度 | iSavta 定位 | 差异化特征 |
|:------|:-----|:------|
| 撮合模式 | 平台直接连接 vs 传统 tagid 中介 | 去中介化，家庭自主筛选，无需支付中介费 |
| 多语言 | 英语 / 希伯来语 / 俄语 / 罗马尼亚语 / 乌兹别克语 | 覆盖外籍护理员母语，降低沟通门槛 |
| 直接雇佣工具 | 薪资计算器、社保表单提交、假日管理 | 从「撮合」延伸到「雇佣管理」SaaS |
| 内容生态 | Blog + Magazine（护理知识、社保指南） | 用内容建立信任、SEO 获客 |
| 定价 | 自助 69 NIS/月，全服务 119 NIS/月 | 极低定价（vs tagid 收取 2,000 NIS 注册费 + 70 NIS/月） |

### 战略演变三阶段

| 阶段 | 时期 | 战略焦点 |
|:------|:-----|:------|
| Phase 1 — 验证 | 2011-2015 | 免费网站，验证「在线撮合护理员」需求是否真实存在 |
| Phase 2 — 商业化 | 2016-2019 | 转为付费平台，建立双边网络；完成 Pre-Seed 融资 |
| Phase 3 — 深度工具化 | 2020-至今 | 从纯撮合向「直接雇佣 SaaS」扩展（薪资计算、社保表单、假日管理）；强化内容生态 |

### 价值链定位

```
纯中介 ────────────────●────── 自建医疗体系
(classified ads)      │      (vertically integrated provider)
                      │
```

iSavta 处于「纯分类广告」与「自建服务体系」之间的 **撮合+轻 SaaS** 位置——比 Craigslist 式分类广告多了结构化资料、直接雇佣管理和多语言；但远未涉及临床服务、护理质量保证或保险整合等深度价值链环节。

## D8 — 工作流/旅程映射

### 雇主端旅程

```
Phase 0: 需求触发
  │  家中老人失能/ADL 评估不达标 → 需要全职护理员
  │  触发渠道：医院出院建议 / 家庭医生转诊 / NII 通知
  ▼
Phase 1: 评估与匹配
  │  在 iSavta 注册（免费浏览）→ 设置筛选条件（地点/语言/性别/工作类型）
  │  → 浏览护理员资料（照片+推荐信+经验描述）
  │  → 发布职位 → 接收申请 → 加入收藏夹管理候选人
  ▼
Phase 2: 面试与雇佣
  │  通过平台私信联系 → 线下/视频面试 → 核查推荐信 → 核实签证/工作许可状态
  │  → 通过 tagid 完成法定注册（iSavta 不替代此步骤）
  │  → 决定是否使用 iSavta 直接雇佣服务（NII 现金津贴申请）
  ▼
Phase 3: 服务交付
  │  护理员到岗（住家/不住家）→ 日常照护（ADL协助、陪伴、简单家务）
  │  → iSavta 直接雇佣工具：月度薪资计算、社保自动计算、假日管理
  ▼
Phase 4: 结算
  │  家庭向护理员支付工资（含 NII 津贴 + 自费部分）
  │  → iSavta 直接雇佣系统生成多语言工资单（希伯来语/英语/俄语）
  │  → 储蓄社保权益在家庭账户
  ▼
Phase 5: 持续跟踪
  │  护理员请假/度假 → 在 iSavta 搜索临时替换护理员
  │  → 定期检查社保缴纳情况 → 必要时更换护理员
  │  → 阅读 iSavta Magazine 获取护理知识更新
```

### 护理员端旅程

```
Phase 0: 进入市场
  │  已在以色列（持有效签证）或即将抵达
  ▼
Phase 1: 注册与展示
  │  在 iSavta 免费注册 → 创建个人资料（照片/经验/语言/推荐信/工作类型偏好）

Phase 2: 找工作
  │  浏览职位列表 → 主动申请 → 等待雇主联系
  │  → 或：收到雇主直接联系（雇主主动发起）
  ▼
Phase 3: 面试与签约
  │  与雇主沟通 → 面试 → 协商薪资和工作条件
  │  → 通过 tagid 完成法律手续 → 开始工作
```
