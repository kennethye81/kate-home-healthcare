Labrador Systems — 27 维度深度尽调报告

调研日期：2026 年 7 月 16 日 | 调研人：Kenneth Ye | 版本：v2.0 数据截止：2026 年 7 月（最新公开动态：2026.5 Gadgeteer 报道）

D0 — 赛道真实性验证

🚨 赛道定位：Labrador Systems 是 居家物理辅助机器人公司，核心产品 Retriever/Caddie 是自主导航的「机器人推车」——帮助行动不便者搬运物品。属于 辅助技术（Assistive Technology） 子类别。

维度 判断
是否属于居家护理机器人？ ✅ 是——属于「物理辅助/搬运」子类别
是否属于医疗设备？ ❌ 否——consumer assistive device，非 FDA 监管
对 iHomeCare (HaH) 直接相关性 🟡 中——HaH 患者可能行动不便，但 Retriever 不涉及临床护理
与 ElliQ 的赛道区别 ElliQ = 陪伴+健康行为改变；Labrador = 物理搬运+物品递送

D1 — 执行摘要

Labrador Systems 是全球极少数聚焦居家物理搬运的消费级机器人公司。核心产品 Retriever 本质上是一台自主导航的「机器人推车」，可承载 25 磅物品、自动导航到家中指定位置、通过语音控制。它解决的是行动不便老人 最基础但最被忽视的日常痛点——端水、拿药、取餐食。

核心矛盾：产品概念获 IEEE Spectrum、CES 高度评价，创始人团队有 20+ 年消费机器人经验（iRobot 前高管），但公司极度早期——仅 $310 万种子轮融资、2022 年才开始首批机构部署、2023 年预期量产一再延迟、至今无收入公开数据。是一个「概念极好、执行极度早期」的故事。

关键指标 数值
总融资 ~$310 万（种子轮）+ NSF 资助
估值（估） ~$1,000-2,000 万
收入 早期，估 <$100 万/年
定价 $1,500 预付 + $99-149/月 × 36 月（Retriever）；$1,500 + $100/月（Caddie）
首次部署 2022.11（Masonic Homes、On Lok PACE 等）
员工规模 估 15-25 人

总体判断：🟡 产品概念 + 团队背景顶级。🔴 但极度早期——融资规模极小、量产一再延迟、收入几乎为零。对 iHomeCare 直接相关性有限，但搬运机器人的底层 SLAM + 自主导航 + 低成本硬件方案值得关注。

D3 — 战略定位

一句话核心逻辑

「养老机器人的最大刚需不是 AI 对话，而是帮老人端一杯水、取一片药。」

战略差异化要素

维度 定位
产品形态 自主导航机器人推车——非人形、非屏幕、非语音音箱，纯粹解决「搬运」问题
核心差异 做减法——不做 AI 对话、不做人脸识别、不做健康监测。只做一件事：自主移动 + 物品承载 + 语音调度。这使其成本可控（消费级电子件）、可靠性可控
目标人群 行动受限者——慢性疼痛、关节炎、术后恢复、轻度残疾、高龄体弱者
付费方 消费者（$1,500+$100/月订阅） + 养老机构（B2B 车队） + 保险公司（Nationwide 已合作）
技术壁垒 自研低成本 SLAM 导航——用消费级电子件实现商业级机器人导航精度（NSF 资助验证）

战略演变三阶段

  • Phase 1 (2017-2021)：原型开发 → Alpha 测试 → CES 发布 → 种子轮
  • Phase 2 (2022-2025)：首批机构部署 → 量产爬坡（延迟） → 迭代优化 → B2B 车队交付
  • Phase 3 (2026-)：量产规模化 → 消费者版（Caddie） → 保险公司渠道扩展 → 国际市场

D8 — 工作流/旅程映射

Phase 0: 部署设置
  └→ Labrador 代表远程驾驶机器人 → 3D 建图 → 设置"公交站"位置点

Phase 1: 日常使用
  └→ 用户说"Alexa, tell Labrador to go to the kitchen"
  └→ 或按无线按钮 / 手机 App 选择目的地
  └→ Retriever 自主导航到指定位置

Phase 2: 物品取用
  └→ 家人/护工事先将物品放在托盘上
  └→ Retriever 到指定"公交站" → 对接托盘 → 自动收回
  └→ 导航回用户身边 → 升降平台调至合适高度

Phase 3: 定期调度
  └→ 预设时间自动配送：上午 8 点送药、中午 12 点送午餐
  └→ 物理提醒——机器人按时出现比 App 通知更有效

Phase 4: 充电 + 待命
  └→ 全天电池续航（多数时间静止当桌子）
  └→ 中间层储物空间可充电手机 + 存放常用物品

D16 — 对 iHomeCare 战略建议

直接竞品相关性：🟡 中

Labrador 不做临床护理，但其 低成本自主导航 + 物理搬运 技术路线对 iHomeCare 有借鉴：

  1. 「搬运是第一刚需」验证：HaH 患者中有行动不便者（术后、心衰、COPD），药物、餐食、水壶的搬运是真实障碍。但 iHomeCare 的 RPM 套件目前是固定设备，不需要移动。

  2. SLAM 低成本导航：如果 iHomeCare 未来需要移动机器人组件（如移动式生命体征采集车），Labrador 的低成本方案值得研究——而非常规的 $10 万医院 AMR。

  3. 语音控制集成：Labrador 的 Alexa 集成模式——「语音命令 + 机器人执行」——可能启发 iHomeCare 的家属/患者交互设计。

  4. 「做减法」战略：Labrador 刻意不做 AI 对话、不做健康监测，只做搬运。这种聚焦在资源受限的创业阶段是正确的——iHomeCare 在产品路线图中也需警惕功能膨胀。
