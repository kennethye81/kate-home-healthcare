# 香港 — 政策与法律法规

## 一、政策框架总览

香港居家医疗/护理的监管与政策体系由**三个政策局**分治：

| 政策局 | 管辖范围 | 执行机构 |
|--------|---------|---------|
| **医务卫生局（HHB）** | 医疗服务、遥距医疗、医管局、基层医疗 | 医管局（HA）、卫生署（DH）、基层医疗署（将成立） |
| **劳工及福利局（LWB）** | 安老服务、社区券、院舍监管、护理人力 | 社会福利署（SWD） |
| **创新科技及工业局（ITIB）** | 乐龄科技、医健通+、智慧城市 | 政府资讯科技总监办公室（OGCIO） |

**核心理念**：「居家安老为本、院舍照顾为后援」——这是1997年《安老服务计划方案》确立、至今仍贯穿所有政策文件的基石原则。

## 二、长者社区照顾服务券（CCSV）计划

### 2.1 制度概述

CCSV 是香港安老服务最核心的**需求方补贴工具**，以三个原则运作：

| 原则 | 含义 |
|------|------|
| **「钱跟人走」** | 直接资助合资格长者，长者自由选择及转换认可服务单位 |
| **「能者多付」** | 负担能力较低者获更多政府资助 |
| **「混合模式」** | 可同时使用日间护理中心 + 家居照顾服务 |

### 2.2 关键参数（2026-27年度）

| 参数 | 数值 |
|------|------|
| 社区券总数 | **16,000张**（2024-25: 11,000 → 2025-26: 12,000 → 2026-27: 16,000） |
| 每年政府总开支 | **约12亿港元** |
| 社区券月值范围 | **$4,526 – $10,824/月**（2026-27年度） |
| 共付级别 | **6级**（5%、8%、12%、16%、25%、40%） |
| 政府支付比例 | 服务组合价值的95% – 60%（视共付级别） |
| 服务模式 | ①中心为本 ②家居为本 ③混合模式 |

来源：[SWD CCSV计划页面](https://www.swd.gov.hk/sc/pubsvc/elderly/cat_commcare/psccsv/)、[2026-27财政预算案 §236](https://www.budget.gov.hk/2026/chi/budget43.html)

### 2.3 参加资格

- 经**安老服务统一评估机制**评定为适合社区照顾或院舍照顾
- 正在「资助长期护理服务中央轮候册」上
- 尚未接受任何院舍照顾服务或资助社区照顾服务

### 2.4 运作流程

```
中央轮候册排序 → SWD按申请日期发信邀请 → 长者提交申请
                                              ↓
                              SWD 4周内完成审批及发出社区券
                                              ↓
                              长者透过VISE系统选择认可服务单位
                                              ↓
                              确认服务组合 → 开始服务
```

### 2.5 共付金额厘定

社署根据**长者及同住家人收入**进行经济状况审查，参考政府统计处家庭住户每月收入中位数，将长者归入六级共付级别。长者支付服务组合价值的 5%–40%，政府支付余额。

## 三、长者院舍照顾服务券（RCSV）计划

### 3.1 制度概述

RCSV 是院舍端的「钱跟人走」机制，2026-27年度：

| 参数 | 数值 |
|------|------|
| 院舍券总数 | **7,000张** |
| 每年政府总开支 | **约19.7亿港元** |
| 认可服务机构 | 护理安老宿位 + 护养院宿位提供者 |

### 3.2 与 CCSV 的关系

两券互补：CCSV 覆盖社区/居家护理，RCSV 覆盖院舍。长者不可同时持有两券。两券共同构成「社区→院舍」的完整照护资助链条。

## 四、院舍监管法规——2023年院舍法例修订

《2023年院舍法例（杂项修订）条例》分阶段实施：

| 阶段 | 时间 | 内容 |
|------|------|------|
| **第一阶段** | **2026年6月** | 提高高度照顾院舍的护士及保健员人手标准 |
| **第二阶段** | **2028年6月** | 提高多於60名住客的高度照顾院舍人手标准 |
| **第三阶段** | **2032年6月** | 提升高度/中度照顾院舍人均面积 |

来源：[立法会 CB(1)1163/2025(04)号文件](https://www.legco.gov.hk/yr2025/chinese/panels/ws/papers/ws20250714cb1-1163-4-c.pdf)

## 五、遥距医疗政策与监管

### 5.1 医务委员会指引

香港医务委员会设有**《遥距医疗实务道德规范指引》**，核心要求：
- 遥距医疗适用于慢性病病情稳定、非新症患者
- 医生需了解遥距医疗和电子通讯的局限性
- 不适用于需要临床检查的新症或复杂病例
- 消费者隐私保护（WhatsApp/Zoom 等非专用平台存在隐私风险）

### 5.2 HA 遥距医疗服务

- 2022年4月至2025年3月：超过34万宗非新冠遥距医疗个案
- 涵盖：社区老人评估小组 → 院舍遥距诊症、专职医疗、专科复诊
- 平台：HA Go

来源：[立法会六题答复 2025.09.10](https://www.info.gov.hk/gia/general/202509/10/P2025091000531.htm)

## 六、预设医疗指示（AMD）— 2025年立法

《维持生命治疗的预作决定条例》于**2024年通过**，**2025年7月31日生效**，建立法定框架：

- 年满18岁的成年人可预先订立**预设医疗指示（AMD）**
- 指明在特定情况下（如末期疾病、持续植物状态）拒绝维持生命治疗
- **不作心肺复苏术（DNACPR）** 法定化
- 医护人员及家人须遵从有效 AMD
- 香港医学专科学院发布《AMD最佳实践指引》

**对居家医疗的意义**：AMD 法定化为居家安宁疗护（Home-based Palliative Care）提供了法律基础，居家环境中执行「不抢救」决定有法可依。

## 八、跨境大湾区安老政策

### 8.1 广东院舍照顾服务计划

- 2014年以试验计划形式推出 → 2020年恒常化
- 截至2026年：**26家**广东省内认可服务机构，覆盖大湾区**9个城市**
- 2025年施政报告：资助选择赴粤养老综援受助长者，**每月$5,000元**，名额1,000个
- 综援长者可选择将款项直接汇入内地银行账户（2026年中推出）

### 8.2 医疗补贴试行安排

- 为参与广东院舍计划的长者提供**每人每年门诊费人民币1万元、住院费3万元**上限的医疗补贴
- 2025年底推出，为期两年试行

来源：[2026-27预算案 §237](https://www.budget.gov.hk/2026/chi/budget43.html)

## 九、基层医疗改革——2025施政报告重点

2025年施政报告提出多项基层医疗改革：

1. **成立基层医疗署**：2026年内提交法案，制订全港基层医疗服务标准，建立跨专业服务网络
2. **扩展HA家庭医学门诊**：预防筛查和护理服务增量，延长服务时段常规化
3. **慢性疾病共护计划**：推动「家庭医生+专职医疗」协作模式
4. **医健通+五年计划**：将电子健康记录互通系统升级为集合数据互通、服务提供及流程管理的综合医疗基建

## 十一、政策空白与机遇

| 空白领域 | 现状 | 建议补充路径 |
|---------|------|-------------|
| **急性HaH立法/监管** | 香港无独立的「Hospital at Home」监管框架 | 参考美国 AHCAH waiver、英国 NHS Virtual Ward 制度 |
| **RPM远程监测支付编码** | 无独立报销编码，遥距医疗仅限诊症 | 推动 HA/私营保险引入 RPM CPT 编码 |
| **居家用药管理法规** | 未明确居家静脉输液等高级护理的监管标准 | 参考新加坡 MOH Home Care 监管指南 |
| **数据隐私/FDA级SaMD审批** | 医疗器械条例修订中，但未专门针对数字医疗 | 2026年医疗器械立法中预留数字医疗章节 |
