# 香港 — 支付体系

## 一、支付模型全景

香港居家医疗/护理的支付体系为**「四轨并行」**结构：

```
                    ┌──────────────────────────┐
                    │  香港居家护理支付体系      │
                    └──────────────────────────┘
                                    │
          ┌──────────┬──────────┬───┴────┬──────────┐
          ▼          ▼          ▼        ▼          ▼
      CCSV社区券  RCSV院舍券   HA资助  私营自费   商业保险
      (SWD)      (SWD)       (公营)   (市场化)   (Bupa等)
```

| 支付通道 | 管理机构 | 覆盖范围 | 支付方式 | 受益人规模 |
|---------|---------|---------|---------|-----------|
| **CCSV社区券** | 社署 | 社区/居家照护 | 共付制（政府60-95%） | 16,000人（2026-27） |
| **RCSV院舍券** | 社署 | 院舍照护 | 共付制 | 7,000人（2026-27） |
| **HA公营医疗** | 医管局 | 住院+门诊+社康护理 | 高度资助（住院$120/天） | ~90%住院服务 |
| **私营自费** | 市场 | 上门护理/私人陪护 | 按次/按时收费 | 无统一统计 |
| **商业保险** | 保险公司 | 高端医疗/跨境 | 保险理赔 | 少数高端人群 |

## 二、CCSV 长者社区照顾服务券——支付细节

### 2.1 券值范围（2026-27年度）

| 参数 | 数值 |
|------|------|
| 最高面值 | **$10,824/月** |
| 最低面值 | **$4,526/月** |
| 选择弹性 | 长者可在此范围内选择任意面值组合服务 |

### 2.2 六级共付金额表

社署根据长者及同住家庭收入，将共付分为六级：

| 共付级别 | 长者自付比例 | 政府支付比例 | 适用人群（按家庭收入） |
|:------:|:----------:|:----------:|-------------------|
| **第1级** | **5%** | 95% | 最低收入群组 |
| **第2级** | **8%** | 92% | — |
| **第3级** | **12%** | 88% | — |
| **第4级** | **16%** | 84% | — |
| **第5级** | **25%** | 75% | — |
| **第6级** | **40%** | 60% | 较高收入群组 |

**计算示例**：
- 长者选择 $10,824/月 最高面值、共付第1级（5%）：自付 **$541/月**，政府付 **$10,283/月**
- 长者选择 $6,000/月、共付第4级（16%）：自付 **$960/月**，政府付 **$5,040/月**
- 长者选择 $4,526/月 最低面值、共付第6级（40%）：自付 **$1,810/月**，政府付 **$2,716/月**

来源：[SWD CCSV页面](https://www.swd.gov.hk/sc/pubsvc/elderly/cat_commcare/psccsv/)，2026.07 browser 访问

### 2.3 共付级别厘定机制

- 经济状况审查对象：长者本人 + 同住家人
- 参考基准：政府统计处**按季度更新的家庭住户每月收入中位数**
- 审批时限：社署收到申请后 **4周内** 完成审批及发出社区券

### 2.4 认可服务单位服务范围

CCSV 可购买的服务：
- **个人照顾**：洗澡、穿衣、进食、如厕
- **护理服务**：伤口护理、药物管理、导管护理
- **康复运动**：物理治疗、职业治疗
- **膳食服务**：送餐/到中心用餐
- **家居支援**：家居清洁、陪诊
- **日间护理中心**：全日/部分时段
- **辅助科技产品租赁**（2024年起新增）

## 三、RCSV 长者院舍照顾服务券

| 参数 | 数值 |
|------|------|
| 院舍券总数 | **7,000张**（2026-27） |
| 年政府总开支 | **约19.7亿港元** |
| 认可院舍类型 | 护理安老宿位 + 护养院宿位 |
| 共付模式 | 与CCSV类似，按收入分级共付 |

**CCSV vs RCSV 对比**：

| 维度 | CCSV社区券 | RCSV院舍券 |
|------|-----------|-----------|
| 服务场景 | 居家+社区 | 院舍 |
| 2024-25数量 | 11,000张 | 6,000张 |
| 2026-27数量 | 16,000张 | 7,000张 |
| 年开支 | ~12亿港元 | ~19.7亿港元 |
| 每券年均支出（估算） | ~$75,000 | ~$281,000 |
| 服务弹性 | 高（可选不同单位/服务组合） | 中（可选择认可院舍） |

**关键洞察**：院舍券的每人年均支出（~$281,000）是社区券（~$75,000）的**3.7倍**——这是「居家安老为本」政策的经济理性所在。

## 四、HA 公营医疗服务支付

### 4.1 HA 服务收费标准

| 服务类型 | 合资格人士收费 | 非合资格人士收费 |
|---------|:----------:|:------------:|
| 急症室 | **$180/次** | $1,230/次 |
| 专科门诊（首次） | **$135** | $1,190 |
| 专科门诊（覆诊） | **$80** | — |
| 普通科门诊 | **$50** | $445 |
| 住院（急症病床） | **$120/天**（入院费$75+每天$120） | $5,100/天 |
| 社康护理（上门） | **$80/次** | — |
| 老人科/精神科日间医院 | **$60/次** | — |
| 社区专职医疗服务 | **$80/次** | — |

注：以上为2025-26年度标准。合资格人士指持有香港身份证人士。

**HA 定价逻辑**：收费为**象征性共付**（copayment），远低于实际成本——政府通过一般税收补贴差额。公共医疗开支仅占GDP的**4.1%**，但提供全港**近九成**住院服务（来源：[立法会 CB(3)1432/2025(01)](https://www.legco.gov.hk/yr2025/cn/panels/ps/papers/ps20251013cb3-1432-1-c.pdf)）。

### 4.2 HA 社康护理支付

- HA 社康护理服务：**$80/次**
- 覆盖：伤口护理、药物注射、导管护理、健康指导
- 需经 HA 医生转介，不属于直接购买服务
- 主要针对出院后短期护理，非长期照护

## 五、私营市场支付

### 5.1 私营居家护理收费标准

香港私营居家护理市场缺乏统一披露数据。以下为根据市场公开信息整理的范围（⚠️ 部分为市场调研推断，非官方统计）：

| 服务类型 | 私营市场收费范围 | 说明 |
|---------|:------------:|------|
| 注册护士上门（RN） | **$500-1,200/次** | 伤口护理、药物注射等医疗护理 |
| 登记护士/保健员上门 | **$300-700/次** | 基本护理服务 |
| 护理员/陪诊 | **$100-200/小时** | 个人照顾、陪诊、家务 |
| 物理治疗师上门 | **$800-1,500/次** | 康复治疗 |
| 24小时私家看护 | **$1,500-2,500/天** | 住院/居家一对一护理 |

### 5.2 主要私营服务机构定价模式

| 机构 | 定价模式 | 支付方式 |
|------|---------|---------|
| Evercare | App 下单，按服务项目收费 | 自费 + 企业保险合作 |
| 百本医护（2293.HK） | 时薪/次薪中介撮合 | 自费为主 |
| QualityCare 卓健居家护理 | Bupa 保险整合 + 自费 + CCSV | 保险直付/自费/CCSV |
| YDCare 易得康 | 高端定制化服务包 | 自费 + 保险合作 |

## 六、商业保险参与

### 6.1 Bupa 整合模式

QualityCare（卓健医疗，Bupa 旗下）是香港**唯一**实现「保险+居家护理」深度整合的案例：

- Bupa 全球营收：£140亿+
- 香港网络：1,650+服务点
- 2024年9月推出「卓健居家护理」品牌
- 支付方式：Bupa 保险直付 + 自费 + CCSV 社区券

### 6.2 其他保险参与

- 主流医疗保险（AIA、保诚、AXA等）：住院保险通常**不覆盖**居家护理替代住院，仅部分高端计划包含「上门护理」附加保障
- 企业团体保险：部分企业通过 Evercare 等平台为员工家属购买居家护理套餐

**空白识别**：香港尚无专门针对「居家替代住院（Hospital at Home）」的商业保险产品——这是 iHomeCare 潜在差异化切入点。

## 八、跨境支付——广东院舍计划

### 8.1 内地安老资助

| 资助项目 | 金额 | 名额 |
|---------|------|:---:|
| 赴粤养老资助 | **$5,000/月** | 1,000个 |
| 广东院舍照顾服务计划 | 院舍费用由政府直接支付 | 26家认可院舍 |
| 医疗补贴（门诊） | 人民币 **10,000元/年/人** | 试行2年 |
| 医疗补贴（住院） | 人民币 **30,000元/年/人** | 试行2年 |

### 8.2 跨境支付渠道

- 2026年中起：参与「广东计划」「福建计划」的综援长者，可选择政府将款项**直接汇入内地银行账户**
- 旧模式：需在香港银行账户接收后再自行汇款

来源：[2026-27预算案 §237-238](https://www.budget.gov.hk/2026/chi/budget43.html)

## 九、支付体系 SWOT 分析

| | 优势（Strengths） | 劣势（Weaknesses） |
|------|------|------|
| | • CCSV「钱跟人走」需求方驱动 | • **四轨并行碎片化**，无一站式支付 |
| | • HA 高度资助，基本医疗可及性高 | • **私营居家护理无统一支付编码** |
| | • 跨境支付新通道打通 | • CCSV 16,000张远不及需求（中央轮候册排队数年） |
| | • Bupa 整合模式验证保险+护理可行 | • 商业保险覆盖率极低 |
| | **机遇（Opportunities）** | **威胁（Threats）** |
| | • 急性 HaH 支付空白——首创者定价权 | • 政府财政压力——人口老化加剧 |
| | • CCSV 持续扩张（16,000→未来可能更多） | • 公营医疗收费可能上调（减轻财政压力） |
| | • 大湾区跨境支付新市场 | • 输入外劳政策的政治敏感性 |
| | • 医疗器械立法后可推动 RPM 正式编码 | • 长者数码鸿沟限制电子支付使用 |

## 十、对 iHomeCare 的支付策略建议

| 策略 | 说明 | 优先级 |
|------|------|:---:|
| **对接 CCSV** | 成为 CCSV 认可服务单位，承接政府资助流量 | 🔴 高 |
| **保险产品整合** | 与 Bupa/AIA 等合作开发「HaH替代住院」专属产品 | 🔴 高 |
| **B2B 企业客户** | 瞄准企业团体保险/员工福利市场 | 🟡 中 |
| **跨境大湾区** | 利用港人北上养老趋势，提供跨境健康管理 | 🟡 中 |
| **自费高端线** | 瞄准高净值长者/家属自费市场 | 🟢 低 |
