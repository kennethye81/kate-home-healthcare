# 🇭🇰 香港 Hospital at Home / 居家医疗市场

## 一、市场概况

香港的居家医疗与护理市场是一个**以政府资助为主导、公私混合**的生态系统。与美、日、德等国不同，香港没有独立的「Hospital at Home」急性医疗居家模式——医疗端以医院管理局（HA）的**社康护理服务（Community Nursing Service）**和**遥距医疗（Telemedicine）**为延伸，护理端以社会福利署（SWD）的**长者社区照顾服务券（CCSV）**和**院舍照顾服务券（RCSV）**为核心资助工具。

**核心数据速览（2025-2026）**：

| 指标 | 数值 | 来源 |
|------|------|------|
| 65+人口比例 | **23.9%**（约170万人） | 政府统计处 2024 |
| 预测2043年65+比例 | **35%**（约267万人） | 政府统计处人口推算 |
| 人均寿命 | 男**82.8岁** / 女**88.4岁**（全球最高） | 立法会 CB(3)1432/2025(01) |
| 公共医疗开支占GDP | **4.1%**（提供近九成住院服务） | 同上 |
| CCSV社区券（2026-27） | **16,000张**，年开支约**12亿港元** | 2026-27财政预算案 |
| RCSV院舍券（2026-27） | **7,000张**，年开支约**19.7亿港元** | 同上 |
| 注册+登记护士总数 | **75,161人** | 香港护士管理局 2025.12 |

## 二、医疗体系分工

香港医疗体系呈**「双轨制」**结构：

```
公立体系（主导）                          私营体系（补充）
─────────────────                      ─────────────────
医院管理局（HA）                          私立医院（12家）
├─ 43间公立医院/医疗机构                  ├─ 养和/港安/浸会等
├─ 社康护理服务（上门护理）               ├─ 门诊/专科服务
├─ 社区老人评估小组（院舍遥距诊症）       └─ 私营护理机构
├─ HA Go 遥距医疗平台                       （Evercare/Bamboos/QualityCare等）
└─ 电子生命体征系统（25医院专科+40普通科门诊）
                                                
社会福利署（SWD）                           
├─ CCSV社区券 → 认可服务单位（NGO+私营）
├─ RCSV院舍券 → 认可院舍
├─ 广东院舍照顾服务计划（26家粤院舍）
└─ 长者地区中心/邻舍中心/活动中心
```

**关键特征**：
- **医社分离**：HA 负责医疗护理，SWD 负责长期照护，两者分属不同政策局（医务卫生局 vs 劳工及福利局）
- **「居家安老为本、院舍照顾为后援」**：政府政策明确以社区/居家照顾优先
- **「钱跟人走」**：CCSV 和 RCSV 采用需求方补贴模式，长者自主选择服务机构

## 三、安老服务体系全景

香港安老服务分为两大支柱：

### 3.1 社区照顾及支援服务（社区为本）

| 服务类型 | 内容 | 规模（2024-25） |
|---------|------|----------------|
| **长者社区照顾服务券（CCSV）** | 日间护理中心+家居照顾「混合模式」 | 11,000张（2024-25）→ 16,000张（2026-27） |
| 长者日间护理中心/单位 | 日间照顾、康复运动、膳食 | 全港各区 |
| 综合家居照顾服务 | 护理、个人照顾、家务支援 | 覆盖全港 |
| 改善家居及社区照顾服务 | 针对体弱长者 | — |
| 长者地区中心/邻舍中心 | 社区支援、社交活动 | 41间地区中心 + 200+间邻舍中心 |
| 长者日间暂托服务 | 短暂日间照顾 | 300+个服务点（2024.12起） |

## 四、HA 社区护理与遥距医疗服务

### 4.1 社康护理服务（Community Nursing Service）

HA 通过各医院联网的社康护理服务为出院后患者提供上门护理，包括伤口护理、药物管理、导管更换、健康教育等。具体服务量数据需查阅 HA 年报。

### 4.2 遥距医疗（Telemedicine）

- 2022年4月至2025年3月：**超过34万宗**非新冠遥距医疗个案
- 应用场景：社区老人评估小组（院舍遥距诊症）、专职医疗（临床心理）、专科门诊复诊
- 平台：**HA Go** 流动应用程式
- 适用人群：慢性病病情稳定、非新症、无需临床检查的患者
- 监管框架：香港医务委员会《遥距医疗实务道德规范指引》
- 限制：不适用于初诊和新症；长者面临数字鸿沟

来源：[立法会六题：遥距医疗服务的发展](https://www.info.gov.hk/gia/general/202509/10/P2025091000531.htm)

### 4.3 智慧医疗基建

- **电子生命体征系统**：25间专科门诊 + 40间普通科门诊已部署
- **智慧病房**：电子床头显示板、无纸化巡房、数码化心电图
- **HA Go**：一站式预约/缴费/遥距诊症/药物配送
- **医健通（eHR+）**：五年计划升级为综合医疗资讯基建

来源：[立法会 CB(3)1432/2025(01)号文件](https://www.legco.gov.hk/yr2025/cn/panels/ps/papers/ps20251013cb3-1432-1-c.pdf)

## 六、核心挑战

1. **老龄化加速**：65+人口从23.9%升至35%（2043年），劳动人口同期减少
2. **人力短缺**：院舍护理员空缺率约**20%**，需靠外劳（8,300人已批配额至15,000）
3. **医社割裂**：HA 医疗与 SWD 护理各自为政，缺乏整合型居家医疗模式
4. **支付碎片化**：CCSV/RCSV/HA资助/私营自费 四轨并行，无统一支付通道
5. **急性HaH缺失**：香港尚无美国/英国式「Hospital at Home」急性居家医疗模式——HA 社康护理偏慢性/康复，不替代住院
