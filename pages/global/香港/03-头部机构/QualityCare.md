# QualityCare 卓健护理介绍所（香港）

**业务形态：** Bupa 旗下香港最大私营医疗网络的护理转介及居家护理服务（2024.9推出「卓健居家护理」品牌）
**所在国家：** 香港

## 关键数据
- 母公司：Bupa（保柏），全球营收 £140亿+
- 历史：1868年创立 → 1975年成立护理介绍所 → 2013年 Bupa $3.55亿收购
- 网络：1,650+服务点，1,001-5,000员工
- 支付：Bupa保险直付 + CCSV社区券 + 自费

**核心特征**：「保险+医疗+居家护理」三层闭环——香港唯一实现保险直付的护理机构
