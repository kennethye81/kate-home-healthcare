# 荷兰 RPM 与技术设备

**荷兰 eHealth 和数字护理基础设施——欧洲远程医疗的先行者**

## 一、荷兰 eHealth 生态总览

荷兰是全球数字化程度最高的国家之一，其医疗领域的数字基础设施建设在欧洲处于前列。**Nictiz**（国家医疗信息技术研究所）自 2002 年起负责制定国家 eHealth 标准，与 NIVEL（荷兰医疗研究所）联合发布年度 eHealth 监测报告。

**关键数据**（Nictiz eHealth Monitor 2024）：

| 指标 | 数据 | 趋势 |
|------|------|------|
| 患者使用在线门户查看医疗记录 | **~75%** | 稳步增长 |
| 远程视频咨询使用率 | **~50%+** | COVID 后常态化 |
| 居家远程监测覆盖率（慢性病） | 快速增长中 | 政策推动 |
| 电子健康记录（EHR）互联互通率 | **>95%** | 欧洲领先 |
| 医疗 IT 标准采纳（HL7 FHIR） | 积极推广中 | Nictiz 主导 |

## 二、核心技术标准与基础设施

### 2.1 Nictiz —— 国家标准制定者

Nictiz（Nationaal ICT Instituut in de Zorg）是荷兰卫生、福利与体育部（VWS）下属的国家级研究所，核心职能：

| 职能 | 内容 |
|------|------|
| 标准制定 | 医疗信息交换标准（HL7 FHIR、SNOMED CT、OMAHA 等） |
| 互操作性框架 | 全国统一的信息交换架构 |
| eHealth 监测 | 与 NIVEL 联合发布年度 eHealth Monitor |
| 实施指导 | 为医疗机构提供标准实施支持和最佳实践 |
| 国际对接 | 与欧盟 eHealth Network、WHO 对接 |

### 2.2 MedMij —— 个人健康环境

MedMij 是荷兰的个人健康数据交换框架，类比于苹果 HealthKit 的国家级版本。核心理念是：**每位公民拥有一个安全、私密的个人健康环境（PGO, Persoonlijke Gezondheidsomgeving）**，可从中获取、管理并与医疗服务提供者共享自己的健康数据。

**MedMij 核心标准**：
- 基于 HL7 FHIR（快速医疗互操作性资源）标准
- 授权机制（OAuth 2.0 / OpenID Connect）
- 通过 MedMij 认证的 app 和服务方可接入
- 数据所有权归公民，公民决定共享范围

### 2.3 AORTA / LSP —— 国家医疗信息交换网络

AORTA 是荷兰的国家医疗 IT 基础设施，由 **VZVZ**（Vereniging van Zorgaanbieders voor Zorgcommunicatie）运营。通过 LSP（Landelijk Schakelpunt，国家交换节点），全科医生（GP）、药房、医院和急诊部门可安全交换患者数据。

| 维度 | 说明 |
|------|------|
| 覆盖范围 | 全国 GP、药房、医院急诊部 |
| 数据类型 | 用药记录、GP 摘要、过敏/禁忌 |
| 接入控制 | 患者主动授权（opt-in）+ 医疗人员 UZI 卡认证 |
| 技术 | 基于 HL7v3 和 NEN 标准 |

## 三、远程监测与居家护理技术

### 3.1 远程患者监测（RPM）发展

荷兰在 COVID-19 疫情期间加速了远程监测的推广，特别是在以下领域：

| 领域 | 应用 | 技术手段 |
|------|------|----------|
| 慢性心衰 | 体重、血压、心率远程监测 | 蓝牙设备 + app 平台 |
| COPD | 血氧饱和度、肺功能远程追踪 | 脉搏血氧仪 + 症状日记 app |
| 糖尿病 | 血糖远程监测 | 连续血糖监测（CGM）+ 数据共享 |
| 术后康复 | 远程伤口评估、康复指导 | 影像上传 + 视频随访 |
| 失智症 | GPS 追踪、跌倒检测、药物提醒 | 可穿戴设备 + 智能家居传感器 |
| 产前/产后 | 远程血压、胎心监测 | 家用监测设备 + app |

### 3.2 远程护理平台与供应商

荷兰远程监测/居家护理技术供应商生态（代表性企业）：

| 供应商 | 业务 | 说明 |
|--------|------|------|
| **Luscii** | 远程监测平台 | 荷兰公司，面向医院和社区护理的远程患者监测平台，用户覆盖欧洲多国 |
| **Philips** | 综合远程护理 | 荷兰总部，提供 Hospital at Home 整体解决方案和远程 ICU（eICU） |
| **FocusCura** | 居家护理数字平台 | 为社区护理团队提供电子健康记录和远程监测整合方案 |
| **Nedap Healthcare** | 护理机构 IT | 为护理院和居家护理提供电子护理记录和排班平台 |
| **Sensara** | 智能居家传感器 | 基于行为模式分析的老年人居家安全监测 |
| **MijnEigenPlan** | 护理计划共享 | 患者和护理人员协作的电子护理计划平台 |

### 3.3 Buurtzorg 的技术实践

Buurtzorg 自行开发的 **BuurtzorgWeb** 平台是社区护理数字化的标杆案例（详见 [[reports/国家/荷兰/2026-07-03-buurtzorg-model-analysis.md|Buurtzorg 报告]]）：

| 功能 | BuurtzorgWeb 的实践 |
|------|--------------------|
| 患者评估 | 基于 OMAHA 分类系统的结构化评估 |
| 护理计划 | 线上创建、共享和追踪 |
| 排班与访问 | 团队自主排班、实时更新 |
| 绩效仪表盘 | 团队可见关键指标（护理时间、患者结果） |
| 账单生成 | 对接荷兰保险系统自动生成 |
| 同行学习 | 跨团队共享最佳实践库 |

**关键启示**：BuurtzorgWeb 不追求技术先进性——它追求的是信息透明化和团队自主权的技术支撑。平台为团队服务，而非监控团队的手段。

## 四、政策与投入

### 4.1 国家 eHealth 政策

荷兰政府通过 **「正确地点提供正确照护」**（Juiste Zorg op de Juiste Plek, JZOJP）战略推动居家护理数字化，核心目标：

| 目标 | 措施 |
|------|------|
| 2025 年 50% 慢性病护理实现远程 | 取消远程护理的保险障碍 |
| 全国 PGO 覆盖 | MedMij 标准强制推广 |
| 医院床位替代 | 远程监测 + 社区护理 = 「数字床位」 |
| 数据流通 | 全国统一信息交换标准 |

### 4.2 投入与报销

| 支付方 | 覆盖内容 | 条件 |
|--------|----------|------|
| Zvw | 远程监测属于常规护理覆盖 | 需经社区护士评估和处方 |
| WLZ | 辅助设备和技术支持 | 含在照护包或 PGB 中 |
| Wmo | 智能居家安全设备 | 市政自定（差异大） |
| 创新基金 | ZonMw eHealth 专项资助 | 研究机构和创新企业 |

## 五、ZonMw eHealth 研究资助

ZonMw（荷兰健康研究与发展组织）是 eHealth 研究的主要资助方，代表性项目包括：

- **「eHealth 自我管理」** 计划——资助远程监测工具在慢性病患者自我管理中的应用研究
- **「数字化照护创新」**——支持社区护理中的技术解决方案开发和评估
- **SET（Sustainable employability of eHealth）**——远程监测技术的成本效果分析

## 六、与中国 RPM/数字医疗体系的对比

| 维度 | 荷兰 | 中国 |
|------|------|------|
| 国家标准 | Nictiz + MedMij（FHIR） | 各地医保标准碎片化 |
| 个人健康数据所有权 | 公民（MedMij 框架） | 仍在建立中 |
| EHR 互联互通 | >95%（AORTA/LSP） | 医院内较好，跨院薄弱 |
| RPM 保险覆盖 | 纳入常规 Zvw 护理 | 部分城市试点 |
| 平台生态 | Luscii/Philips/FocusCura 活跃 | 平安好医生/微医等平台主导 |
| 社区护理数字化 | BuurtzorgWeb 标杆 | 多数仍为纸质/简单电子表格 |
