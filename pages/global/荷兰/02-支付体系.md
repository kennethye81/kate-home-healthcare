# 荷兰 支付体系

**三级支付、三套评估、三种自付——荷兰居家医疗的资金架构**

## 一、总览：三级支付体系

```
┌─────────────────────────────────────────────────────────┐
│                荷兰居家医疗/社区护理资金来源               │
├───────────────┬─────────────────┬───────────────────────┤
│     WLZ       │       Zvw       │        Wmo 2015       │
│   长护险法     │    医疗险法      │     社会支持法         │
├───────────────┼─────────────────┼───────────────────────┤
│ 覆盖：24h监护 │ 覆盖：社区护理   │ 覆盖：家务/日间/出行    │
│ 评估：CIZ     │ 评估：社区护士   │ 评估：市政府           │
│ 执行：Zorg-   │ 支付：保险公司   │ 支付：市政府预算        │
│ kantoor       │ 自付：€385免赔  │ 自付：收入分级制        │
├───────────────┼─────────────────┼───────────────────────┤
│ 资金：强制社保 │ 资金：保费+补贴  │ 资金：中央拨款→市政      │
│ (工资税+保费) │                 │                       │
└───────────────┴─────────────────┴───────────────────────┘
```

2024 年荷兰医疗健康总支出 **€1,135 亿**（占 GDP 10.0%），其中 WLZ 增长 11%、Zvw 增长 7.9%（CBS 2025）。

## 二、WLZ 支付体系

### 2.1 CIZ —— 照护需求评估中心

CIZ（Centrum Indicatiestelling Zorg）是 WLZ 的独立准入评估机构。所有 WLZ 照护需经 CIZ 评估后方可获得。

**评估流程**：
1. 申请人（或代理人/GP/医院转介）向 CIZ 提交申请
2. CIZ 派出评估员进行家访或多学科评估
3. 评估员根据标准化框架判断四个核心问题：
   - 是否需要 **24 小时就近照护**？
   - 照护需求是否属于 WLZ 覆盖范围？
   - 预期照护时长是否超过 3 年？
   - 其他保险（Zvw/Wmo）是否可覆盖？
4. CIZ 在 6 周内做出决定并出具 **WLZ 照护需求评定书**（WLZ-indicatiebesluit）

**CIZ 评定内容**：
- 照护档案（zorgprofiel）：标准化的照护需求分类（如 VV4=失智症需庇护居住、VV6=重度身体照护需求）
- 照护强度等级
- 是否适用于居家照护（VPT/MPT/PGB）

### 2.2 Zorgkantoor —— 区域照护办公室

Zorgkantoor（照护办公室）是 WLZ 在各区域的执行机构，全国共 **31 个**（由各大健康保险公司以区域独占方式运营）。

**核心职能**：

| 职能 | 说明 |
|------|------|
| 照护采购 | 与护理机构和居家照护提供者签订合同 |
| 预算管理 | 管理 WLZ 区域预算 |
| PGB 管理 | 审批和发放个人预算 |
| 照护协调 | 帮助受益人选择合适的照护提供者 |
| 质量监督 | 与 IGJ 合作监督照护质量 |
| 等候名单管理 | 协调机构护理等候名单 |

**与保险公司的区别**：Zorgkantoor 不是竞争性保险公司，而是 WLZ 法定的区域垄断执行机构。居民不能选择自己的 Zorgkantoor——由居住地址决定。

### 2.3 WLZ 支付模式与费率

| 支付模式 | 说明 |
|----------|------|
| ZIN（Zorg in Natura） | 实物给付——由与 Zorgkantoor 签约的机构直接提供服务，受益人无需经手资金 |
| PGB（Persoonsgebonden Budget） | 个人预算——受益人自行采购服务，可雇佣非正式照护者（如家人） |
| VPT（Volledig Pakket Thuis） | 全额居家照护包——在居家环境中获得机构等同照护，费率约为机构照护的 **75-80%** |
| MPT（Modulair Pakket Thuis） | 模块化居家照护——按需组合服务模块 |

**2024 年 WLZ 支出**：€310 亿级别（占医疗总支出约 27%），增速 11%——是所有类别中最快。

## 三、Zvw 支付体系

### 3.1 社区护理（Wijkverpleging）

Zvw 下社区护理的支付特点是：
- **不受强制自付额限制**——政策明确激励居家护理
- 按 **护理分段/小时**付费
- 健康保险公司与护理提供者谈判费率和质量指标
- 全国统一的基础保险包内容由 Zorginstituut Nederland（ZIN）认定

**典型支付流程**：
```
患者/GP 提出需求 → 社区护士评估（wijkverpleegkundige indicatie）
  → 制定护理计划 → 提供服务 → 向保险公司提交账单
  → 保险公司审核支付 → 患者0自付（社区护理免自付）
```

### 3.2 强制自付机制

| 项目 | 2025 年标准 | 说明 |
|------|-------------|------|
| 强制自付额（Verplicht eigen risico） | **€385/年** | 政府每年调整 |
| 自愿自付额（Vrijwillig eigen risico） | 最高 **€500/年** | 可降低保费 |
| 社区护理免自付 | ✅ 全额免除 | 政策激励居家护理 |

## 四、Wmo 2015 支付体系

### 4.1 自付机制（Eigen bijdrage Wmo）

Wmo 2015 的自付额由 **CAK（Centraal Administratiekantoor）** 统一计算和征收，按以下因素确定：

| 因素 | 说明 |
|------|------|
| 收入 | 包括 AOW 养老金、补充养老金、其他收入 |
| 资产 | 储蓄和投资（自住房价值除外） |
| 家庭构成 | 单身/夫妻 |
| 年龄 | 退休年龄以下/以上均有不同计算规则 |
| 服务使用量 | 实际使用的 Wmo 服务量 |

**2025 年 Wmo 自付上限**：单身户每月约 **€21.90**，夫妻户每月约 **€31.30**（具体数字每年调整）。低收入者可申请减免。

### 4.2 市政府预算

市政府年度 Wmo 预算来自中央政府的 **市政基金（Gemeentefonds）**，分配公式考虑人口结构、社会弱势程度等因素。关键挑战是：
- 各市 Wmo 预算差异大——富裕城市 vs 农村
- 2015 年以来，中央政府伴随职能下放同时削减了约 15-25% 的拨款
- 地方自付压力逐年增加

## 五、PGB —— 个人预算

PGB（Persoonsgebonden Budget）是荷兰长护/照护体系中独特的个人化支付工具，可在 WLZ、Zvw、Wmo 三个体系中使用。

### 5.1 PGB 运作机制

```
CIZ 评定照护需求水平
  → 受益人选择 PGB 而非 ZIN（实物给付）
    → Zorgkantoor（WLZ）/ 保险公司（Zvw）/ 市政府（Wmo）核定 PGB 金额
      → 受益人开设专用银行账户（通过 SVB 社会保険银行）
        → 受益人自行采购服务、签订合同
          → SVB 代受益人支付服务提供者工资/费用
            → 受益人提交服务记录和支出报告
```

### 5.2 PGB vs ZIN 对比

| 维度 | PGB（个人预算） | ZIN（实物给付） |
|------|----------------|----------------|
| 选择自由度 | 高——可自选提供者、雇佣家人 | 低——必须使用签约机构 |
| 预算灵活性 | 高——按需分配服务组合 | 低——提供者决定服务方案 |
| 行政复杂度 | 高——需自行管理合同、报告 | 低——提供者处理行政 |
| 支付额度 | 约为 ZIN 的 **65-75%** | 全额照护成本 |
| 适用人群 | 能自我管理或由代表管理 | 所有受益人 |

### 5.3 关键数据

- 约 **15-20%** 的 WLZ 受益人选择 PGB
- PGB 人均金额低于 ZIN（受益人以更少预算灵活配置）
- PGB 可雇佣家庭成员（包括同居配偶），但费率低于正式护理人员

## 六、资金流的宏观协调

**风险均衡基金（Risicoverevening）**：Zvw 体系的核心平衡机制。所有 Zvw 保费收入进入全国风险均衡基金，再按各保险公司参保人的年龄、性别、健康状况、收入等风险因子重新分配。这确保了保险公司竞争不演变为「挑年轻健康人、拒老年人」。

| 资金池 | 来源 | 分配机制 |
|--------|------|----------|
| WLZ | 工资税（Wlz-premie）+ 部分保费 | 按区域人口分配给 31 个 Zorgkantoor |
| Zvw | 名义保费 + 雇主缴费 + 政府补贴 | 风险均衡基金→保险公司 |
| Wmo | 中央政府→市政府 | 按人口和社会指标公式分配 |

## 七、与中国长护险支付体系的对比

| 维度 | 荷兰 | 中国 |
|------|------|------|
| 支付层级 | 三级独立（WLZ/Zvw/Wmo） | 单一长护险（社保第六险） |
| 评估机构 | CIZ（独立、全国统一） | 各地医保局委托评估（差异大） |
| 个人预算 | PGB 成熟使用 20+ 年 | 极少（上海等地试点） |
| 社区护理免自付 | ✅（Zvw 政策激励） | 各地标准不一 |
| 支付方竞争 | 保险公司+Zorgkantoor | 医保局单一支付 |
| 实物/现金选择 | PGB vs ZIN 并存 | 以实物为主 |
