# 荷兰 — 支付体系

## 一、支付模型全景

荷兰 LTC 为**「强制社会保险 + 强制私营医保 + 市政税收」三层公共支付**——OECD 中 LTC 公共支出占 GDP 最高的国家之一（~4.1%）。

```
                ┌──────────────────────────────┐
                │      荷兰 LTC 支付体系         │
                └──────────────────────────────┘
                                │
        ┌───────────┬───────────┼───────────┬──────────┐
        ▼           ▼           ▼           ▼          ▼
      WLZ        Zvw          Wmo         自付      私营
    (重度长期)  (社区护理)  (居家帮助)    (有限)    (补充)
```

| 支付通道 | 资金 | 月费率/税 | 负责方 |
|---------|------|:---:|------|
| **WLZ** | LTC 强制保险费 | 工资的 **9.65%** | Zorgkantoor（地区照护办公室） |
| **Zvw** | 私人医保保费+国家基金 | ~€140/月（名义保费）+ 雇主缴费 | 保险公司 |
| **Wmo** | 市政税收 | — | 342 个市政 |
| **自付** | 个人 | WLZ: 按收入分级; Wmo: 市政自行设定 | — |

## 二、WLZ — 长期护理支付

| 指标 | 数据 |
|------|:---:|
| 2023 总支出 | ~**€280亿** |
| 受益人数 | ~**25万** |
| 支付方式 | Zorgprofielen（照护画像）——按需分层 |
| 机构照护 | 护理院人均 ~€80,000-100,000/年 |
| 重度居家 | Modulair Pakket Thuis (MPT) 或 Persoonsgebonden Budget (PGB) |
| 自付（Eigen Bijdrage） | CAK（中央管理办公室）按收入+资产确定——最高 ~€2,700/月 |

### PGB — 个人预算

WLZ 受益人可申请 **PGB（Persoonsgebonden Budget）**——由个人管理预算、自行购买照护服务（包括雇用家庭成员）。年预算因人而异，平均 ~€20,000-50,000/年/人。

---

## 三、Zvw — 社区护理支付

| 维度 | 内容 |
|------|------|
| 支付方 | 私人保险公司（Zorgverzekeraars） |
| 采购方式 | 保险公司与护理机构签约——按小时/按结果付费 |
| 患者自付 | **€0**——2020年起免除基准自付（Eigen Risico/€385） |
| 覆盖范围 | 注册护士（Wijkverpleegkundige）的上门护理——不限小时 |

---

## 四、Wmo — 市政支付

| 维度 | 内容 |
|------|------|
| 资金 | 市政税收 + 国家市政基金（Gemeentefonds） |
| 自付 | 市政自行设定——通常按收入分级（~€19/月固定费或按次收费） |
| 特点 | 342 个市政各自独立→**市际差异显著** |

---

## 五、费用水平

| 服务 | 月成本 | 个人自付 |
|------|:---:|------|
| Wijkverpleging（社区护理） | €3,000-6,000 | €0 |
| Wmo 居家帮助 | €1,000-3,000 | ≤€19/月 |
| WLZ 护理院 | €5,000-9,000 | 按收入+资产（最高 €2,700/月） |
| PGB 个人预算 | €20,000-50,000/年 | 0-€2,700/月 |
