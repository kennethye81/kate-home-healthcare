## 二、医疗/长护险制度框架

荷兰医疗体系以**强制社会健康保险**为核心：

### 基本健康保险（Zvw — Zorgverzekeringswet）

| 维度 | 说明 |
|------|------|
| **覆盖** | 所有荷兰居民强制参保 |
| **运营** | 私营保险公司受政府严格监管 |
| **基本包** | 涵盖GP、医院、药品、部分远程医疗和RPM服务 |
| **自付** | 年度免赔额（eigen risico）~€385（2024年） |

### 长期护理保险（Wlz — Wet langdurige zorg）

| 维度 | 说明 |
|------|------|
| **覆盖** | 需要24/7长期照护的严重失能/失智人群 |
| **资金** | 税收+保费 |
| **服务** | 护理院、居家护理中的远程监护设备 |

### 关键机构

| 机构 | 职责 |
|------|------|
| **VWS（卫生、福利与体育部）** | 政策制定 |
| **NZa（荷兰医疗管理局）** | 费用监管、报销标准制定 |
| **Zorginstituut Nederland** | 基本包评估与质量管理 |
| **Nictiz** | 国家医疗IT标准化中心 |

### 政策方向

- 「**Thuis in plaats van in het ziekenhuis**」（居家代替住院）——国家医疗转型战略核心
- **Toekomstagenda Zorg**（未来议程，2022）：计划到2030年新增**50,000名**护理人员，重点布局居家护理

## 三、居家医疗/HaH 市场概况

荷兰居家医疗/居家护理市场以 **Buurtzorg 模式** 为核心特征，同时存在多元化的RPM市场和数字健康生态。

### Buurtzorg 核心数据

| 指标 | 数据 |
|------|------|
| **创立时间** | 2006年（创始人Jos de Blok） |
| **护理专业人员** | **~15,000人**（>95%为注册护士） |
| **自管理团队** | **~1,200个**（每队10–12人） |
| **覆盖患者** | **~10万名**居家护理患者 |
| **市场占有率** | 荷兰居家护理市场约**60–70%** |
| **管理成本占比** | **8%**（传统机构~25%） |
| **间接成本率** | **~8%**（行业典型25–40%） |
| **患者满意度** | **9.1/10**（高于行业30%） |
| **护士职业倦怠率** | **10%**（传统机构~33%） |
| **年离职率** | **7–10%**（传统机构20–25%） |
| **每患者护理时长** | **30分钟/次**（传统机构15分钟/次） |
| **总成本节约** | 比传统机构**低30–40%**（主因住院和急诊减少） |

### 数字健康/RPM市场

| 指标 | 数据 |
|------|------|
| 数字健康市场规模（2025估） | **€15–20亿** |
| 年均增长率 | **10–15%** |
| 家庭宽带接入率 | **>98%** |
| 国家EHR交换平台 | LSP（Landelijk Schakelpunt）连接医院、药房、GP、居家护理 |

### 医保覆盖RPM

| 维度 | 说明 |
|------|------|
| **Zvw覆盖** | 远程问诊和特定慢性病（如心衰）远程监测 |
| **Wlz覆盖** | 居家护理中的远程监护设备成本 |
| **自费市场** | 健康追踪器、跌倒检测等由补充保险或自费 |
| **支付方式** | 远程问诊按consult计费；RPM按患者/月付费 |
| **2025动态** | NZa正在制定新的远程护理报销标准 |

## 五、04/05/06 核心数据摘要

### 04-RPM与技术设备

| 指标 | 数据 |
|------|------|
| BuurtzorgWeb平台 | 自研云原生护理管理系统（SaaS），~15,000名护士使用 |
| Omni患者端应用 | iOS/Android，护理计划查看、团队通讯、健康提醒 |
| 管理效率 | 护士每周行政事务**~1.5小时**（传统机构3–4小时） |
| 互操作性标准 | HL7 FHIR（NL FHIR Core）、ZIB临床信息模型、NEN 7510信息安全标准 |
| LSP国家交换平台 | 连接医院、药房、GP、居家护理机构 |
| Philips心衰RPM研究（UMC Utrecht） | 30天再入院率降低**30%** |
| Luscii COPD远程监测研究 | 急性加重住院减少**25%** |
| Buurtzorg+技术赋能研究（Erasmus） | 工作效率提升**40%** |

### 05-临床证据

| 维度 | 关键数据 |
|------|---------|
| Buurtzorg总费用节约 | **低30–40%**（vs传统居家护理） |

> **赛道成熟度评估**：★★★★★（全球标杆）。荷兰以**Buurtzorg自管理团队模式**在全球居家护理领域树立了效率和质量的双重标杆。其**8%的间接成本率**、**9.1/10的患者满意度**、**30–40%的总成本节约**是业界难以超越的基准。RPM市场由Philips（本土龙头）和ChipSoft（EMR基础设施占有60–70%市场）双轮驱动，数字健康市场以10–15%的年增长率持续扩张。主要挑战：护理人力短缺（全行业~45,000空缺）、居家护理与医院护理的薪资差距、人口老龄化加速（65+已占20%）。

> **对iHomeCare的关键启示**：自管理团队架构（直接护理时间≥60%硬指标）、极简后台（≤1:100后台/一线比）、ICT平台作为赋能使能器（非控制工具）、教练替代管理者角色、「人道高于官僚」组织文化。
