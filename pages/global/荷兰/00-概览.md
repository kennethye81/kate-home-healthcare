# 🇳🇱 荷兰 居家医疗/社区护理市场全景

**法律框架：** WLZ 长护险 + Zvw 医疗险 + Wmo 社会支持 三级体系
**核心特色：** Buurtzorg 自管理护理团队模式——全球居家护理运营效率标杆
**居家优先原则：** "Eerst thuis"（先居家）是国家政策核心

## 一、市场概况

荷兰是全球长护险制度的先驱——WLZ（Wet langdurige zorg）于 1968 年施行，是世界最早的长护险之一。2024 年荷兰医疗健康总支出 **€1,135 亿**，占 GDP **10.0%**（CBS 2025 年报告）。其中 WLZ 长护险支出同比增长 **11%**，Zvw 医疗险支出增长 **7.9%**，自付支出增长 7.5%（CBS, 2025）。

根据 Custom Market Insights 数据，荷兰长护市场 2025 年以公共支付方占 **57%** 份额，预计 2026-2035 年 CAGR **5.37%**，临终关怀（hospice）细分增长最快（CAGR 7.12%）。

## 二、三级体系架构

荷兰的居家医疗/社区护理由三个独立法律框架覆盖，形成清晰的「三级分工」：

```
WLZ（长护险法，1968/2015）
├─ 覆盖：重度、24 小时需要监护的人群
├─ 资金：强制社会保险（工资税 + 保费）
├─ 管理：CIZ 评估 → Zorgkantoor 区域执行
├─ 服务：机构护理 + 居家护理（VPT/MPT/PGB）
└─ 自付：按收入分级（eigen bijdrage）

Zvw（医疗险法，2006）
├─ 覆盖：社区护理（wijkverpleging）、全科医疗、医院
├─ 资金：法定健康险（保费 + 政府补贴）
├─ 管理：健康保险公司竞争
├─ 服务：社区护士上门护理（伤口、注射、用药管理等）
└─ 自付：强制自付额 €385/年（2025）

Wmo 2015（社会支持法）
├─ 覆盖：家务帮助、日间活动、出行工具、住房改造
├─ 资金：市政预算（中央拨款）
├─ 管理：市政府（gemeente）
├─ 服务：非医疗性日常生活支持
└─ 自付：按收入/资产（市政自定）
```

**关键特征**：三级体系在制度上完全独立——资金池不同、管理机构不同、评估机构不同。但 2015 年改革后，「居家优先」原则贯穿三级，目标是在最低成本层级解决照护需求。

## 三、Buurtzorg 模式及其影响

Buurtzorg Nederland（荷兰语「邻里照护」）由护士出身的 Jos de Blok 与三位同事于 **2006 年**创立，是荷兰乃至全球最具影响力的社区护理创新。

**核心特征**（详见 [[03-头部机构/Buurtzorg|Buurtzorg 导航卡]] 及 [[reports/国家/荷兰/2026-07-03-buurtzorg-model-analysis.md|27 维深度分析报告]]）：

| 特征 | Buurtzorg | 行业对比 |
|------|-----------|---------|
| 中层管理者 | **0** | 多层管理架构 |
| 间接成本率 | **~8%** | 25%-40% |
| 后台/一线比 | **1:280** | 通常 1:50-100 |
| 团队规模 | ≤12 人 | 不固定 |
| 护士直接护理时间 | **62%**（硬指标） | 行业常低于 50% |
| 患者满意度 | **9.1/10** | 行业约 7.0 |
| 每患者护理小时 | 比同行少 **50%-67%** | 基准 |

**行业影响**：Ernst & Young（2010）估算若全荷兰采用 Buurtzorg 模式可节省约 **40%** 医保支出。该模式已启发 25 个国家的护理机构采用或改编。

## 四、2015 年去机构化改革

2015 年是荷兰居家医疗体系的分水岭。三大法律同时经历重大改革：

1. **WLZ 范围收窄**：从覆盖中度照护收窄至仅覆盖「24 小时需要永久监护」的重度人群
2. **Zvw 承接社区护理**：原属 AWBZ（WLZ 前身）的社区护理（wijkverpleging）转移至 Zvw，由健康保险公司管理
3. **Wmo 2015 全面启动**：非医疗性日常支持（家务、日间活动等）从国家保险下放至市政府

改革核心理念：**「从照护型国家到参与型社会」**（van verzorgingsstaat naar participatiesamenleving）。政府期望更多人居家养老、由家庭和社区网络承担更多非正式照护。

## 五、市场规模与增长动力

| 驱动因素 | 描述 |
|----------|------|
| 人口老龄化 | 65+ 占比从 2020 年 19.5% 预计升至 2040 年 ~26% |
| 居家优先政策 | 政府持续推动减少机构照护、增加居家服务 |
| 护理人力成本上升 | 推动效率和模式创新（如 Buurtzorg 式去管理层） |
| eHealth 投入增加 | 远程监测和数字护理成为居家替代机构的使能器 |
| 公共支出压力 | WLZ 支出增速（11%）远超 GDP 增速，改革压力持续 |

## 六、核心挑战

1. **三级体系碎片化**——WLZ/Zvw/Wmo 三个制度、三个评估、三个支付方增加了协调成本
2. **劳动力短缺**——社区护士（wijkverpleegkundigen）和护理员（verzorgenden）供给严重不足
3. **非正式照护压力**——政府期望家庭承担更多，但家庭规模缩小、女性劳动参与率上升形成矛盾
4. **Buurtzorg 模式可复制性**——其成功高度依赖荷兰特有的社会文化环境和支付体系
