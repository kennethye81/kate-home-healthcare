# 巴西 — 支付体系

## 一、支付模型全景

巴西居家/长期护理支付为**「SUS 税收资助为主 + 私营保险补充 + 自费+家庭照顾」**结构。由于无独立 LTC 保险，支付严重碎片化。

```
                     ┌──────────────────────────────┐
                     │     巴西 LTC 支付体系          │
                     └──────────────────────────────┘
                                    │
            ┌──────────┬────────┬───┴───┬──────────┐
            ▼          ▼        ▼       ▼          ▼
          SUS       SUAS     私营保险  自费      家庭照顾
       (税收资助) (社会援助) (雇主)  (市场化)  (无偿/非正式)
```

| 支付通道 | 管理机构 | 覆盖 | 支付方式 |
|---------|---------|------|---------|
| **SUS 居家护理** | 联邦+市卫生局 | Melhor em Casa（AD1/AD2/AD3） | 税收资助，免费 |
| **SUAS 社会援助** | 市社会援助局 | 脆弱老年人社区照护 | 税收资助 |
| **私营保险** | ANS 监管 | 5,220 万人（~25%） | 雇主/个人保费 |
| **自费** | 个人/家庭 | ILPIs 养老院、私营居家护理 | 市场价 |
| **家庭照顾** | 非正式 | 主要模式 | 无偿 |

## 二、SUS 支付机制

### 2.1 资金来源

| 来源 | 说明 |
|------|------|
| 联邦税收 | 联邦政府通过一般税收拨款，设定全国最低标准 |
| 州级税收 | 各州补充拨款 |
| 市级税收 | 各市执行服务提供——资金和管理权力下放至 5,570 个市 |

### 2.2 SUS 服务免费范围

所有居民（含访客和无证移民）免费获得：
- 初级保健（社区卫生站）
- 专科门诊
- 住院治疗
- 处方药
- **Melhor em Casa 居家护理**（AD1-AD3，视城市覆盖而定）
- 心理健康服务
- 免疫接种

### 2.3 SUS 支出

| 指标 | 数据 |
|------|:---:|
| 健康支出占 GDP | ~**9.6%** |
| 政府支出占比 | **45%**（2022） |
| 人均健康支出 | ~**$1,200 美元/年**（远低于OECD平均） |

## 三、居家护理支付

### 3.1 SUS Melhor em Casa 的支付逻辑

Melhor em Casa 通过 SUS 常规预算支付——**无独立的居家护理支付编码或基金**。各市根据自身财政能力决定覆盖范围和投入力度。

| AD 类别 | 支付来源 | 自付 |
|:---:|------|:---:|
| AD1 | SUS 初级保健预算 | $0 |
| AD2 | SUS + 市级补充 | $0 |
| AD3 | SUS + 市级补充 | $0 |

**关键限制**：SUS 服务的覆盖面严重依赖**城市财政能力**——富裕城市（如圣保罗）和贫困城市（如东北部小城）的居家护理服务差距巨大。

### 3.2 私营居家护理自费

| 服务 | 月费范围（R$） | 折合美元 |
|------|:---:|:---:|
| 私营居家护理员（全职） | R$ 2,000-5,000 | $400-1,000 |
| 私营注册护士上门 | R$ 100-300/次 | $20-60 |
| ILPI 养老院（基础） | R$ 1,500-3,500 | $300-700 |
| ILPI 养老院（优质） | R$ 5,000-12,000 | $1,000-2,400 |

## 四、私营健康保险

### 4.1 规模

- **5,220 万**巴西人拥有私营医疗保险（2024）——占总人口约 25%
- 另有 3,450 万人拥有纯牙科计划
- 绝大多数由**雇主提供**（企业福利）
- 监管：国家补充健康局（ANS，Agência Nacional de Saúde Suplementar）

### 4.2 私营保险的 LTC 覆盖

⚠️ 巴西私营健康保险**一般不覆盖长期护理（LTC）或居家护理**。保险主要覆盖急性医疗（住院+专科+检查），长期护理依赖自费或家庭。

## 五、ILPIs（养老院）支付

巴西的 ~3,500 家 ILPIs 的支付来源：

| 支付方 | 占比（估） | 说明 |
|--------|:---:|------|
| 家庭自费 | ~70% | 市价支付 |
| 慈善/宗教资助 | ~15% | 传统模式 |
| 政府补贴 | ~10% | 市政对低收入长者的有限补贴 |
| SUS/SUAS | ~5% | 部分长期住院患者的转介 |

---

## 六、家庭照顾——隐性支付

巴西文化中家庭（尤其是女性）是 LTC 的主要提供者——这是巴西 LTC「体系」的**隐性支柱**。随着女性劳动参与率上升和小家庭化，这一模式正面临根本性冲击。

## 七、支付体系 SWOT

| | 优势 | 劣势 |
|------|------|------|
| | • SUS 全民覆盖——**免费是法律权利** | • **无 LTC 专项支付**——SUS 拨款无法单独追踪 LTC |
| | • Melhor em Casa 是政府主导的居家医疗方案 | • 市际差距巨大——贫困地区居家护理几乎空白 |
| | • 私营保险覆盖 25% 人口——中产阶级有替代 | • 私营保险**不覆盖 LTC** |
| | **机遇** | **威胁** |
| | • 老龄化速度空前——政策窗口正在打开 | • 财政紧缩可能限制 SUS 扩展 |
| | • 数字健康（TeleSUS/远程监测）可降低边际成本 | • 政治不确定性——巴西近年政局动荡 |
| | • 中产阶级增长→自费高端居家护理需求 | • ILPIs 质量危机——多起虐待丑闻 |
