## 二、医疗/长护险制度框架

巴西医疗体系是独特的**双轨结构**（1988年宪法确立）：

### SUS（Sistema Único de Saúde）— 公立统一卫生系统

| 维度 | 说明 |
|------|------|
| **覆盖** | 100%巴西居民（宪法权利），实际依赖者约**75%**（~164M） |
| **资金** | 联邦+州+市税收三方分摊，**全额免费** |
| **治理** | 联邦（卫生部）→ 26州 → 5,570个市 |
| **ESF（家庭健康战略）** | 世界最大社区医疗项目，**33,000+**多学科团队，覆盖**65–70%**人口 |
| **社区健康代理人（ACS）** | **~236,000人**（在eSF团队中），全球最大的社区级\"最后一公里\"触角 |

### Saúde Suplementar — 补充医疗（私人保险）

| 维度 | 说明 |
|------|------|
| **覆盖** | ~**25%**人口（52.2M人） |
| **监管** | ANS（补充医疗国家监管局） |
| **主要模式** | 雇主提供计划占主导（>70%） |
| **支付方式** | 按服务收费（FFS）为主 |

### Melhor em Casa（Better at Home）

巴西的公立HaH项目，创建于2011年（Portaria GM/MS No. 2.527/2011），是SUS内正式的**住院替代服务**。核心特征：

- 定位：**\"替代或补充住院的服务\"** — 急性后期/亚急性期医疗级介入
- 三种团队配置：**EMAD Tipo I/II**（多学科居家护理团队）+ **EMAP**（多学科支持团队）
- 2024年新增**EMAP-R**（康复支持团队），面向小城市
- 2024年预算：**R$ 895.5百万**（三方分摊）
- 累计转移支付（2011–2023）：**~R$ 5.2 B**
- 居家治疗成本比住院**低约70%**（巴西卫生部数据）

| 层级 | 服务类型 | 提供者 |
|------|---------|--------|

### 05-临床证据

| 维度 | 关键数据 |
|------|---------|
| Melhor em Casa成本效益 | 居家治疗成本比住院**低70%**，临床效果无显著差异 |

### 06-劳动力市场

| 指标 | 数据 |
|------|------|
| ACS+ACE总数 | **402,777人**（2024年） |
| 家庭医疗团队（eSF）数 | **33,000+** |
| ACS人均负责家庭 | 约100–150户 |
| EMAD团队配置 | 医生+护士+护理技士+物理治疗师或社工 |
| EMAP团队 | 最少3名不同专业（营养、牙医、药剂、言语、心理、作业治疗） |
| ESF覆盖率目标（2026） | **80%**实际覆盖率 |
| 劳动力挑战 | 护士/护工在主要城市以外严重不足、高流动性、ACS职业倦怠 |
| 薪资压缩 | SUS有政府预算限制，私人市场面临盈利压力 |
| 培训标准不统一 | 私人居家护理行业缺乏标准化资质认证 |

> **赛道成熟度评估**：巴西居家医疗市场处于**快速扩张期**。Melhor em Casa（公立HaH）自2011年建立以来团队数增长~3,000%，覆盖已达所有26州。双轨结构（SUS+补充医疗）为新兴市场HaH提供了完整参照模型。核心优势包括ESF社区健康代理人网络的全球独特性、2022年远程医疗正式法律化、以及加速的市场整合趋势。主要挑战包括联邦制碎片化（5,570个市执行力参差不齐）、联邦支出上限（EC 95）限制SUS预算增长、专业人力短缺。

> **对iHomeCare的关键启示**：双轨结构战略意义、ACS模式作为去中心化筛查/转诊枢纽、Melhor em Casa经济模型（成本低70%）、去机构化政策路径（Desospitalização）。
