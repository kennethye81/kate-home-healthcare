# 🇧🇷 巴西 居家医疗/长护市场全景

## 一、市场概况

巴西居家医疗呈现 **「SUS 公立主导 + Saúde Suplementar 私营补充」双轨并行** 格局。SUS（Sistema Único de Saúde，统一卫生系统）是世界上最大的公共医疗系统之一，宪法保障全民免费医疗权。Melhor em Casa（"在家更好"）是 SUS 内唯一的全国性公立 Hospital-at-Home 项目，2011 年启动，覆盖 977 个市（2024）和 2,187 支多学科团队。私营补充医疗体系由 ANS（国家补充医疗局）监管，覆盖 ~53M 受益人（2025），其中居家护理以市场化运作为主。

**核心数据**：

| 指标 | 数值 |
|------|------|
| 总人口 | ~212M（2022 人口普查）/ ~220M（2026 估计） |
| 60+ 人口占比 | **16.6%**（2026）← 11.3%（2012），几乎翻倍 |
| 65+ 人口 | **22.2M**（2022），较 2010 增长 57% |
| 60+ 预测（2050） | **~30%**——老龄化速度全球前列 |
| SUS 实际覆盖 | ~75% 人口（~164M）依赖 SUS |
| 私营健康保险覆盖 | **53M** 受益人（2025，ANS），创历史纪录 |
| 健康支出占 GDP | **9.7%**（2023，World Bank）/~10.7%（Statista 2023） |
| 居家医疗市场规模 | **USD 12.7B**（2024，Grand View Research），CAGR **10.9%**（2025-2030） |

> 来源：IBGE 2022 人口普查；Agência Brasil 2026.04；ANS 2025；Grand View Research；World Bank

## 二、体系架构

```
┌────────────────────────────────────────────────────┐
│              巴西居家医疗体系                        │
├──────────────────────┬─────────────────────────────┤
│  SUS（公立轨）        │  Saúde Suplementar（私营轨） │
├──────────────────────┼─────────────────────────────┤
│  • Melhor em Casa    │  • 保险公司 Home Care 产品   │
│    (Hospital-at-Home)│  • Concierge Medicine       │
│  • ESF 社区家庭健康   │  • 自费居家护理              │
│  • ACS 社区健康代理人  │  • Home Doctor 等私营运营商  │
│  • EMAD/EMAP/EMAP-R  │  • ANS 监管，无统一标准      │
│  • 100% 免费          │  • 按计划条款 + 自付比例      │
└──────────────────────┴─────────────────────────────┘
```

**关键特征**：巴西是全球少数将「健康是全民权利、国家有义务提供」写入宪法的国家。SUS 遵循** decentralization（分权化）+ universal coverage（全民覆盖）+ community participation（社区参与）**三原则。居家医疗在 SUS 内被定位为「去机构化（Desospitalização）」的核心工具——同等治疗效果下，居家成本比住院**低约 70%**（MS 数据）。

## 三、Melhor em Casa 全国项目

Melhor em Casa 是巴西卫生部（Ministério da Saúde）直接管理的全国性公立居家医疗项目，正式名称为 SAD（Serviço de Atenção Domiciliar）。

| 维度 | 数据 |
|------|------|
| 启动 | 2011 年（Portaria GM/MS No. 2.527/2011） |
| 覆盖城市 | **977 个市**（2024.03），26 州全覆盖 |
| 活跃团队 | **2,187 支**（2024）← ~100 支（2011），增长 ~3,000% |
| 年度就诊量 | **5,190,708 次**（2023），月均 **432,000+** 次 |
| 年度预算（2024） | **R$ 895.5M**（三方联邦/州/市分摊） |
| 累计转移支付（2011-2023） | ~R$ 5.2B |
| 患者 60+ 占比 | **68.4%** |
| 案例成功率 | **84%** |
| 受益者满意度 | **90%-94%** |

**三种团队配置**：
- **EMAD Tipo I/II**（Equipe Multiprofissional de Atenção Domiciliar）：医生+护士+护理技士+物理治疗师或社工，每周 ≥2 次访视
- **EMAP**（Equipe Multiprofissional de Apoio）：营养师/牙医/药剂师/言语治疗师/心理师等，按需支持
- **EMAP-R**（2024 年新增）：康复专业团队，面向 <20,000 人小城镇

> 来源：Ministério da Saúde；Agência Gov 2024.11

## 四、ESF 社区家庭健康战略

ESF（Estratégia Saúde da Família）1994 年创立，是世界最大规模的社区初级医疗项目，覆盖 **65%-70%** 人口：

- 33,000+ 家庭医疗团队（eSF），每队含 1 医生 + 1 护士 + 1-2 护理技士 + 4-6 ACS
- **402,777 名 ACS**（Agente Comunitário de Saúde，社区健康代理人，2024）
- ACS 负责 100-150 户家庭，每月上门走访——全球最大规模的社区级「最后一公里」触角网络
- ESF ↔ Melhor em Casa 衔接：稳定慢性病由 ESF 随访；急性加重后转介至 EMAD

## 六、核心挑战

1. **区域不平等**：Melhor em Casa 在东南部（SP/RJ/MG）和南部覆盖更广，北部/东北部农村地区薄弱
2. **联邦制碎片化**：5,570 个市执行力参差不齐，小城市 2024 年前无法参与
3. **联邦支出上限（EC 95/2016）**：限制 SUS 预算增长，扩张受限
4. **私营体系缺乏统一标准**：ANS 框架下 Home Care 无强制覆盖范围和专门质量指标
5. **劳动力短缺**：护士和治疗师在主要城市以外严重不足
6. **数据孤岛**：SUS（SAIPS/CNES）与 ANS 运营商数据互不联通

## 七、关键趋势

1. **2024 年 EMAP-R 开辟新领域**：为小城市开发康复团队，使 <20,000 人的市镇首次有机会参与
2. **姑息治疗正式整合**：2023.12 国家姑息治疗政策获批，自 2024 年起全面纳入 SAD 服务
3. **远程医疗从紧急授权到永久制度**：Lei 14.510/2022 + CFM Resolução 2.314/2022 建立联邦法律框架
4. **私营整合加速**：Dasa+Amil 合并（2024）、Rede D'Or+SulAmérica 合作，垂直整合成为主流模式
5. **数字健康投资增长**：超 600 家 healthtech 初创企业，吸引 ~USD 1.6B 融资；拉丁美洲近 2/3 数字健康公司在巴西

## 八、最新动态

- **2025-2026**：ANS 报告健康计划受益人数突破 53M，创历史纪录。联邦最高法院（STF）提高健康计划覆盖扩展门槛
- **2026.04**：IBGE 数据——巴西人口增长放缓，60+ 占比升至 16.6%，老龄化加速
- **2025**：Journal of Palliative Medicine 发表 Melhor em Casa 姑息治疗项目评估——患者症状控制显著改善，住院死亡大幅减少
- **2025.05**：卫生部宣布加强公私合作扩大专科医疗服务
