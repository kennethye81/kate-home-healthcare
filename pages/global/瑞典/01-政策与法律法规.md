# 瑞典 — 政策与法律法规

## 一、政策框架总览

瑞典拥有全球最完善的**税收资助型**长期护理体系之一。1992 年「Ädel 改革」将老年照护责任从省议会（Landsting）全面转移到市镇政府（Kommun），形成了「**市镇全责制**」的居家+机构照护一体化体系。

| 维度 | 内容 |
|------|------|
| **核心法律** | 《社会服务法》（Socialtjänstlagen / SoL）——确立老年照护为法定权利 |
| **主管部门** | 21 个地区（Regioner）+ 290 个市镇（Kommuner） |
| **制度类型** | 税收资助、全民覆盖、高度去中心化 |
| **居家护理** | Hemtjänst（居家帮助）+ Hemsjukvård（居家医疗护理）——市镇责任 |
| **全国指导** | 国家卫生和福利委员会（Socialstyrelsen） |

---

## 二、Ädel 改革（1992）—— 全球标杆

### 2.1 历史背景

1992 年 Ädel 改革是全球长期护理史上最重要的制度变革之一：**将老年照护从医疗体系（省议会管）完全移交市镇社会服务体系**。这意味着：
- 老年护理**不是「医疗问题」而是「社会福利问题」**
- 市镇对居家护理和机构照护负有**全面法律义务**
- 省议会仅保留急症医院和初级保健

### 2.2 核心原则

| 原则 | 含义 |
|------|------|
| **「就地安老」（Kvarboende）** | 老年人有权留在自己家中，市镇必须提供居家服务使其可能 |
| **全面责任（Heltäckande Ansvar）** | 市镇对老年照护负全责——从居家到护理院无缝隙 |
| **普遍主义（Universalism）** | 按需分配而非按收入——所有居民均有资格 |
| **高度去中心化** | 290 个市镇各自独立——无国家标准，有全国框架 |

## 三、服务体系

### 3.1 Hemtjänst — 居家帮助

| 维度 | 内容 |
|------|------|
| 服务 | 个人照料（洗澡/穿衣/如厕）、购物、清洁、备餐、社交陪伴 |
| 提供方 | 市镇直接提供 + LOV 授权私营机构 |
| 24 小时服务 | 针对重度失能——「夜巡服务」（Nattpatrull） |
| 服务量 | 约 **25 万** 65+ 老年人接受（占 65+ 的 ~12%） |

### 3.2 Hemsjukvård — 居家医疗护理

| 维度 | 内容 |
|------|------|
| 服务 | 由注册护士/专科护士提供居家医疗——伤口护理、药物管理、临终照护 |
| 区分 | 1992~2015 由省议会管 → 2015+ 逐步移交市镇 |
| 特征 | 与初级保健中心（Vårdcentral）紧密协作 |

### 3.3 Särskilt Boende — 特殊居住（护理院）

- 约 **8 万** 65+ 老年人居住
- 24 小时护理人员在场
- 市镇全责——从建设到运营

---

## 四、LOV — 选择自由法（2009）

LOV（Lagen om Valfrihetssystem）允许私营服务提供者进入市镇老年护理市场，居民可**自由选择**公立或私营服务商。目前约 **25%** 居家护理由私营提供。

## 五、近期政策

| 年份 | 政策 |
|------|------|
| 1992 | Ädel 改革——老年照护权转移至市镇 |
| 2009 | LOV——私营进入老年护理 |
| 2015 | Hemsjukvård 移交市镇 |
| 2018 | 「God och Nära Vård」——优质近距离照护改革，强化居家和初级保健整合 |
| 2024 | 新《社会服务法》修订——强化预防和早期干预 |
