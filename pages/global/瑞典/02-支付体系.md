# 瑞典 — 支付体系

## 一、支付模型全景

瑞典长期护理**90% 以上由市镇税收资助**——是全球公共化程度最高的 LTC 支付模式。患者自付有法定上限，确保「费用不成为获取照护的障碍」。

```
                    ┌────────────────────────────┐
                    │    瑞典 LTC 支付体系         │
                    └────────────────────────────┘
                                    │
                    ┌───────────────┼───────────────┐
                    ▼               ▼               ▼
              市镇所得税      国家政府拨款      患者自付
              (~85% LTC)       (均衡补助)      (法定上限)
```

| 支付通道 | 占比 | 来源 |
|---------|:---:|------|
| **市镇税收** | ~**85%** | 地方所得税（平均 ~32%）+ LTC 专项 |
| **国家均衡拨款** | ~**10%** | 弥补贫富市镇差距 |
| **患者自付** | ~**4-5%** | 法定最高上限 |

---

## 二、市镇税收——LTC 核心支柱

### 2.1 资金来源

瑞典 290 个市镇通过**地方所得税**（Kommunalskatt）为老年护理提供资金。地方所得税率平均约 **32%**（含市镇 ~21% + 地区 ~11%）。

| 指标 | 数据 |
|------|:---:|
| 市镇 LTC 总支出 | ~**SEK 1,500亿/年**（~$150亿） |
| 占市镇预算 | ~**25%**（最大单类支出） |
| 65+ 覆盖率 | 居家护理 ~12%（~25万人）/ 护理院 ~3.5%（~8万人） |

### 2.2 国家均衡系统

瑞典通过「市镇税收均衡」（Kommunalekonomisk Utjämning）机制，将富裕市镇的税收部分转移至贫困市镇，确保全国 LTC 服务的基本均等。

## 三、患者自付——法定上限

### 3.1 居家护理最高费用

| 服务 | 月费上限（SEK） | 折合美元 |
|------|:---:|:---:|
| Hemtjänst（居家帮助） | **SEK 2,310/月** | ~$220 |
| Hemsjukvård（居家护理） | **SEK 0** | 完全免费 |
| 日间照护 | SEK 2,310/月 | ~$220 |
| 安全警报（Trygghetslarm） | SEK 300/月 | ~$30 |

### 3.2 护理院最高费用

| 项目 | 月费上限 |
|------|:---:|
| 护理院月费 | **SEK 2,310/月**（与居家同上限） |
| 实际成本 | SEK 70,000-90,000/月——**政府补贴 ~97%** |

### 3.3 高成本保护（Högkostnadsskydd）

瑞典的「高成本保护」机制确保**任何人的自付费用不超过法定上限**——无论是居家还是机构照护。个人收入低于「保留金额」（Förbehållsbelopp，基本生活费保障）的，费用进一步减免。

## 四、费用水平（2024-2025）

| 服务 | 月毛成本（SEK） | 个人自付 | 政府补贴比例 |
|------|:---:|:---:|:---:|
| Hemtjänst 居家帮助 | ~10,000-25,000 | ≤2,310 | **~85-90%** |
| 护理院 | ~70,000-90,000 | ≤2,310 | **~97%** |
| Hemsjukvård 居家医疗 | 含在地区预算内 | 0 | **100%** |

**关键特征**：瑞典 LTC 的公共化程度（~95%）全球最高之一——远高于日本（50%）、德国（~65%）、美国（~20% Medicaid）。

## 五、私营保险

| 维度 | 数据 |
|------|:---:|
| 私营健康保险覆盖率 | **7.4%**——极低（主要覆盖快速就诊而非 LTC） |
| 原因 | 公立 LTC 已全面覆盖，私营保险无市场空间 |

## 六、支付体系 SWOT

| | 优势 | 劣势 |
|------|------|------|
| | • **全球最高的公共 LTC 投入**——95% 补贴 | • **严重依赖市镇税收**——人口流出市镇面临财政危机 |
| | • 法定自付上限——可及性极高 | • 市镇差异——斯德哥尔摩 vs 北部小城的服务质量 |
| | | • LOV 私营化争议——部分市镇过度私有化 |
| | **机遇** | **威胁** |
| | • 数字化可降低人力成本（远程护理/智能家居） | • 老龄化加速——65+ 比例从 20%→25%（2030+） |
| | • 新《社会服务法》强化预防——前移投入 | • 护理人力缺口——预计 2030 年需新增 10 万+ |
