## 二、医疗/长护险制度框架

瑞典医疗制度是**分散式（decentralised）模式**，三级治理：

- **国家层面（Stat）**：立法、监督、国家指导（Socialstyrelsen、IVO）
- **21个Region（地区）**：负责医院、专科医疗、高级居家医疗（ASIH）、初级保健。收入来自地区所得税（~70%）+ 国家拨款
- **290个Kommun（市镇）**：负责居家护理（hemsjukvård）、住宅护理。收入来自市镇所得税（~65%）+ 国家拨款

**支付体系**：税收为主（**公共来源86%**，OECD最高之一），自付有年度封顶（门诊~1,450 SEK/12个月，药品~2,900 SEK/12个月）。患者费用极低。

**居家医疗层级**：
1. **基本居家护理（Hemsjukvård）** — Kommun负责，护理为主
2. **高级居家医疗（ASIH）** — Region负责，多学科团队，24/7可及，始于1980年代
3. **急性期HaH（Sjukhusansluten hemsjukvård）** — 医院派出团队，新兴模式
4. **虚拟病房（Virtual Ward）** — Karolinska@home 数字+实体混合模式

> 核心制度特征：Region（医疗）和Kommun（护理社会服务）的职责划分清晰，但也导致了**碎片化**问题。协调出院法（SFS 2017:612）通过滞留费机制推动出院后居家康复。

## 三、居家医疗/HaH 市场概况

| 指标 | 数据 | 年份 |
|------|------|------|
| 医疗卫生GDP占比 | **11.2%**（~7,190亿 SEK） | 2024 |
| 人均医疗卫生支出（PPP） | ~7,017 USD | 2022 |
| ASIH居家医疗受益者 | **~20,000–25,000人/年** | 2023–24 |
| 急性期HaH（试点阶段） | **~500–1,500人** | 2024–25 |
| Kommun居家护理（≥65岁） | **~240,000人** | 2023 |
| 居家医疗占医疗总支出 | **<1%**（预计2030年前快速上升） | 2024估 |
| 住院日成本 vs 居家日成本 | 10,000–15,000 SEK vs 3,000–5,000 SEK | SKR/行业估算 |

**增长驱动**：人口老龄化、床位紧张、数字化成熟度高（1177.se年访问量近1,500万次、BankID覆盖>95%成年人口）、政治意愿（SKR将居家医疗列为首要战略方向）

## 四、主要供应商/机构

### 公共部门（Region自营，约占70–75%）

| 机构 | Region | 特色项目 |
|------|--------|---------|
| **Karolinska大学医院** | Stockholm | Karolinska@home（数字+实体混合虚拟病房，2024启动） |
| **Sahlgrenska大学医院** | Västra Götaland | 大规模ASIH和居家监测项目 |
| **Skåne大学医院** | Skåne | 南部最大居家医疗服务提供者 |
| **Norrlands大学医院** | Västerbotten | 北部偏远地区远程居家医疗创新 |

| 供应商 | 业务领域 |

| **Aleris** | 居家医疗、安宁疗护 |
| **Attendo** | 养老和居家护理（北欧最大之一） |
| **Cura** | 安宁疗护、高级居家医疗 |
| **Humana** | 个人援助、居家护理 |
| **Vardaga** | 居家护理、特别住宅 |

### 关键设备/技术供应商

- **Karolinska@home技术栈**：可穿戴生命体征监测 + 4G/5G传输 + 24/7中心监控站
- **研发合作**：Karolinska大学医院与**皇家理工学院（KTH）**合作开发
- **RPM互操作标准**：HL7 FHIR、NPÖ（国家患者概览）、BankID集成
