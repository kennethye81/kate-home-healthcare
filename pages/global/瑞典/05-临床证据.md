# 瑞典 — 临床证据与学术研究

## 一、ASIH（Advanced Home Care）临床数据

ASIH（Avancerad sjukvård i hemmet，高级居家医疗）是瑞典最成熟的"居家替代住院"模式，始于 1980 年代，目前已在所有 21 个 Region 运行。[^1]

### 1.1 ASIH 服务规模

| 指标 | 数据 |
|------|------|
| 接受 ASIH 专科居家医疗的患者 | 约 **20,000–25,000 人/年** |
| ASIH 团队构成 | 安宁专科医生 + 专科护士 + 物理治疗师 + 职业治疗师 + 社工 |
| 服务可及性 | 7 天/24 小时（部分团队夜间接线值班） |
| 医生家访频率 | 通常 1–2 次/周，必要时加频 |
| 覆盖病种 | 安宁疗护、晚期肿瘤、心衰、COPD、神经退行性疾病 |

### 1.2 瑞典安宁疗护质量（Svenska Palliativregistret 2023）[^2]

| 质量指标 | 居家环境数据 |
|---------|-------------|
| 疼痛评估覆盖率 | 约 **90%** |
| 吗啡使用比例（居家） | 约 **65%** |
| 临终对话（brytpunktsamtal）记录率 | 约 **55%**（仍有提升空间） |
| 家属支持覆盖率 | 约 **35%**（被认为不足） |
| 居家度过生命最后阶段的患者比例 | 约 **50%**（含普通居家和 ASIH） |
| 在医院去世的患者比例 | 约 **40%**（瑞典希望改善的指标） |
| ASIH 覆盖的安宁疗护患者比例 | 约 **15–20%**（专科安宁疗护） |

> **瑞典安宁疗护登记系统**（Svenska Palliativregistret，2005 年启动）是全球最完善的国家级安宁疗护质量登记之一，覆盖全国所有安宁疗护单位。[^2]

### 1.3 ASIH 的治疗结局

| 结局指标 | 观察结果 | 来源 |
|---------|---------|------|
| 患者满意度 | **极高**（ASIH 在家居环境中被高度评价） | 多项 Region 级调查 |
| 住院替代效果 | ASIH 患者住院日显著少于非 ASIH 居家患者 | Socialstyrelsen 公开比较 |
| 生存质量 | 安宁疗护质量指标达到或超过国际基准 | 瑞典安宁疗护登记 [^2] |

## 二、Karolinska Virtual Ward (Karolinska@home) 2024

Karolinska@home 是瑞典首个**数字+实体混合模式**（digi-physical）的急性期 HaH 项目，由 Karolinska 大学医院与皇家理工学院（KTH）合作开发，2024 年发表于同行评审期刊。[^3]

### 2.1 项目设计

| 维度 | 描述 |
|------|------|
| **目标患者** | 急性内科疾病（肺炎、心衰、COPD 急性加重、尿路感染等），急诊分诊后确定适合居家 |
| **服务模式** | 每日 1–2 次护士上门访视 + 远程生命体征监测 + 24/7 虚拟病房中心响应 |
| **纳入标准** | NEWS 评分 <5、年龄≥18、距医院 <30 分钟、有智能设备、愿意配合 |
| **排除标准** | 需持续 ICU 监测、需频繁静脉输液、认知障碍无家属支持 |

### 2.2 初期临床成果（Kastengren et al., 2024, J Telemed Telecare）[^3]

| 结局指标 | Karolinska@home | 非匹配住院对照组 |
|---------|:---------------:|:----------------:|
| 可行性 | **证实安全和可行** | — |
| 患者满意度 | **4.8/5**（极高） | — |
| 不良事件率 | 无显著差异 | 参照 |
| 平均住院时间 | **缩短约 30–40%** | 参照组 |
| 30 天再入院率 | **约 12–15%** | 相似水平 |

### 2.3 Region Stockholm 虚拟病房扩展计划

- Region Stockholm 已整合远程监测、视频问诊、医生远程查房功能
- 集中于心衰、COPD、高血压等慢性病急性发作后管理
- 计划 **2030 年前** 将虚拟病房能力扩大至每日覆盖约 **100–150 例** [^4]

## 三、居家医疗的卫生经济学

### 3.1 费用对比

| 服务模式 | 每日费用（SEK） | 约合（EUR） | 来源 |
|---------|:-------------:|:----------:|------|
| 综合医院普通病床 | 10,000–15,000 | 870–1,300 | SCB / SKR |
| 居家医疗（HaH/ASIH） | 3,000–5,000 | 260–430 | 行业估算 [^1] |
| 住院 vs 居家成本比 | 约 **3:1** | — | 基于典型路径对比 |

> 居家医疗每日费用约为住院的三分之一，但总费用可能因服务天数不同而变化。随着虚拟病房规模扩大，单位成本预计将进一步下降。[^1]

### 3.2 研究：Stockholm Sjukhem EPIC-HOME RCT

- 2019 年启动的随机对照试验
- 针对老年不治癌症患者的**早期整合安宁疗护居家模式**
- **结果**：住院率降低约 **30%**，生活质量提高，医疗成本降低 [^1]

### 3.3 居家医疗的宏观经济意义

| 维度 | 数据 | 影响 |
|------|------|------|
| 长期照护支出占 GDP | **约 3.4%**（2021, OECD） | 高于欧盟平均 1.7%，反映 LTC 体系广度 |
| 居家医疗占医疗总支出 | <1%（当前） | 预计 2030 年前快速上升 |
| 住院回避潜力 | 约 12–15% 的常规住院可居家化（估） | 可释放大量床位资源 [^4] |

## 四、居家氧疗与呼吸支持临床数据（Swedevox 登记）[^5]

瑞典国家居家氧疗登记 Swedevox（1996 年启动）提供了长达近 30 年的连续数据：

| 指标 | 数据 |
|------|------|
| 全国居家氧疗患者数 | 约 **3,500 人**（稳定） |
| 居家呼吸机使用患者 | 约 **2,000 人**（缓慢增长） |
| 登记系统连续运行 | 1996 年至今，近 30 年 |
| 质量指标 | 氧疗处方合理性、依从性、地区差异 |

## 五、关键学术机构与研究中心

| 机构/组织 | 研究方向 |
|-----------|----------|
| **Karolinska Institutet / Karolinska 大学医院** | Karolinska@home 数字+实体 HaH 项目；临床结局评价 |
| **KTH 皇家理工学院** | 远程监测技术和可穿戴设备的研发合作 |
| **Lund 大学** | AI 居家风险预测——利用 EHR + 可穿戴设备数据预测患者居家恶化风险 |
| **Stockholm Sjukhem** | EPIC-HOME 早期整合安宁疗护 RCT |
| **Sahlgrenska 大学医院** | ASIH 模式和大规模居家医疗研究 |
| **Region Västerbotten / Norrlands 大学医院** | 偏远地区远程居家医疗方案 |
| **SBU（瑞典卫生技术评估局）** | 居家医疗服务的系统评价和证据评估 |
| **Svenska Palliativregistret** | 居家安宁疗护质量登记与分析 |
