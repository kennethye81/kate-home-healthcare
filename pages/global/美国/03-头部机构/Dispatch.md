# DispatchHealth（美国）

**业务形态：** 全栈式居家急性医疗服务运营商（ER替代 + 住院替代 + 过渡期护理）
**所在国家：** 美国

## 关键数据
- 规模：120万+服务人次 / 50大都市区 / ~40卫生系统合作伙伴 / 2,200+员工
- 总融资：$7亿+；2025年6月与Medically Home合并
- 临床质量：意外死亡率0%、患者NPS +93、30天再入院率9.3%
- 每案例节省：ER替代$1,400+，住院替代$5,000-7,000
