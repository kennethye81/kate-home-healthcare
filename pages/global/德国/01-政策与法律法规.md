# 德国 — 政策与法律法规

## 一、政策框架

德国 1995 年实施 **Pflegeversicherung（SGB XI）**——全球第一个作为社会保险独立分支的长护险。

| 维度 | 内容 |
|------|------|
| 核心法律 | SGB XI（Sozialgesetzbuch XI） |
| 实施 | 1995.01（居家给付）/ 1996.07（机构给付） |
| 原则 | **「ambulant vor stationär」**（居家优先） |
| 运营 | Pflegekassen（护理保险基金）——与 Krankenkassen 联动 |

## 二、Pflegegrade 体系（2017）

2017 年重大改革——从 3 级 Pflegestufen → **5 级 Pflegegrade**：

| 等级 | 判定 | 占比 |
|:---:|------|:---:|
| PG 1 | 轻度自理受限 | ~3% |
| PG 2 | 中度失能 | ~40% |
| PG 3 | 重度失能 | ~30% |
| PG 4 | 极重度 | ~17% |
| PG 5 | 最重度+特殊照护需求 | ~10% |

**新评估工具**：NBA（Neues Begutachtungsassessment）——6 维度 64 项

## 三、BEEP 法（2026）

2026 年实施——扩大居家护理护士权限（可独立开具辅助器具和部分药物）、简化行政流程。

## 四、Zukunftspakt Pflege

讨论长期财源可持续性——保费率从 2.55%（2017）升至 3.6%（2026），预测 2040 年需 >5%。

## 五、Pflegeneuordnungsgesetz (PNOG) 2026

2026年6月4日，联邦卫生部（BMG）公布**Pflegeneuordnungsgesetz (PNOG)**草案——自2017年Pflegestärkungsgesetz以来最大的护理保险改革：

| 维度 | 内容 |
|:----|:------|
| **目标** | 重新规划法定护理保险（soziale Pflegeversicherung），适应未来挑战 |
| **草案发布日期** | 2026.06.04 |
| **立法时间表** | 目标2026年底前生效 |
| **核心方向** | 财源可持续性、护理人力保障、数字化推进 |
| **BEEP法后续** | 扩大居家护理护士权限的补充措施 |

**讨论焦点：**
- 保费率持续上升压力——2026年已达3.6%（无子女者3.8%）
- 护理人力缺口——当前缺口约20万人
- 居家护理优先原则「ambulant vor stationär」进一步强化
- 数字化和远程护理（Telepflege）的法定基础
