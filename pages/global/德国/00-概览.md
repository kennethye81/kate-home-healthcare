# 🇩🇪 德国 居家医疗/长照市场

## 一、市场概况

德国 1995 年实施 **Pflegeversicherung（护理保险）**——全球第一个作为社会保险独立分支的长护险。SGB XI（社会法典第十一编）法律框架，以「ambulant vor stationär」（居家优先于机构）为法定原则。

**核心数据**：

| 指标 | 数值 |
|------|------|
| 65+ 人口 | **22.7%**（2025） |
| Pflege 认定者 | ~**500 万**（2025） |
| 其中居家照护占比 | **~75%**（在宅率） |
| 护理保险保费率（2026） | 一般 **3.6%** / 无子女 **4.2%** |
| Pflegegrade 1-5 | 2017 年自立性障碍评估取代原 3 级 |
| 居家实物给付（PG2-5） | €**796-2,299/月**（Sachleistung） |
| 居家现金给付（PG2-5） | €**347-990/月**（Pflegegeld） |

## 二、体系架构

```
Pflegeversicherung (SGB XI)
├─ Sachleistung → 上门护理服务（由 Pflegedienst 提供）
├─ Pflegegeld → 现金给付（家属照护补贴）
├─ Kombinationsleistung → 实物+现金混合
├─ Tages-/Nachtpflege → 日间/夜间照护
├─ Kurzzeitpflege → 暂托照护（最长 8 周/年）
└─ Vollstationäre Pflege → 机构全时照护

Krankenversicherung (SGB V)
└─ Häusliche Krankenpflege → 居家医疗护理（医生处方）
```

## 三、市场特征

- **极度分散**：TOP 15 居家护理服务商仅占 ~5.4% 市场份额
- 头部：Johanniter、Deutsche Fachpflege、Korian（欧州最大养老集团）
- **BEEP 法（2026）**：扩大居家护理护士权限、简化行政流程
- **Zukunftspakt Pflege**：讨论 LTC 财源长期可持续性
- **最大痛点**：机构 OOP（自付）每月 €2,000-3,000——远超多数家庭承受力

## 四、核心挑战

1. 护理人力严重短缺——预计 2035 年缺口 50 万+
2. 机构自付高昂——推动更多人选择居家（但居家给付也不够）
3. Pflegeversicherung 财政压力——保费率从 2.55%（2017）升至 3.6%（2026）
