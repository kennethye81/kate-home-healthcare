# 台湾 — 政策与法律法规

## 一、政策框架

「长照 2.0」（2017 年启动）是台湾史上最大规模长照升级——以税收为财源，ABC 三级据点网络。

| 维度 | 内容 |
|------|------|
| 法律 | 长期照顾服务法（2017）+ 长照保险法（草案·未通过） |
| 財源 | 长照基金——遺贈税+煙税+房地合一税+政府予算 |
| 主管 | 衛生福利部（長照司） |

## 三、在宅医療·在宅急症

2024 年健保署「在宅急症照護」试点：
- 急性感染（肺炎/UTI/軟組織）→居家 IV 抗生物質治療
- 多学科 Team：医師+護理師+薬剤師+呼吸治療師
- 台湾版 Hospital at Home
- **2026年扩展**：从3类感染症扩大至**全部感染症**，未来慢性心衰竭等也可能纳入

## 五、長照2.0深化与长护险立法（2025-2026）

### 長照保險法立法進展

長照保險法（社会保険化）自2015年草案提出以来历经多届立法院審議未果。2024年大選後，賴清德政府將長照保險法重新納入立法議程：

| 年份 | 進展 |
|:---:|------|
| 2015 | 長照保險法草案首次送立法院，未完成審議 |
| 2017 | 長照2.0啟動，以稅收制暫代社会保険 |
| 2021 | 第二次送審，因疫情及政治爭議再次擱置 |
| 2024 | 總統大選後重啟討論——衛福部表態「2025年啟動立法評估」 |
| 2025 | 衛福部完成長照保險財務精算報告，規劃2026年送立法院審議 |

核心爭議點：① 保費負擔比例（雇主/個人/政府）② 與現有長照基金如何銜接 ③ 外籍看護工是否納入保険給付範圍。

## 六、長照3.0（2026-2035）

行政院2025年7月1日正式核定、2026年起實施的10年計劃。長照2.0的社區主義、人本位、持續照護理念上，提出8大目標：

| 目標 | 核心內容 |
|:----|:--------|
| 1. 健康促進 | 社區型照護網絡、預防性照護與活躍老化整合 |
| 2. 醫療與長照整合 | 出院前在宅照護計畫、全民健保急性後期照護銜接 |
| 3. 積極復能 | 失能者長照資格擴大（不限年齡）、日間照護功能強化 |
| 4. 機構量能 | 夜間/深夜緊急照護、社會住宅PPP模式 |
| 5. 家庭支持 | 住院共同照護、年輕型失智症支援 |
| 6. 智慧照顧 | 智慧輔具租賃系統、日間/住宿機構導入 |
| 7. 安寧照顧 | 預立醫療照護計畫（ACP）推廣、特定對象免費諮詢 |
| 8. 人力發展 | 外國中階技術人力擴大、女性再就業、勞動條件改善 |

**關鍵數字**：
- 服務使用者目標：50萬人（2.0末）→ 70萬人（3.0）
- 部立醫院：26家醫院參與，2029年前整備1,900床住宿式長照設施
- 未來政策重點：日間照顧、居家醫療、居家安寧
- 新增五大類智慧科技輔具全租賃補貼（2026年7月第三階段）

### ABC社区整体照护深化

長照2.0 ABC体系经过7年运行（2017-2024），2025年进入第三期计划：

| 维度 | 一期（2017-2020）| 二期（2021-2024）| 三期（2025-2028）|
|------|:---:|:---:|:---:|
| 服务对象 | 51.1万人 | 73.8万人 | 目标100万人+ |
| A级据点 | 469 | 700+ | 目标800+ |
| B级据点 | 3,800 | 7,000+ | 目标8,500+ |
| C级据点 | 1,800 | 3,500+ | 目标5,000+ |
| 年度预算 | NT$300亿 | NT$600-900亿 | NT$1,000亿+ |

核心模式：A級（個案管理師）作為單一窗口，評估後鏈接B級服務與C級預防。2025年起推行「包裹式給付」（bundled payment）試點——按CMS等級給予固定月額，由A級据点統籌分配。
