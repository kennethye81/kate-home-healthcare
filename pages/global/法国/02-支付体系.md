# 🇫🇷 法国 HAD 支付体系

## 一、法国医疗保障体系概述

法国拥有全球评价最高的医疗保障体系之一，以 **Assurance Maladie**（疾病保险）为核心，覆盖全民。2024 年法国人均医疗支出约 **$4,920**（PPP），位列 OECD 前列。医疗消费（CSBM）增长 3.6%，为欧盟最低增速之一。

### 1.1 三层支付结构

| 层级 | 覆盖方 | 覆盖比例（平均） | 说明 |
|------|--------|-----------------|------|
| 第一层 | Assurance Maladie（法定医保） | ~70-80% | 强制参保，全民覆盖 |
| 第二层 | Mutuelle / Complémentaire Santé（补充保险） | ~15-25% | 雇主或自购，覆盖 copay |
| 第三层 | 患者自付（Reste à Charge / OOP） | ~3-5% | 在法国整体较低 |

> 法国 OOP 占比为 OECD 最低之一，约 **3.2%** 家庭最终消费（OECD 2025 数据）。

> **来源**：DREES — Health Expenditure 2024, Édition 2025；OECD Health at a Glance Europe 2024；OECD Country Health Profile 2025: France

## 二、HAD T2A 按日付费体系

### 2.1 T2A（Tarification à l'Activité）框架

自 2005 年起，法国 HAD 纳入 T2A 按活动付费体系，支付机制包含**两大资金包**：

#### 第一部分：GHT（Groupement Homogène de Tarifs）按日付费

- **计费单位**：GHT（同质费率组），基于主要照护模式（MPCP — Mode de Prise en Charge Principal）
- **费率跨度**：约 **€150-€350/日**（根据照护强度和 MPCP）

#### 第二部分：Liste en Sus 药品和耗材

- 列入「liste en sus」的昂贵药品（如某些化疗药、生物制剂）和植入式医疗器械按实际成本额外结算
- 常规药品含在 GHT 日费率内

### 2.2 核心 GHT 类别

| GHT 类别 | 说明 | 占 HAD 住院日比例 |
|----------|------|-------------------|
| 姑息治疗（Soins Palliatifs） | 终末期患者症状管理和心理支持 | 29% |
| 复杂伤口护理（Pansements Complexes） | 压疮、糖尿病足、术后伤口等 | ~28% |
| 重度护理（Soins de Nursing Lourd） | 高度依赖性患者日常护理 | ~10% |
| 呼吸辅助（Assistance Respiratoire） | 氧疗、无创通气 | ~9% |
| 疼痛管理（Prise en Charge de la Douleur） | 慢性疼痛综合管理 | ~9% |
| IV 治疗（Traitements Intraveineux） | IV 抗生素、营养等 | ~8% |
| 肿瘤化疗/监测（Oncologie） | 非姑息性肿瘤治疗 | ~3% |
| 围产期/产后（Périnatalité） | 产后早期出院延续护理 | ~3% |
| 康复（Rééducation） | 神经/骨科康复 | ~2% |

### 2.3 HAD 与 MCO 支付对比

| 特征 | MCO（传统住院） | HAD |
|------|----------------|-----|
| 计费单位 | GHS（按住院次） | **GHT（按日）** |
| 费率水平 | €500-€1,500/日 | €150-€350/日 |
| 时长效应 | 短期更有利可图 | 无激励偏差 |
| 医生费用 | 含在 GHS（公立） | 不含（ex-OQN 需补加） |
| 资本成本 | 高（建筑/设备） | 低（流动运营） |

> **HAD 成本低于传统住院 50-80%**：以终末期姑息治疗为例，HAD 日均成本约 €198 vs 医院姑息单元（USP）€497/日。

> **来源**：IRDES QES n°67, 2003；ATIH — Chiffres Clés HAD 2023；FNEHAD

### 2.4 支付资金流

```
Parlement（议会）
    │ 确定 ONDAM（国家健康保险支出目标）
    ▼
ODMCO（MCO 支出子目标）← HAD 份额含在其中
    │
    ▼
ARS（区域卫生局）← 区域分配
    │
    ▼
HAD 机构 ← 按 GHT × 实际住院日结算
    │         + Liste en sus 药品/耗材
    ▼
患者 ← 0 自付（全由 Assurance Maladie + Mutuelle 覆盖）
```

### 2.5 制度改革方向

- **2024 PLFSS**（社会保障融资法）：将 HAD 纳入更广泛的「按质量付费」（paiement à la qualité）改革
- 逐步提高固定拨款（dotation populationnelle）占比，降低纯 T2A 活动付费的比重
- HAD 因其天然的低成本优势，在改革中处于相对有利位置

## 三、APA 分级给付体系

APA（Allocation Personnalisée d'Autonomie）是法国长期照护的核心支付机制，由各省议会管理、CNSA 资金支持。

### 3.1 2026 年 APA 居家给付标准

| GIR 等级 | 月最高给付额（2026） | 自付比例（按收入） |
|----------|---------------------|-------------------|
| GIR 1 | **€2,080.33** | 0-90%（梯级递增） |
| GIR 2 | **€1,686.28** | 0-90% |
| GIR 3 | **€1,222.17** | 0-90% |
| GIR 4 | **€815.50** | 0-90% |

### 3.2 自付比例（Ticket Modérateur APA）收入阶梯

| 月收入（€） | 自付比例 |
|------------|---------|
| < €840.30 | 0% |
| €840.30 - €1,094.64 | 10% |
| €1,094.65 - €1,348.93 | 20% |
| €1,348.94 - €1,602.57 | 30% |
| €1,602.58 - €1,857.64 | 40% |
| €1,857.65 - €2,111.21 | 50% |
| €2,111.22 - €2,365.44 | 60% |
| €2,365.45 - €2,619.60 | 70% |
| €2,619.61 - €2,873.82 | 80% |
| > €2,873.82 | **90%** |

> APA 无收入条件限制（即无收入上限排除），但给付金额随收入梯级递减。

### 3.3 APA 资金来源

| 来源 | 说明 |
|------|------|
| **CNSA 拨款** | 国家层面对各省的拨款（2025 年增加 €2 亿） |
| **省议会自有资金** | 各省需匹配自有预算 |
| **CSG（社会普及税）** | 部分 CSG 专用于自主支持 |
| **CASA（团结附加税）** | 对资本收入的附加税，2024 年贡献 CNSA 部分收入 |

> **来源**：CNSA, LFSS 2025, Sécurité Sociale Évaluation, Famirelay, sap.colombage-cohabitation.fr

## 四、Mutuelle / Complémentaire Santé（补充保险）

### 4.1 覆盖率

法国补充健康保险（mutuelle / complémentaire santé）覆盖率极高：

| 覆盖渠道 | 覆盖率 |
|---------|--------|
| 雇主提供的集体 mutuelle | ~50% |
| 个人自购 mutuelle | ~35% |
| CSS（Complémentaire Santé Solidaire，免费/廉价） | ~10% |
| 无补充保险 | **~5%** |

> 95% 的法国居民拥有某种形式的补充保险，这是法国 OOP 处于 OECD 最低水平的核心原因。

### 4.2 HAD 场景下的覆盖

- HAD 作为「全时住院」，Assurance Maladie 覆盖 **100%**（按住院标准）
- Mutuelle 通常覆盖 Assurance Maladie 未覆盖部分（如单人病房差价、某些舒适性服务）
- **HAD 患者实际自付（OOP）趋近于 0**——这是 HAD 对患者的重大吸引力

### 4.3 CSS（Complémentaire Santé Solidaire）

- 面向低收入人群的免费或廉价补充保险（月费 ≤ €1/天）
- 2024 年覆盖约 700 万人
- CSS 受益人在 HAD 场景下的覆盖与标准 mutuelle 一致

## 五、国际支付对比

| 维度 | 法国 HAD | 美国 CMS HaH | 日本 介護保険 |
|------|---------|-------------|--------------|
| 支付模式 | T2A 按日（GHT） | DRG 按次 + 日附加 | 介護報酬按服务 |

| 患者 OOP | **≈0%**（HAD） | 10-20%（Part B） | 10-30% |
| 激励方向 | 质量 > 量 | 量 > 质量 | 平衡 |
