# 法国 — 支付体系

## 一、支付模型全景

法国居家医疗支付为**「社保报销 + APA 津贴 + 补充保险 + 自费」**四层结构。HAD 按住院费率全额报销——这是法国模式的最核心特征。

```
                     ┌────────────────────────────────┐
                     │       法国 居家医疗 支付          │
                     └────────────────────────────────┘
                                    │
          ┌──────────┬──────────┬───┴───┬──────────┐
          ▼          ▼          ▼       ▼          ▼
       Assurance   APA       Mutuelle  自费      CNSA
       Maladie   (自主津贴)  (补充保险) (少量)  (长期照护基金)
       (HAD100%) (居家/机构)
```

| 支付通道 | 覆盖 | 支付方 | 自付比例 |
|---------|------|------|:---:|
| **Assurance Maladie (HAD)** | 急性居家医疗 | 法定医保 | **0%（住院费100%报销）** |
| **Assurance Maladie (门诊居家)** | 社康护理（SSIAD） | 法定医保 | 0-30%（依服务类型） |
| **APA** | 长期照护 | CNSA + 省级议会 | 按收入分级 |
| **Mutuelle（补充保险）** | 门诊共付部分 | 雇主/个人 | 96%覆盖 |

## 二、HAD — 按住院费全额报销

### 2.1 支付逻辑

HAD 在法律上等同于住院——社保按 **T2A（按活动付费 / Tarification à l'Activité）** 或按日费率全额报销：

| 支付方式 | 说明 |
|------|------|
| **按日费率（Forfait Journalier）** | HAD 每日固定费用——覆盖医生、护士、药物、设备 |
| **按活动付费** | 复杂照护按 GHT（Homogeneous Tariff Groups）分组付费 |
| **患者自付** | **€0**——HAD 治疗 100% 由 Assurance Maladie 覆盖 |

### 2.2 对标住院

| 项目 | 实体住院 | HAD 居家住院 |
|------|:---:|:---:|
| 社保报销 | 80% + Mutuelle 补 20% | **100%** |
| 每日酒店费（Forfait Journalier） | €20/天（患者付或 Mutuelle） | €0（包含在 HAD 日费率中） |
| 医生费 | 社保 70% + Mutuelle 30% | 100% 覆盖 |

**关键优势**：HAD 对患者的自付成本**低于实体住院**——这是法国推动 HAD 的核心经济激励。

## 三、APA — 长期照护支付

### 3.1 支付标准（居家）

| GIR 等级 | 失能程度 | 最高月额（2024 估） | 用途 |
|:---:|------|:---:|------|
| GIR 1 | 完全卧床/认知极重度 | **~€1,900/月** | 护理员、适老化改造、辅助设备 |
| GIR 2 | 重度失能 | ~€1,500/月 | 同上 |
| GIR 3 | 中度失能 | ~€1,100/月 | 同上 |
| GIR 4 | 轻度失能 | ~€750/月 | 同上 |
| GIR 5-6 | 基本自主 | 无资格 | — |

### 3.2 支付标准（机构）

| 费用构成 | 支付方 |
|------|------|
| **照护费**（Tarif Soins） | Assurance Maladie |
| **依赖费**（Tarif Dépendance） | APA（按 GIR）+ 个人自付 |
| **住宿费**（Tarif Hébergement） | 个人自付（可申请 ASH 社会援助） |

### 3.3 APA 资金来源

- **CNSA** 主导——来自 CSG 的「自主团结附加费」（Contribution Solidarité Autonomie）
- 省级议会配套拨款
- 年总支出 ~**€60亿+**

## 四、SSIAD — 社康护理服务

SSIAD（Services de Soins Infirmiers à Domicile）提供**非急性**居家护理：

| 维度 | 内容 |
|------|------|
| 覆盖人群 | 60 岁以上失能老年人 + 18 岁以上残疾人 |
| 服务 | 护理（护士/护理员上门）、个人卫生协助 |
| 报销 | Assurance Maladie 全额覆盖 |
| 处方 | 需医生处方 |
| 数量 | ~2,000+ 机构 |

---

## 五、费用水平

| 服务 | 月费 | 公共资助 |
|------|:---:|------|
| HAD（急性居家住院） | €0（100% 报销） | Assurance Maladie |
| SSIAD（社康护理） | €0（全额覆盖） | Assurance Maladie |
| APA 护理员（GIR 1-2） | 自付部分依收入 | APA ~€1,500-1,900/月 |
| 私营居家护理员（非 APA） | €1,500-3,000 | 自费 |
| EHPAD（护理院） | €2,000-5,000/月 | 照护费由医保+APA部分覆盖 |

## 六、支付体系 SWOT

| | 优势 | 劣势 |
|------|------|------|
| | • HAD 100% 报销——**全球最强的急性居家医疗经济激励** | • APA 金额对重度失能不足——GIR 1-2 的 €1,900 不够全覆盖 |
| | • Mutuelle 96% 覆盖率——几乎零自付缺口 | • EHPAD 机构费用高昂——月 €2,000-5,000 |
| | • APA 将长期护理制度化——2002年便是国家责任 | • APA 由各省管理→地区差异 |
| | **机遇** | **威胁** |
| | • 第五分支（5e Branche）——LTC 制度化加速 | • CSG 税率已达上限——CNSA 资金增长空间有限 |
| | • HAD 扩展至更多专科（肿瘤/精神科/儿科） | • 老年人口增速远超 APA 预算增速 |
