# 法国 — 政策与法律法规

## 一、政策框架总览

法国拥有**全球历史最悠久的制度化「居家住院」（Hospitalisation à Domicile / HAD）体系**——可追溯至 1951 年的 Assistance Publique – Hôpitaux de Paris 试点，1957 年正式立法确立。

| 维度 | 内容 |
|------|------|
| **核心体系** | HAD（Hospitalisation à Domicile）——纳入医院体系的急性居家医疗 |
| **长护支柱** | APA（Allocation Personnalisée d'Autonomie）——个性化自主津贴 |
| **医疗覆盖** | PUMa（Protection Universelle Maladie）——2016年起全民法定医保 |
| **主管部门** | 卫生部（Ministère de la Santé）+ 省级议会（Départements，负责 APA） |

---

## 二、HAD — 全球最成熟的制度性「居家住院」

### 2.1 历史

HAD 在法国**不是「新兴模式」而是「成熟制度」**：

| 年份 | 里程碑 |
|------|------|
| 1951 | AP-HP（巴黎公立医院集团）在 Paris 试点 HAD |
| 1957 | 正式立法确立 HAD 为医院体系的一部分 |
| 1970 | 社会保险将 HAD 纳入法定报销 |
| 1992 | HAD 法律框架完善——明确 HAD 是「住院替代」 |
| 2000+ | HAD 机构数量快速增长 |
| 2018 | 「Ma Santé 2022」改革——HAD 被定位为医疗体系转型核心 |

### 2.2 法律定位

HAD 在法律上**等同于住院**——患者被正式「住院」（hospitalisé），只是在**家中**接受医院级照护。关键含义：
- HAD 由**医院医生开具处方**（非 GP 可开）
- 服务由 HAD 机构提供——可以是公立医院附属、私立非营利或私立营利
- 社会保险按**住院费率**报销——与实体住院同等待遇

### 2.3 服务范围

HAD 覆盖三大类照护：

| 类别 | 内容 |
|------|------|
| **复杂伤口和术后照护** | 手术后换药、引流管理、造口护理 |
| **姑息治疗（Soins Palliatifs）** | 生命末期居家照护——HAD 最重要领域之一 |
| **静脉治疗** | 抗生素、化疗、营养液（TPN）居家输注 |
| **产科** | 产后早期出院+居家随访 |
| **康复** | 神经系统疾病（中风/ALS/MS）居家康复 |

### 2.4 规模

| 指标 | 数据 |
|------|:---:|
| HAD 机构数量 | ~300+ |
| 年服务患者 | ~30 万+ |
| HAD 床位 | ~2.2 万张（相当于法国总床位的 ~5%） |

## 三、APA — 长期护理支柱

### 3.1 制度概述

APA（Allocation Personnalisée d'Autonomie）是法国的**主要长期护理公共资助**。2002 年实施，由省级议会（Conseil Départemental）管理。

| 维度 | 内容 |
|------|------|
| 资格 | 60 岁以上、经 GIR 评估确定失能等级（GIR 1-4） |
| GIR 等级 | 1-6 级，1 最重/6 完全自主 |
| 资助 | GIR 1-4 有资格——1-2 全额、3-4 部分 |
| 使用方式 | 可用于居家照护（护理员上门、适老化改造）或入住机构 |
| 最高月额 | GIR 1: ~€1,900/月（居家）/ 机构照护另计 |

### 3.2 资金来源

- **CNSA**（Caisse Nationale de Solidarité pour l'Autonomie）：国家团结自主基金——来自 CSG（一般社会贡献税）的「自主团结附加费」
- 省级议会补充拨款
- APA 年支出约 **€60亿+**

## 四、PUMa — 全民医疗保障

| 指标 | 数据 |
|------|:---:|
| 覆盖 | 100% 合法居民 + 居留>3个月的无证移民 |
| 补充保险覆盖率 | **96%**（mutuelles/私营） |
| 公共支出占比 | **75.4%**（2022） |
| 自付占比 | **8.9%**（2022） |
| 2023 总健康支出 | **€3,250亿**（增长 3.5%） |

## 五、近期改革

| 年份 | 改革 |
|------|------|
| 2016 | PUMa 全民覆盖生效 |
| 2018 | Ma Santé 2022——HAD 定位为核心转型方向 |
| 2020+ | 数字化转型——Mon Espace Santé 电子健康空间 |
| 2021 | 第五分支（5e Branche）——在社会保障体系中正式建立「自主」分支，长期护理制度化提速 |
| 2025 | CNSA 继续推展居家照护优先战略 |
