# 🇨🇳 中国 — 支付体系

## 长护险支付

| 参数 | 标准 |
|:-----|:-----|
| 费率 | 0.3% 左右（单位+个人同比例分担） |
| 基金支付比例 | ~70% |
| 起付线 | 无 |
| 年度上限 | ≤统筹地区上年居民人均可支配收入50% |
| 支付方式 | 基金直付服务机构（原则上不发现金） |
| 居家倾斜 | 鼓励居家和社区护理，支付上倾斜 |
| 服务目录 | 36项全国统一项目（20项生活照护+16项医疗护理） |

## 筹资四源结构

长护险采用**多元责任共担**筹资机制，由以下四个来源共同构成：

| 来源 | 承担主体 | 说明 |
|:-----|:---------|:-----|
| **医保基金划拨** | 职工医保统筹基金 | 结余较多地区可划拨部分至长护险基金 |
| **财政补贴** | 中央+地方财政 | 对城乡居民参保给予补助；对特困/低保人员分类资助 |
| **单位缴费** | 用人单位 | 费率为职工工资总额的0.15%左右（与个人同比例，合计约0.3%） |
| **个人缴费** | 职工/退休人员/城乡居民 | 职工按本人工资收入；退休人员按养老金；城乡居民定额 |

### 各类人群缴费细则

- **单位职工**：费率由用人单位和个人按同比例分担。单位缴费基数=职工工资总额，个人缴费基数=本人工资收入
- **退休人员**：费率与单位职工个人费率相同，缴费基数与养老金水平挂钩，由个人缴费
- **未就业城乡居民**：个人缴费+政府补助，政府补助由中央和地方财政共同承担
- **18周岁以下**：跟随父母或其他法定抚养人参保，不单独筹资
- **困难群众**：特困人群、低保对象等享受分类资助

### 医保个人账户打通

职工基本医疗保险个人账户可用于本人及**近亲属**（配偶、父母、子女、兄弟姐妹、祖父母、外祖父母、孙子女、外孙子女）参加长护险的个人缴费。

### 中央财政补助机制

2026年中央对地方转移支付预算已安排长护险补助资金。当年按各地预计参保人数先预拨，次年根据实际参保人数据实结算，确保足额拨付。今后随参保人数增加，财政补助力度继续加大。

## 各地缴费标准对比

| 地区 | 个人缴费 | 筹资结构 | 备注 |
|:-----|:---------|:---------|:-----|
| 全国统一 | 约0.15%（个人部分） | 单位+个人+财政+医保 | 费率控制在0.3%左右 |
| 江苏连云港 | 每人每年30元 | 个人+财政+医保划拨 | 从医保个人账户划拨 |
| 四川成都 | 按年龄/收入分档 | 单位+个人+财政 | 全民覆盖，含学生儿童 |
| 山东青岛 | 按职工/居民分类 | 职工医保+财政 | 最早试点城市之一 |
| 上海 | 按职工医保基数 | 医保+财政 | 不额外征缴 |

> **注**：各地在0.3%国家基准费率框架下，可结合实际调整。城乡居民地区差异较大，从定额每年30元到按收入比例不等。

## 医保支付（居家医疗相关）

- **家庭病床**：各地试点纳入医保，按床日或项目付费
- **上门护理**："互联网+护理服务"部分地区纳入医保
- **门诊慢特病**：10种门诊慢特病跨省直接结算

## 商保与健康管理

- "十五五"规划提出：商业健康保险与健康管理"深度融合"
- 鼓励覆盖健康干预、特需医疗、创新药的商保产品
- 长期护理商业保险：部分地区试点，万亿级市场空间
- 主要参与机构：中国人保、中国人寿、中国平安、中国太保、新华保险、泰康人寿等
- 商业长护险主力供给方：专业健康险公司（人保健康、平安健康、太保安联等）

## 自付与政府补贴

- 经济困难老年人：养老服务补贴+护理补贴+高龄津贴
- 2026年：民政部财政部中度以上失能老年人消费补贴（消费券模式——即CSV社区券）
- 长护险基金支付后自付部分约30%，对困难群众实行减免

## 支付方式改革趋势

- 从按项目付费 → 按床日/按人头/按绩效付费
- 部分地区探索"按结果付费"（Value-Based Payment）
- 长护险信息化平台全国统一建设中
- 商保与社保数据互通（十五五规划方向）
