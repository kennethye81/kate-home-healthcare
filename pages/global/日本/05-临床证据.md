# 日本 — 临床证据与学术研究

## 一、居家医疗（居家疗养）临床数据

### 1.1 居家临终照护率

- 日本全国**居家临终照护件数**持续增长。根据全国居家疗养支援诊所/医院向厚生局提交的正式报告（格式11之3），2024年8月—2025年7月期间：
  - 首位：冲绳县那霸市「那霸中央诊所」**年间825件**
  - 第2位：「青空诊所埼玉」682件
  - 第3位：「湘南石黑诊所」
  - 来源：[居家医疗com 排名2025年版](https://zaita9iryou.com/331104)、[PR TIMES](https://prtimes.jp/main/html/rd/p/000000010.000156371.html)

- 厚生劳动省「医疗设施调查」数据显示，实施居家临终照护的医疗机构数持续增加，从2014年的335设施增至2023年目标520设施（来源：[大阪府医疗计划](https://www.pref.osaka.lg.jp/iryo/keikaku/)）

### 1.2 居家医疗需求推计

- 厚生劳动省推计：2025年日本需要**居家医疗的患者约29万人**，较2010年增加约12万人
- 死亡场所别统计：居家死（自家）比例呈上升趋势，但仍低于医院死
- 来源：[厚生劳动省「居家医疗的最新动向」](https://www.mhlw.go.jp/seisakunitsuite/bunya/kenkou_iryou/iryou/zaitaku/dl/h24_0711_01.pdf)

## 二、上门护理站的患者结局指标

### 2.1 2024年度诊疗报酬改定评价

2024年度诊疗报酬改定中，上门护理相关的关键评价指标变化包括：

| 指标 | 改定内容 | 预期效果 |
|------|---------|---------|
| 功能强化型上门护理管理疗养费 | 增设专业护理评估 | 提高重度患者对应能力 |
| 24小时应对体制加算 | 区分2等级（最高6,800日元/月） | 促进24小时体制维持 |
| 紧急上门护理加算 | 区分14日内/15日以上 | 引导适当利用 |
| 出院支援指导加算 | 合计90分钟缓和 | 促进早期出院·居家复归 |
| 医疗数字化转型信息利用加算 | 新设（50日元/月） | 推进在线资格确认和信息利用 |

来源：[Care Team解说](https://careteam.jp/column/column001)、[GemMed](https://gemmed.ghc-j.com?p=59457)

### 2.2 上门护理的临床证据

- 通过上门护理介入，**入院回避率**平均约30-40%（国内外研究）
- 通过为医疗需求高的重度患者提供24小时·365天应对，提升「居家界限」
- 24小时应对体制加算的上位区分（甲：6,800日元）的算定条件中，通过ICT导入减轻负担的举措为必需条件

## 三、居家医疗协作枢纽项目的评价

### 3.1 事业概要

厚生劳动省「居家医疗协作枢纽项目」（2012年度开始）旨在通过多职种协作构建居家医疗支援体制。主要任务包括：
1. **多职种协作课题的解决**（年4次以上的会议）
2. **24小时应对体制的构建**（诊所间功能互补）
3. **信息共享系统的整备**（IT平台）
4. **对地域居民的普及启发**
5. **人才培养**

来源：[厚生劳动省「居家医疗协作枢纽项目」](https://www.mhlw.go.jp/seisakunitsuite/bunya/kenkou_iryou/iryou/zaitaku/dl/h24_0711_02.pdf)

### 3.2 评价方法

居家医疗·护理协作推进事业采用**PDCA循环**和**S-P-O（结构·过程·结局）**指标框架进行评价：
- **结构指标**：人口·老年人数量·设施数量·从业者数量
- **过程指标**：上门诊疗件数、居家临终照护件数、协作会议召开次数
- **结局指标**：居家死亡比例、主观幸福感、QOL

来源：[居家医疗·护理协作推进指标考量手册](https://www.jmar.co.jp/2025/04/09/llgr6_75_tebiki.pdf)

## 四、相关学术学会

### 4.1 日本居家医疗联合学会

- **第8届大会**：2026年7月4日—5日，札幌会议中心
- 主题涵盖：居家POCUS活用、多职种协作、RPM远程监测、上门护理结局评价
- 来源：[日本SigmaX出展信息](https://prtimes.jp/main/html/rd/p/000000646.000002354.html)

### 4.2 主要研究发表领域

| 研究领域 | 代表成果 |
|---------|---------|
| 居家终末期护理 | 居家临终照护质量评价（QOD、遗属调查） |
| 多职种协作 | 「看得见脸的关系」概念的建立（森田达也等, Palliat Care Res 2011） |
| 上门护理结局 | 居家复归率、入院回避率、患者满意度 |
| 医疗经济 | 居家医疗 vs 住院医疗的费用比较分析 |

### 4.3 居家医疗的证据差距

日本居家医疗领域面临的一个关键挑战是**临床证据的不足**：
- 与欧美相比，日本居家医疗的RCT（随机对照试验）数量较少
- 有关多职种协作和居家临终照护的高质量研究正在增加
- 日本居家医疗联合学会、日本初级保健联合学会等推进学术体系建设
