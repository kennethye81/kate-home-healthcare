# 日本 — 政策与法律法规

## 一、政策框架

介護保険法（2000）——全球首个以社会保险为基础的独立长护险。

| 维度 | 内容 |
|------|------|
| 法律 | 介護保険法（1997 公布/2000 実施） |
| 運営 | 市町村（保険者）+ 都道府県（支援） |
| 加入 | **40 歳以上**全員——65+（1号）/ 40-64（2号） |
| 認定 | 要支援 1-2 / 要介護 1-5（8 段階） |
| 原則 | 予防重視·自立支援·利用者本位 |

## 二、認定プロセス

1. **一次判定**：74 項目コンピュータ判定
2. **二次判定**：保健·医療·福祉専門家審査会
3. 全国統一基準——市町村格差最小化
4. 有効期間：要支援 6-12 ヶ月 / 要介護 6-24 ヶ月

## 三、地域包括ケアシステム

2025 年目標——中学校区ごとに：
- 医療 + 介護 + 予防 + 住まい + 生活支援
- 地域包括支援センター（全国 ~5,000 ヶ所）
- 24 時間定期巡回·随時対応サービス

### 介護保険法改正案（2026年4月提出）

- **ケアマネ更新制廃止** — 介護支援専門員の更新制度を見直し
- **人口減少地域に新サービス類型** — 過疎地向けの柔軟なサービス提供モデル創設
- **有料老人ホーム登録制創設** — 参入規制の緩和と透明性向上
- **介護情報基盤** — 2026年4月から順次開始、ICT活用による業務効率化とデータ連携推進

## 六、2040 年展望

65+ 35%·85+ 1,000 万人→介護人材 **280 万人**必要（現状 ~200 万人）。外国人介護人材受入れ拡大（特定技能·EPA）。
