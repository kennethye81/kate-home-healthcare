# 🇸🇬 新加坡 居家医疗/长照市场

## 一、市场概况

新加坡为 **「3M+C + AIC 主导」** 模式——强制储蓄+保险+安全网+长护险的独特组合。MOH 下属 AIC（护联中心）为居家护理的统一协调机构。

**核心数据**：

| 指标 | 数值 |
|------|------|
| 65+ 人口 | **18.4%**（2025）→ 25%（2030） |
| CareShield Life 参保人 | ~200 万 |
| AIC 居家服务（年） | ~10 万+ 人次 |
| 外籍家庭佣工（FDW） | ~**25 万**人——居家照护支柱 |
| MOH 健康支出 | ~S$160 亿/年 |

## 二、体系架构

```
MediSave (强制储蓄) → 门诊/住院/居家护理
MediShield Life (大病保险) → 高额住院
CareShield Life (长护险) → 严重失能月付 S$660+
MediFund (安全网) → 低收入最后保障
AIC (护联中心) → 居家服务统一入口+补贴管理
```

**关键特征**：「个人责任+家庭+政府」三角——MOH 补贴居家服务 30-80%（按收入），但家庭和外佣仍是照护的主力。

## 三、AIC 居家服务体系

- 居家护理（Nursing）：RN/EN 上门——伤口/导管/药物管理
- 居家康复（Therapy）：PT/OT 上门
- 居家个人照顾（Personal Care）：ADL 协助
- 送餐服务（Meals on Wheels）
- **MIC@Home** 试点——新加坡版 Hospital at Home

## 四、核心挑战

1. **外佣依赖**——25 万 FDW 是居家照护基石，政策变动冲击大
2. CareShield Life 的 S$660/月远不足以覆盖全职照护成本
3. MIC@Home 仍处试点——规模化路径不明
4. **2026.7 深挖 Speedoc**——03-头部机构/Speedoc|Speedoc 为新加坡唯一自有临床团队+MIC@Home 合同的私营 HaH 运营商，AI 全栈 (H-Grid+Gemini)，临床证据 BMC 2026 发表
