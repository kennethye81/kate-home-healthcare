# 新加坡 — 支付体系

## 一、支付模型全景

新加坡居家护理支付为 **「3M+C + AIC 分层补贴」** 五层结构。「个人-家庭-政府」三角平衡是新加坡模式的核心哲学。

```
                    ┌──────────────────────────────┐
                    │    新加坡 居家护理 支付         │
                    └──────────────────────────────┘
                                    │
        ┌──────────┬──────────┬─────┼──────┬──────────┐
        ▼          ▼          ▼     ▼      ▼          ▼
    MediSave   CareShield  Elder  Medi  AIC补贴    自费
    (强制储蓄) (长护险)    Fund  Fund  (30-80%)  (市场价)
```

| 支付通道 | 管理机构 | 覆盖 | 资金来源 |
|---------|---------|------|------|
| **MediSave** | CPF Board | 居家护理/门诊/住院 | 强制储蓄（工资 8-10.5%） |
| **CareShield Life** | MOH/AIC | 严重失能后月付现金 | 强制保费（MediSave 支付） |
| **ElderFund** | MOH | 30 岁以上重度失能低收入者 | 政府 |
| **MediFund** | MOH | 医疗安全网 | 政府捐赠基金 |
| **AIC 补贴** | AIC/MOH | 居家护理服务 | 政府预算（按 PCHI 分层） |
| **自费** | 个人/家庭 | 外佣/私营护理 | 个人 |

## 二、MediSave — 强制医疗储蓄

### 2.1 缴款率

| 年龄 | 雇主 | 雇员 | 合计 |
|:---:|:---:|:---:|:---:|
| ≤55 | 17% | 20% | **37%** |
| 55-60 | 15% | 16% | 31% |
| 60-65 | 11.5% | 10.5% | 22% |
| >65 | 9% | 7.5% | 16.5% |

其中分配至 MediSave 账户的比例随年龄增加（8-10.5% 区间）。

### 2.2 居家护理提取

| 用途 | 提取限额 | 条件 |
|------|:---:|------|
| 居家护理（Home Care） | **S$200/月** | 需医生推荐 |
| 日间照护（Day Care） | S$200/月 | 同上 |
| 住院 | S$550-750/天 | — |

**限制**：MediSave 的居家护理提取额度（S$200/月）远不足以覆盖全职照护——体现了新加坡「不鼓励过度依赖」的设计理念。

## 三、CareShield Life — 长护险

### 3.1 核心参数

| 指标 | 数值 |
|------|:---:|
| 启动 | **2020 年 10 月**（替代旧 ElderShield） |
| 参保 | **强制**——1980 年后出生自动加入 |
| 严重失能定义 | **不能独立完成 ≥3 项 ADL** |
| 月付金额 | **S$660/月**（2025），每年递增 **2%** |
| 终身支付 | ✅ 无期限限制（只要持续失能） |
| 保费支付 | 通过 **MediSave** 全额支付保费 |
| 政府补贴 | 中低收入者享受保费补贴（最高 30%） |

### 3.2 与 ElderShield 的区别

| 维度 | 旧 ElderShield | CareShield Life |
|------|:---:|:---:|
| 参保 | 默认退出（Opt-out） | **强制加入** |
| 支付 | S$300-400/月 | **S$660/月** |
| 期限 | 最多 6 年 | **终身** |
| 递增 | 无 | 2%/年 |

### 3.3 IDAPE

对于因年龄/既有疾病无法加入 CareShield Life 的群体，IDAPE（Interim Disability Assistance Programme for the Elderly）提供 S$150-250/月的现金补助。

## 四、AIC（护联中心）——居家服务补贴体系

### 4.1 收入分层补贴

AIC 根据 **人均家庭月收入（PCHI）** 确定补贴等级：

| PCHI 区间 | 补贴比例 | 典型家庭类型 |
|:---|:---:|------|
| **≤ S$1,800** | **80%** | 低收入 / 无收入 |
| **S$1,801 – 2,800** | **75%** | 低中收入 |
| **S$2,801 – 3,300** | **60%** | 中等收入 |
| **S$3,301 – 4,000** | **50%** | 中高收入 |
| **> S$4,000** | **30%** | 高收入 |

另有 **Pioneer Generation**（建国一代，+额外 10-20%）和 **Merdeka Generation**（立国一代，+额外 5-10%）附加补贴。

### 4.2 补贴后自付示例

| 服务 | 市场价（S$/月） | 80% 补贴后 | 30% 补贴后 |
|------|:---:|:---:|:---:|
| 居家护理（每周 3 次） | ~S$800 | **S$160** | S$560 |
| 日间照护（每周 5 天） | ~S$1,200 | **S$240** | S$840 |
| 居家康复（每周 2 次） | ~S$600 | **S$120** | S$420 |
| 送餐服务 | ~S$300 | **S$60** | S$210 |

## 五、Home Caregiving Grant (HCG)

| 维度 | 内容 |
|------|------|
| 金额 | **S$200-400/月**（按收入） |
| 用途 | 补贴居家照护费用（包括外佣薪资） |
| 条件 | 中度至重度失能、家庭 PCHI ≤ S$2,800 |
| 旧名 | Foreign Domestic Worker Grant（已合并） |

## 六、ElderFund

| 维度 | 内容 |
|------|------|
| 目标 | 30 岁以上重度失能、低收入（PCHI ≤ S$1,800） |
| 支付 | 月付 S$250（2025） |
| 特征 | 无需保费——完全政府资助 |

## 七、私营/自费市场

| 服务 | 月费（S$） | 说明 |
|------|:---:|------|
| 外籍女佣（FDW） | ~S$600-800 | 月薪 + 征税 + 食宿——新加坡居家照护最普遍的解决方案 |
| 私营居家护理员 | S$1,500-2,500 | 全职 |
| 私营护理院 | S$2,000-4,500 | 经济型→高端 |
| 私立医院 HaH | S$3,000-8,000 | 急性居家替代 |

**关键洞察**：新加坡 25 万外佣（FDW）是居家照护的**实际主力**——月成本 S$600-800 远低于正式居家护理（S$1,500+）。CareShield Life 的 S$660/月刚好约等于一个外佣的月成本。

## 八、支付体系 SWOT

| | 优势 | 劣势 |
|------|------|------|
| | • **多层安全网**——CareShield+MediSave+AIC+ElderFund+MediFund 五层保护 | • 「个人-家庭」责任过重——自付比例高于北欧/日本 |
| | • 外佣 S$600/月→极低成本的居家照护方案 | • 外佣依赖带来的质量和稳定性风险 |
| | • AIC 分层补贴设计精妙——精准定向 | • MediSave S$200/月提取限制太低 |
| | **机遇** | **威胁** |
| | • MIC@Home 若规模化可开辟新支付通道 | • 老龄化加速（65+ 18%→25%）——财政压力 |
| | • 数字健康/远程监测可降低人力成本 | • 外佣政策收紧（征税上升/配额减少） |
