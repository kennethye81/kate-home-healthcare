## 一、护理人力总体供需格局

### 供给端：结构性短缺

以色列医疗卫生人力长期低于OECD平均水平，尤其在护理领域短缺严重：

| 人力指标 | 以色列 | OECD平均 | 差距 |
|:---|:---|:---|:---|
| 执业医师/1,000人 | 3.5 | 3.9 | -10% |
| **执业护士/1,000人** | **5.6** | **9.2** | **-39%** |
| 医护比 | 1.6:1 | 2.5:1 | — |
| 医学毕业生/100,000人口 | — | — | 在36个OECD国家中排名垫底（2023年数据） |

（来源：OECD Health at a Glance 2025: Israel; Jerusalem Post, 2025; PMC, 2023）

### 需求端：老龄化+政策效应叠加

| 需求驱动因素 | 影响 |
|:---|:---|
| 75岁以上人口年均增长20,000-30,000人 | 直接增加护理需求基数 |
| NII受益人数2017-2022年增长80% | 政策扩大覆盖+人口老龄化双重效应 |
| Gila改革 (2018) 提高了护理小时/受益人 | 同样数量的受益人需要更多护理人力 |
| 社区优先政策（Aging in Place） | 居家护理需求进一步超过机构护理 |
| HaH扩展 | 急性居家住院需要更高资质的护士（非一般护理员） |

### 供需缺口估算

仅NII长护险一项，339,000受益人若平均每人每周需15小时护理，则全年需要：
- 约 **2.64亿护理小时/年**（339,000 × 15 × 52周）
- 折合约 **127,000名全职护理员**（按每年2,080工时计算）

而以色列的执业护士总数仅约5.3万名（9.5M人口 × 5.6/1,000），其中直接从事老年居家护理的比例极低。**供需缺口巨大，外籍护工填补了大部分缺口**。

## 二、居家护理劳动者分层

以色列的居家护理劳动力可分为三个层级：

### 层级 1：注册护士（Registered Nurse / RN）

| 维度 | 描述 |
|:---|:---|
| **角色** | HaH项目核心人员，负责静脉用药、伤口护理、病情评估、远程监测解读 |
| **资质** | 本科护理学位 + 以色列护士注册 |
| **数量** | 约5.3万执业护士（总），从事居家护理的比例较低 |
| **薪资** | 公立医疗机构标准薪资，约10,000-15,000 NIS/月起 |
| **瓶颈** | 护士严重短缺（5.6/1,000），社区/居家方向吸引力低于医院 |

### 层级 2：执业护士/社区护士（Practical Nurse / Community Nurse）

| 维度 | 描述 |
|:---|:---|
| **角色** | 慢性病管理、常规护理操作、健康宣教、基础评估 |
| **资质** | 2年制执业护理文凭 + 注册 |
| **数量** | [待补充] |
| **瓶颈** | 同样面临短缺；社区方向地位/薪酬低于医院 |

### 层级 3：护理员/看护（Métapel/Métapelet / Caregiver）

| 维度 | 描述 |
|:---|:---|
| **角色** | ADL协助（洗浴、穿衣、转移、进食）、陪伴、简单家务 |
| **资质** | 基础护理培训（NII要求，但标准有限） |
| **人群构成** | **以外籍护工为主**（菲律宾、印度、东欧为主），少数以色列籍 |
| **薪资** | 最低工资标准：~6,248 NIS/月（2025年4月） |
| **雇主** | 多数由NII给付覆盖（通过签约护理公司派遣），或私人雇用 |

> **术语**：métapel (מטפל, 男性护理员) / metapelet (מטפלת, 女性护理员) 是以色列通用的护理员称呼，无论是以色列籍还是外籍。在实际语境中，该词常特指外籍居家护工。

## 三、外籍护工政策与现状

### 外籍护工来源国构成

| 来源国 | 估计人数 (2024-2025) | 占比趋势 | 文化特征 |
|:---|:---|:---|:---|
| **菲律宾** | ~20,154人 | 最大单一来源 | 英语能力好，护理培训较系统，基督教文化 |
| **印度** | ~11,827人 | 增长中 | 印度政府积极推动护理劳务输出 |
| **东欧**（摩尔多瓦、乌克兰等） | 数千人 | 下降中 | 受战争影响（乌克兰），传统来源但供应不稳定 |
| **尼泊尔/斯里兰卡** | 小规模 | 补充来源 | — |
| **其他国家** | — | — | — |

（来源：Facebook / Migrant Caregivers社群数据，2025年）

### 签证与工作许可制度

以色列的外籍护工制度基于**"绑定"模式**（Binding Arrangement）：

```
外籍护工进入以色列的路径：

路径A：通过持牌人力中介机构
  └── 以色列人力中介在国际市场招聘
      获得工作签证（B/1签证，护理行业）
      └── 抵达后与特定雇主（老年/残障人士）"绑定"
          护工的工作许可挂靠在该雇主名下
          
路径B：私人安排
  └── 家庭直接联系海外护工
      通过以色列内政部（Population and Immigration Authority）申请
      常规流程需数月

⚠️ "绑定"制度的争议：
  - 护工离职需获得当前雇主同意
  - 如与雇主产生纠纷，护工处于弱势地位
  - 护工不得自由转换雇主（除非特殊批准）
  - 人权组织长期批评该制度可能导致剥削
```

### 签证配额与政策波动

| 时间节点 | 政策变化 |
|:---|:---|
| **2023-2024** | 在战争/安全局势下，政府考虑了特殊外籍护工签证安排 |
| **2025年** | 持续的外籍护理劳工人道主义签证讨论，但无系统性改革 |
| **整体趋势** | 签证配额趋紧（政治因素），但老龄化需求持续增长 → 供需矛盾加剧 |

### 最低工资标准演变

|:---|:---|:---|:---|
| 2023.4 | ~5,572 | — | — |
| 2024.4 | **~5,880** | — | +5.5% |

| 2026.4（预告） | [待确认] | [待确认] | 年度调整 |

### 外籍护工的实际总成本

雇主（老年家庭或其家属）的实际总支出远高于最低工资：

| 成本项目 | 月额估算 (NIS) |
|:---|:---|
| 基本工资（最低标准） | ~6,250 |
| 养老金/遣散费提取（雇主支付部分） | ~530-1,000 |
| 健康保险/国民保险 | ~500-700 |
| 住宿（如提供） | 非现金/折算 |
| 食品/公用事业（如提供） | 非现金/折算 |
| 休假/病假/节假日工资 | 按法定 |
| **雇主月总支出（约）** | **~7,500-9,000+ NIS** |

加上住宿和食品，实际全包成本可达**9,000-12,000 NIS/月**。而NII长护险Level 3的平均给付价值约为每周16-20小时护工服务——折合每月远不足以覆盖全职外籍护工的成本，**大量家庭需要自掏腰包补差**。

## 四、iSavta 在线护工匹配平台

### 平台简介

**iSavta** 是以色列领先的在线外籍护工匹配平台（详见 03-头部机构/iSavta.md），直接连接老年家庭与来自菲律宾、印度等国的护工。

| 维度 | 描述 |
|:---|:---|
| **商业模式** | 在线平台匹配（类似"护工领域的Airbnb"）+ 签证/行政支持 |
| **覆盖** | 以色列全国 |
| **核心价值** | 降低中介费用、提高匹配透明度、缩短等待时间 |
| **市场定位** | 填补传统人力中介与私人直接雇佣之间的空白 |

## 五、人力短缺对HaH的影响

### 护士短缺是HaH规模化的最大瓶颈

**居家住院比传统病房更需要高年资护士**，因为：
- HaH护士需独立决策（无医生在场，无快速会诊）
- 需具备更广泛的多学科知识（内、外、急诊、老年科交叉）
- 需驾驶和移动能力（上门访问）
- 需较强的沟通能力（面对焦虑的家庭环境）

**量化估算**：若每个HaH护士同时管理5-8名居家患者（每日访问1-2次+远程监测），全国HaH年收治若扩展到50,000人次/年，需要额外约300-500名专职社区HaH护士——这在当前护士整体短缺（5.6/1,000）的背景下是重大挑战。

### 社区物理治疗师/职业治疗师短缺

| 康复师类型 | 供给状态 | 对居家护理的影响 |
|:---|:---|:---|
| **物理治疗师（PT）** | 不足，多数在医院/私营门诊 | 术后康复/跌倒预防/功能训练能力受限 |
| **职业治疗师（OT）** | 严重不足 | 居家环境改造/ADL训练受限 |
| **言语治疗师（SLP）** | 极度稀缺 | 脑卒中后居家康复受限 |

### 政府应对

| 措施 | 状态 |
|:---|:---|
| 增加医学院招生名额 | 逐步实施（但培养周期长） |
| 临床实践向社区转移导向 | 政策鼓励但缺乏具体激励机制 |
| 扩大外籍护工签证配额 | 政治敏感，进展缓慢 |
| 远程医疗/数字工具替代 | 积极推动（详见04-RPM与技术设备.md） |
| 护理师（Nurse Practitioner）角色 | 正在探索中，尚未系统推广 |

## 七、关键趋势与政策展望

### 趋势1：外籍护工依赖不可逆

以色列本土护理员供给有限（工作强度大、社会地位不高、薪资相对低），外籍护工依赖度短期内无法降低。随着老龄化加速，需求还将继续增长。

### 趋势2：印度成为增长最快来源国

印度政府的护理劳务出口政策（2023-2024年加速推进）+ 以色列-印度双边劳务协议 = 印度护工人数快速增长。印度护工英语能力普遍较好，培训体系正在快速完善。

### 趋势3：数字平台重构护工市场

iSavta等在线平台正在减少传统中介的信息不对称和中介费用，但也引发了对护工权益保护（如平台是否承担雇主责任）的新争议。

### 趋势4：远程监测部分替代人力

随着Sensi.AI等AI监测技术成熟，部分低风险老人的全天候"人在场"护理需求可能被"技术在场"替代——但仅限于特定场景，无法完全替代人的照料。

### 趋势5：NII护理公司招标改革

2022年NII发布了新的长护服务供应商招标，包含加强监督的条款。若该招标能全面落地实施，有望改善护理员的工作条件和服务质量。
