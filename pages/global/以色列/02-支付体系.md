# 以色列 — 支付体系

## 一、支付模型全景

以色列长期护理支付为**「社会保险为主 + 私营保险补充 + 自费」三层结构**：

```
                    ┌────────────────────────────┐
                    │   以色列 LTC 支付体系        │
                    └────────────────────────────┘
                                    │
          ┌──────────┬──────────┬───┴────┬──────────┐
          ▼          ▼          ▼        ▼          ▼
       NII/社保    MOH资助    MOLSA    私营保险    自费
      (居家护理)  (护理院)  (辅助居住)  (补充)   (市场化)
```

| 支付通道 | 管理机构 | 覆盖范围 | 支付方式 | 受益人规模 |
|---------|---------|---------|---------|:---:|
| **NII 长护险** | 国家保险研究院 | 社区居家个人护理 | 实物给付（in-kind），最高 16小时/周 | ~160,000人 |
| **MOH「卫生部编码」** | 卫生部 | 护理院入住 | 部分/全额资助（经济状况调查） | ~14,000人 |
| **MOLSA 辅助居住** | 社会事务部 | 庇护住房/辅助居住 | 资助（经济状况调查） | — |
| **私营 LTC 保险** | 商业保险公司 | 补充现金给付 | 按月缴费→现金理赔 | 广泛 |
| **自费** | 个人/家庭 | 全部机构类型 | 市场价 | — |

## 二、NII 长护险 — 支付细节

### 2.1 资金来源

| 来源 | 说明 |
|------|------|
| **工资税（雇主+雇员）** | 全民强制缴费，以色列所有居民按收入缴纳 NII 保险费 |
| **政府财政补贴** | 以色列政府对 NII 赤字提供补贴 |
| **移民缴费历史** | 新移民（Olim）如无 NII 缴费记录，可能无法立即获得完整福利 |

### 2.2 NII 支出规模

| 年份 | NII LTC 年支出 | 说明 |
|------|:---:|------|
| 2011 | **NIS 40亿**（~$10亿美元） | 占 GDP 0.5% |
| 2017（改革前） | **NIS 70亿** | — |
| 2020 | **NIS 53.1亿** | 占公共 LTC 支出的 64% |
| 2025（改革后） | **NIS 210亿** | 三倍增长，反映 2018 年改革效果 |

来源：PMC (2013)、Jerusalem Post (2025)、Expat Focus (2024-2025)

### 2.3 受益人规模

| 年份 | 受益人数 | 说明 |
|------|:---:|------|
| 2011 | **145,600人** | 占社区正式照护老年人的 80% |
| 2020 | **~160,000人** | — |

### 2.4 给付标准

| 指标 | 数值 | 说明 |
|------|:---:|------|
| 每周护理小时上限 | **16 小时/周** | 2018 改革后水平 |
| 服务类型 | 个人照料、备餐、清洁、购物 | 实物给付 |
| 给付形式 | **In-kind（实物）**——不发放现金 | 区别于私营保险的现金给付 |
| 服务机构 | 持牌私营就业机构 | 国家保险研究院直接付款给机构 |

### 2.5 受益条件

- 达到退休年龄（男 67 / 女 62-65）
- 社区居住（非机构）
- ADL 评估确认为失能
- NII 缴费记录达标
- 以色列合法居民身份

## 三、MOH 卫生部 — 护理院支付

### 3.1 「卫生部编码」计划

卫生部通过「Kod Misrad HaBriut」计划为合资格老年人提供护理院入住资助：

| 条件 | 要求 |
|------|------|
| 年龄 | 60-65 岁以上 |
| 医疗评估 | 医学确认需要机构照护 |
| 经济状况调查 | 收入和资产低于门槛 |
| 其他福利先耗尽 | 须先用完 NII 长护险福利 |
| 合法身份 | 以色列合法居民 |

### 3.2 资助规模

- MOH + MOLSA 合计支出：**NIS 21亿**（~26% 公共 LTC 支出）
- 受益人数：约 **14,000 名**老年人

## 四、私营 LTC 保险

### 4.1 市场特点

以色列拥有全球最发达的**私营（商业）长期护理保险**市场之一。约半数以色列成年人购买补充性商业 LTC 保险。

| 维度 | NII 公共保险 | 私营商业保险 |
|------|:---:|:---:|
| 参保方式 | 强制 | 自愿 |
| 给付形式 | **实物**（in-kind 护理服务） | **现金**（cash benefit） |
| 覆盖缺口 | 16 小时/周可能不足 | 补充现金可用于自选照护方式 |
| 保费 | 工资税 | 按年龄/健康状况市场化定价 |

### 4.2 市场动态

- 多家保险公司（如 Clal、Migdal、Harel、Phoenix 等）提供 LTC 产品
- 2020 年代因 LTC 成本上升，部分保险公司停止销售新保单或提高保费
- Myers-JDC-Brookdale 研究所定期发布私营 LTC 保险市场研究报告

## 六、跨境/外籍护理员支付

以色列的外籍护理员制度有独特的支付逻辑：

- 老年人通过 NII 获得「外籍护理员雇用许可证」
- 通过私营中介（如 iSavta 等）招聘菲律宾/印度/尼泊尔等国护理员
- 全职外籍护理员月薪 **₪7,000-15,000**，由家庭自费为主
- NII 的 16 小时/周服务不足以覆盖全职需求 → 外籍护理员填补缺口
- 形成了「NII 基本照护 + 家庭自费外籍全职护理员」的二元照护结构

## 七、支付体系 SWOT

| | 优势 | 劣势 |
|------|------|------|
| | • 1988 年起步，**全球最早的长护险之一** | • **碎片化**——NII/MOH/MOLSA 三轨并行 |
| | • 实物给付（in-kind）防现金滥用 | • 16 小时/周对重度失能**严重不足** |
| | • 私营保险市场成熟——可补充公共覆盖 | • 护理院床位严重不足（2.1万张 vs 老龄化需求） |
| | • 2018 改革大幅扩展（支出 3 倍增长） | • NII 支出增速远超 GDP——**财政可持续性存疑** |
| | **机遇** | **威胁** |
| | • 2018 以色列银行提案（整合至健康基金）可解决碎片化 | • 政治僵局——改革提案多年未立法 |
| | • 数字健康/远程监测可降低居家照护成本 | • 外籍护理员供应链地缘政治风险 |
| | | • 65+ 人口从 12%→14%（2030）→更快的需求增长 |
