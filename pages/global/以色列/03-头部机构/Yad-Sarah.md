# Yad Sarah（以色列）

**业务形态：** 以色列最大志愿组织——免费出借 300+ 种医疗康复设备（轮椅/病床/制氧机等），并运营日间康复中心、紧急报警系统、上门牙科、法律援助等 20+ 项社区居家服务

## 关键数据
- 成立：1976 年（2026 年 50 周年）/ 126+ 分支 / 7,000+ 志愿者 / ~150 职员
- 年设备出借：244,000+ 件 / 库存 ~300,000 件 / 年服务 125 万+ 人次
- 年运营预算：~$29M–49M（100% 捐赠，零政府资助）
- 年节省医疗成本：NIS 55 亿（~$1.5B USD）——每投入 $1 为医疗系统节省 ~$50
- CEO：Moshe Cohen / 创始人：Rabbi Uri Lupolianski（前耶路撒冷市长）
- 荣誉：Israel Prize (1994) / UN ECOSOC 咨询地位 (2005)

**核心特征：** 全球最大医疗设备志愿出借网络——通过免费/近乎免费提供居家康复设备，让术后患者和老年人不必因设备短缺而被迫住院，累计「每两个以色列家庭就有一个被帮过」。2023.10 战争后成立士兵康复单元，已支援 2,500+ IDF 伤兵。模式已被美国 Wheel it Forward、Maryland DME Re-Use 等复刻。
