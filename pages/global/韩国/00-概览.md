# 🇰🇷 韩国 HaH/居家医疗

## 国家概况

| 指标 | 数值 |
|:---|:---:|
| 总人口（2025年） | 约 5,170 万人 |
| 65岁以上人口比例 | 约 19%（2025年预计突破20%） |
| 老龄人口预测 | 2036年超30%，进入超高龄社会 |
| 人均 GDP | 约 $35,000 |
| 医疗保险制度 | 国民健康保险（NHI，全民强制参保） |
| 长期护理保险 | 老人长护险（2008年引入，覆盖65+及部分年轻失能者） |

## 制度框架

### 国民健康保险（NHI）
- 全民强制参保，覆盖医疗、住院、药品
- 2024年起推进远程医疗制度化（COVID后加速）
- 数字健康纳入报销范围：电话/视频诊疗、CGM、血压监测指导费

### 老人长护险（노인장기요양보험, 2008年引入）
- 覆盖65岁以上及部分年轻失能者
- 服务类型：居家护理（방문요양）、日间照护（주간보호）、短期 respite
- 2024年参保人数约1,100万人
- 给付等级：1-5级（按失能程度分级）
- 居家护理人力：访问护士约3.1万人、访问照护员约19.8万人

## 居家医疗/HaH 市场

| 指标 | 数值 |
|:---|:---:|
| 数字健康市场规模（2024年） | 4.5-5万亿韩元（~$35-40亿） |
| RPM/远程监测 | 慢性病管理为主（高血压、糖尿病、心衰） |
| 主要远程医疗供应商 | 三星、LG、SK Telecom、Kakao Healthcare |
| HaH 试点 | 居家重症管理试点中，费用节省约45.5% |
| 访问护理机构数 | 约 17,000 家 |

## 关键数据摘要

### RPM 与技术设备
- 韩国数字健康产业以 ICT 巨头为驱动（三星/LG/SKT）
- 政府「数字健康综合计划」推进中
- NHI 对远程监测的报销逐步放开
- 主要技术供应商：HUMASOFT, InBody, i-SENS, VUNO, DoctorNow

### 临床证据
- 首尔大学高血压 RCT（n=1,024）：远程监测有效控制血压
- 延世大学 CGM 糖尿病研究（n=512）
- 国家癌症中心居家安宁研究（n=2,486）
- NECA 系统评价：RPM 年节省 18-48 万韩元/人
- HaH 居家重症管理节省 45.5% 费用

### 劳动力市场
- 注册护士：54.5万人注册 / 45.5万人执业（OECD 8.2人/千人）
- 访问护士：约3.1万人
- 访问照护员：约19.8万人
- 护士年薪：3,400-5,000万韩元
- 护士缺口预测：2025年4.1万 → 2035年11.2万人
- 政府应对：护理人力综合对策、疗养保护师待遇改善

## 主要供应商/机构
- 居家护理市场极度分散，无单一主导企业
- 大型财团（三星、LG、SKT）通过技术平台参与
- 专业居家护理机构多为中小规模
