# 🇰🇷 04 — RPM与技术设备

**政策环境：** MyHealthWay 数据平台 + AI医疗器械整合审查改革（2022年）+ 「第四次产业革命」健康领域战略
**RPM 市场规模（2024年）：** **4.33亿美元**，预计2035年达 22.98亿美元（CAGR **16.3%**）
**代表性企业：** SILWHON、Kakao Healthcare、多家 AI 健康监测初创
**关键标准：** KHIS（韩国健康信息标准）推动互操作性
**当前痛点：** 远程医疗法律限制、数字鸿沟（52%老人需协助使用医疗APP）、保险覆盖不足


## 1. 韩国数字健康（Digital Health）发展总览

### 1.1 国家战略定位

韩国政府将数字健康列为「第四次产业革命」的核心战略方向：

| 战略要素 | 具体内容 |
|---------|---------|
| **MyHealthWay 平台** | 国家级个人医疗数据聚合与共享平台，支持跨机构数据流通和患者自主管理 |
| **AI医疗器械整合审查评价制度** | 2022年10月改革实施，大幅加速 AI 数字医疗设备的监管审批流程 |
| **K- Digital Health** | 韩国政府推动的数字健康出口品牌，整合 AI、IoT、5G 等技术 |
| **数据三法修订** | 《个人信息保护法》《信用信息法》《信息通信网法》修订，为医疗数据利用提供法律基础 |

**来源：PMC Healthcare Inform Res 2024；Korea Biomedical Review 2026**

### 1.2 数字健康基础设施

| 基础设施 | 说明 |
|---------|------|
| **全民 EHR（电子健康记录）** | 韩国几乎所有医疗机构已完成 EHR 部署，数据基础扎实 |
| **NHIS 大数据** | NHIS 拥有全国范围的健康保险大数据，涵盖诊断、处方、就诊全链条 |
| **HIRA 数据** | HIRA 持有全国医疗费用审查数据，支持质量评估和研究分析 |
| **5G 网络覆盖率** | 全球最高之一，为远程医疗和实时监测提供通信基础 |

## 2. 远程患者监测（RPM）市场

### 2.1 市场规模与增长预测

| 指标 | 数值 |
|------|------|
| 2024年市场规模 | **4.33 亿美元** |
| 2025年市场规模（预估） | 约 5.04 亿美元 |
| 2035年市场规模（预估） | **22.98 亿美元** |
| CAGR（2025-2035） | **16.3%** |
| 主要驱动因素 | 老龄化加速、慢性病患病率上升、远程医疗政策放宽、5G 基础设施 |

**来源：Market Research Future 2025**

### 2.2 RPM 主要应用领域

| 应用领域 | 说明 | 成熟度 |
|---------|------|--------|
| **慢性病管理**（糖尿病、高血压） | 血糖/血压远程监测 + AI 分析，警报生成 | 🔴 成熟——已商业化 |
| **心血管监测** | 可穿戴 ECG、心率变异性远程监测 | 🟡 增长中 |
| **术后居家监测** | 出院后生命体征远程追踪 | 🟡 试点扩展中 |
| **老年人安全监测** | AI 跌倒检测、异常行为识别、GPS 定位 | 🟡 早期商业化 |
| **认知症管理** | 数字疗法 + 行为监测 | 🟢 早期——监管审批中 |
| **居家康复** | 康复机器人 + 远程物理治疗指导 | 🟢 早期商业化 |

**来源：Korea Biomedical Review 2026；Ga H. AGMR 2024**

## 3. KHIS（韩国健康信息标准）

KHIS（Korea Health Information Standards）是韩国推动医疗数据互操作性的核心技术标准框架：

| 维度 | 内容 |
|------|------|
| 目的 | 推动医疗机构间、医疗-LTC 机构间的数据标准化和互操作性 |
| 标准基础 | 基于 HL7 FHIR、SNOMED CT、ICD-10 等国际标准进行本地化 |
| 覆盖范围 | 诊疗记录、护理记录、用药记录、检查结果、转诊信息 |
| 与 MyHealthWay 关系 | KHIS 为 MyHealthWay 平台的数据交换标准基础 |
| 实施阶段 | 大型医院已基本实现，中小机构和 LTC 机构正在推进 |

**来源：PMC Healthcare Inform Res 2024**

## 4. 居家医疗中的技术应用

### 4.1 PICS-K 项目中的技术实践

韩国最具代表性的整合居家医疗项目 PICS-K（NHIS 一山医院）展示了居家医疗的典型技术配置：

| 技术/工具 | 应用方式 | 效果 |
|----------|---------|------|
| **Kakao Channel** | 居家患者实时咨询平台（基于韩国最大社交通讯软件） | 使用者满意度高，降低沟通成本 |
| **分级远程监控** | 按病情严重程度设定不同周期的电话/远程监控频率 | 优化资源配置，减少不必要的上门 |
| **NHIS 大数据** | 用于患者识别、用药史分析、风险分层 | 精准筛选适合居家医疗的患者 |
| **出院前评估** | 多学科团队（IDT）出院前会议 + 电子评估工具 | 确保转介连续性 |

**来源：Mun H et al. PICS-K. Int J Integr Care 2023;23(2):1-12**

### 4.2 其他技术应用场景

| 技术 | 应用场景 | 当前状态 |
|------|---------|---------|
| **可穿戴健康监测** | 智能手表/手环进行生命体征远程上传（心率、血氧、活动量） | 市场增长中，尚未大规模纳入保险支付 |
| **居家康复机器人** | 韩国多家初创企业（如 Neofect、H-Robotics）开发居家上肢/下肢康复设备 | 早期商业化阶段 |
| **AI 跌倒检测** | 基于摄像头或雷达的人员跌倒与异常行为识别 | 部分养老机构和居家试点 |
| **数字疗法（DTx）** | 认知症预防/管理 App（如 Neurophet、WELT） | 监管审批推进中 |
| **智能药物管理** | AI 用药提醒 + 远程用药依从性监测 | 部分 LTC 机构部署 |
| **语音/视频 AI 认知评估** | 通过语音和视频分析进行认知功能评估 | 研究/试点阶段 |

**来源：PMC Healthcare Inform Res 2024；Korea Biomedical Review 2026**

## 6. 监管环境与创新壁垒

### 6.1 远程医疗法律限制

| 时间 | 政策变化 |
|------|---------|
| COVID-19 前 | 《医疗法》严格限制非面对面诊疗（原则上禁止） |
| 2020年 COVID-19 | 政府临时放宽——允许电话咨询和远程处方 |
| 2022年后 | 部分临时措施逐步撤回，但推动立法永久化 |
| 当前（2026年） | 远程医疗法律地位尚在立法讨论中，医师协会强烈反对完全放开 |

### 6.2 其他关键障碍

| 障碍 | 说明 |
|------|------|
| **数字鸿沟** | 52%的 65岁以上老年人需要协助才能使用医疗移动应用（2025年数据） |
| **保险覆盖不足** | 大多数数字健康服务尚未纳入 NHI/LTCI 支付范围 |
| **数据隐私** | 个人医疗数据跨机构共享的法律和伦理框架仍不完善 |
| **互操作性** | 中小型 LTC 机构的 EHR/KHIS 合规度不高 |
| **碎片化市场** | 大量小型数字健康初创企业，缺乏整合平台 |

**来源：PMC Healthcare Inform Res 2024；Korea Biomedical Review 2026**

## 7. 未来趋势与机遇

1. **《社区整合照护支援法》驱动数字化**：2026年施行后，统一评估和服务连接机制将引入数字平台支持，为 RPM、远程咨询、电子个案管理创造政策窗口。

2. **AI 医疗器械审批加速**：2022年改革后，AI 数字医疗设备的市场准入流程缩短，预计更多居家监测和数字疗法产品获批。

3. **MyHealthWay 平台扩展**：随着更多医疗机构和 LTC 机构接入，个人健康数据的跨机构流通将改善居家医疗的连续性和质量。

4. **Kakao 等互联网平台的跨界整合**：依托全国性用户触达能力，可能成为居家医疗的"数字前门"和患者入口。

5. **RPM 市场高增长**：16.3%的 CAGR 持续到 2035年，预计随着保险覆盖扩大和政策放开，增长将进一步加速。

**来源：Market Research Future 2025；PMC Healthcare Inform Res 2024；Korea Biomedical Review 2026**
