# 🇰🇷 06 — 劳动力市场

**从业人员总数（2025年）：** 约 **72.7万人**，其中 요양보호사（疗养保护士）65.4万人（**90.0%**）
**核心职业：** 요양보호사（疗养保护士）→ 240小时培训 + 国家资格考试；간호사（护士）→ 4年大学 + 国家资格考试
**关键挑战：** 67%兼职率、低薪资、居家诊疗医师极度稀缺（0.8%）、专业护士占比极低
**外籍劳动力：** E-9 签证（非专业就业）逐步扩展至护理领域
**供需预测：** 老年人 1,100万人 vs 从业人员 72.7万人，照护比约 **1:15**


## 1. 护理人力分类与资格要求

### 1.1 核心职业类别

| 职业（韩文） | 中文名称 | 培训要求 | 主要职责 |
|------------|---------|---------|---------|
| 요양보호사 | 疗养保护士 | **240小时培训** + 国家资格考试 | 日常生活照护（沐浴、进食、移动、排泄辅助等） |
| 간호사 | 注册护士 | **4年大学护理专业** + 国家资格考试 | 专业护理操作、评估、用药管理、伤口护理 |
| 간호조무사 | 护理助理 | 培训 + 资格考试 | 辅助护理、生命体征测量、基本护理操作 |
| 사회복지사 | 社会工作者 | 社会福利专业学位 + 国家资格 | 服务协调、心理支持、资源链接、福利申请 |
| 의사 | 医师 | **医学院6年** + 实习 + 专科培训（总计约10-12年） | 上门诊疗、处方开立、健康评估、疾病诊断 |

**来源：NHIS《健康保险及长期疗养保险制度说明手册》（2023版）；Ga H. AGMR 2024**

### 1.2 疗养保护士（요양보호사）培训体系

| 维度 | 内容 |
|------|------|
| 培训时长 | **240小时**（约6-8周全日制） |
| 培训内容 | 基础护理理论、ADL 辅助技术、沟通技巧、伦理、感染控制、急救 |
| 资格考试 | 全国统一国家资格考试 |
| 对比国际 | 日本介護福祉士需 1,850小时培训（约2年），韩国培训时长远低于日本 |

> ⚠️ 240小时培训被 OECD 和学术界广泛批评为"不足以应对日益复杂的老年人照护需求"（Lee HY et al. 2022）。

**来源：Lee HY et al. Arch Public Health 2022**

## 2. 从业人员规模与结构

## 3. 薪资与劳动条件

### 3.1 薪资水平

| 职业 | 月薪范围（韩元） | 约合美元/月 | 评价 |
|------|----------------|-----------|------|
| 요양보호사（疗养保护士） | 180-220万 | ~$1,370-$1,670 | 服务业底层水平 |
| 간호조무사（护理助理） | 200-250万 | ~$1,520-$1,900 | 略高于保护士 |
| 간호사（注册护士：LTC机构） | 250-350万 | ~$1,900-$2,660 | 中等 |
| 사회복지사（社会工作者） | 220-280万 | ~$1,670-$2,130 | 中等偏低 |
| 의사（居家诊疗医师） | 按诊疗量计费 | 变异性大 | 低于机构内诊疗 |

> ⚠️ 以上为近似范围（2024-2025年参考值），实际薪资因机构类型、工作形式（全职/兼职）、地区差异而异。

### 3.2 劳动条件

| 指标 | 数据 | 说明 |
|------|------|------|
| **兼职/临时合同比例**（2020年） | **67%** | 三分之二的 LTC 劳动力为非正规雇佣 |
| 性别比例 | 女性占绝对多数（>90%） | 典型的女性密集型行业 |
| 平均年龄 | 50-60岁为主 | 中高龄女性为主要劳动力供给群体 |
| 人员流失率 | 高——年均流失率估计 20-30% | 低薪资+高劳动强度+情感负担 |
| 职业伤害 | 高——腰痛、肌肉骨骼损伤频发 | 身体负荷大，缺乏充分防护培训 |

**来源：OECD Health at a Glance 2023；Lee HY et al. Arch Public Health 2022**

## 4. 供需分析

### 4.1 供需对比

| 指标 | 数值 |
|------|------|
| 65岁以上人口（2025年） | 约 **1,100万人** |
| LTCI 认定人数（2025年） | **123.5万人**（每10名老人中 >1人） |
| LTCI 从业人员总数 | **72.7万人** |
| 从业人员 / 65岁以上人口 | 约 **6.6人/100名65+** |
| 从业人员 / LTCI 认定者 | 约 **0.59人/1名认定者**（即约 1.7名认定者配备 1名从业者） |

### 4.2 国际比较

| 指标 | 韩国 | OECD 平均 |
|------|------|----------|
| LTC 从业人员/100名65岁以上人口（2021年） | **4.8人** | 约 5.0人 |
| 其中疗养保护士（240小时培训）占比 | **90%** | 各国差异大（日本约60-70%） |
| 兼职/临时合同比例 | **67%** | — |

**来源：OECD Health at a Glance 2023/2025**

### 4.3 结构性短缺因素

| 因素 | 分析 |
|------|------|
| **人口老龄化加速** | 2025年进入超高龄社会，85岁以上人口在 2025-2035年激增 |
| **劳动力供给萎缩** | 韩国生育率全球最低（0.72，2023年），年轻劳动力持续减少 |
| **行业吸引力不足** | 低薪资、低社会地位、高劳动强度 → 难以吸引年轻人和男性 |
| **专业医疗人员稀缺** | 0.8%的初级医师提供上门诊疗（2020年高阳市数据）；护士集中在医院 |
| **培训质量瓶颈** | 240小时培训被认为不足以应对复杂照护需求 |

**来源：Lee HY et al. Arch Public Health 2022；OECD 2025**

## 5. 外籍护工与外籍劳动力政策

### 5.1 E-9 签证（非专业就业）

| 维度 | 内容 |
|------|------|
| 签证类型 | E-9（非专业就业，Non-professional Employment） |
| 适用领域 | 制造业、农业、渔业、建筑业、**服务业（逐步扩展至护理）** |
| 配额 | 政府每年设定 E-9 签证总配额（逐年增加） |
| 护理领域适用 | 近年逐步扩展至长期护理机构，但居家护理领域引入 E-9 护工的法律仍在讨论中 |
| 来源国 | 主要来自东南亚和南亚国家（越南、菲律宾、印尼、尼泊尔等） |

### 5.2 护理领域外籍劳动力现状

| 现状 | 说明 |
|------|------|
| **规模有限** | 外籍护工在韩国 LTC 劳动力中占比仍极低（估计 <3%） |
| **集中在设施** | 外籍护工主要集中在疗养医院和设施机构（시설급여），居家领域（재가급여）罕见 |
| **语言障碍** | 韩国对外籍护工的韩语能力要求（EPS-TOPIK），但实际沟通仍有困难 |
| **法律限制** | E-9 签证持有者的就业范围和工作期限受严格限制（通常最长4年10个月） |
| **政策讨论** | 2024年后持续进行是否将居家护理纳入 E-9 签证放宽范围的讨论 |

### 5.3 与日本的外籍护工政策对比

| 维度 | 韩国 | 日本 |
|------|------|------|
| 主要签证 | E-9（非专业） | 技能实习/特定技能/介護/EPA |
| 护工专属签证 | ❌ 无 | ✅ 介護（2017年创设） |
| 日语/韩语要求 | EPS-TOPIK | JLPT N4-N3 + 介護技能考试 |
| 外国护工占比 | <3% | 约3-5%（介護领域） |
| 长期居留路径 | 有限 | 特定技能2号→可带家属、长期居留 |

> 韩国在外籍护工政策上相对日本更为保守，尚未创设护工专属签证类型。

**来源：韩国法务部出入境政策；相关新闻报道**

## 6. 劳动力相关政策改革

### 6.1 现行政策措施

| 政策 | 内容 |
|------|------|
| **요양보호사 资格制度强化** | 讨论增加培训时长（从240小时提升），引入在职培训和继续教育要求 |
| **薪资补贴** | 部分地方政府对 LTC 机构提供从业人员薪资补贴 |
| **职业发展路径** | 讨论建立疗养保护士→高级保护士→护理管理者的职业阶梯 |
| **工作环境改善** | 推行辅助器械使用（如移位机、沐浴辅助设备），减少职业伤害 |

### 6.2 2026年展望

| 方向 | 预期 |
|------|------|
| **外籍护工扩大** | E-9 签证配额可能扩大，居家护理领域的引入将逐步放宽 |
| **培训改革** | 疗养保护士培训体系可能向日本模式（1,850小时）靠近 |
| **居家医疗人才培养** | 居家医疗中心（재택의료센터）的全国覆盖将催生居家医疗专业人才需求 |
| **薪酬提升压力** | LTCI 给付费用快速增长（+9.3%），部分将传导至从业人员薪资 |

**来源：Ga H. AGMR 2024; Korea Biomedical Review 2026**

## 7. 对 iHomeCare 的劳动力启示

| 韩国经验 | 对香港/iHomeCare 的建议 |
|---------|----------------------|
| 90% 劳动力为240小时培训的疗养保护士 → 照护质量天花板低 | iHomeCare 应确保注册护士在居家医疗团队中的核心地位 |
| 67% 兼职率 → 人员不稳定，服务连续性差 | 香港应确保全职岗位比例，建立合理的编制标准 |
| 居家诊疗医师极度稀缺（0.8%） | iHomeCare 需建立医师从事居家诊疗的激励机制 |
| 个人所有机构占 83.9% → 碎片化、质量监管难题 | 香港可设定较高的机构准入门槛，建立质量分级制度 |
| 外籍护工政策保守 → 劳动力补充有限 | 香港已有菲佣/印佣等外籍照护资源，可探索将其纳入正式居家医疗支持体系 |

**来源：基于韩国劳动力分析的对标建议**
