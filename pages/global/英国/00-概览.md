# 🇬🇧 英国 居家医疗/HaH 市场

## 一、市场概况

英国为 **「NHS 免费医疗 + 经济审查制社会照护」** 双轨。NHS Virtual Ward 是英国版 Hospital at Home 的核心载体，2025 年扩展至 10,000 虚拟床位。

**核心数据**：

| 指标 | 数值 |
|------|------|
| NHS 预算 | ~£1,900 亿（2025-26） |
| Virtual Ward 床位 | ~**10,000**（2025 目标） |
| NHS Continuing Healthcare 受益人 | ~6 万 |
| 社会照护年度支出 | ~£300 亿 |
| 65+ 人口 | **19%**（2025） |
| 居家护理自费比例 | ~**40%** |

## 二、体系架构

```
NHS (免费医疗)
├─ Virtual Ward → 急性居家替代（NHS 全额支付）
├─ District Nursing → 社区护理（伤口/药物/临终）
└─ Continuing Healthcare → 重度医疗需要者全额 LTC

Local Authority (社会照护——经济审查)
├─ 资产 < £23,250 → 地方政府支付部分 LTC
└─ 资产 > £23,250 → 全额自费
```

**关键特征**：NHS 和 Social Care 的**制度割裂**是英国 LTC 的根本问题。一个人在 NHS 下免费获得 Virtual Ward 急性照护，但需要的长期个人照顾落入经济审查制的 Social Care——导致「免费医疗+付费照护」的不公平。

## 三、NHS Virtual Ward

- NHS England 2023 年起大规模扩展
- 服务模式：远程监测（RPM）+ 社区护士上门 + 多学科团队虚拟查房
- 主要供应商：Doccla、Whzan、Clinitouch、Luscii 等（详见03-头部机构）
- 100% 由 NHS 预算覆盖——患者零自付

## 四、核心挑战

1. **NHS-Social Care 割裂**——急性 HaH 免费 vs 长期照护需经济审查
2. 社会照护自费比例高——£15-25/小时 时薪使很多家庭负担不起
3. Virtual Ward 从 10,000 到规模化仍有距离
