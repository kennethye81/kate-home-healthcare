# 英国 — 支付体系

## 一、支付结构

NHS（免费）+ 社会照护（资产审查）+ Better Care Fund。

| 支付通道 | 法律依据 | 自付 |
|---------|------|:---:|
| NHS Continuing Healthcare | NHS Act 2006 | **£0** |
| NHS Funded Nursing Care (FNC) | — | **£0**（£235.88/周·2025） |
| NHS Virtual Ward | NHS England | **£0** |
| District Nursing | — | **£0** |
| Local Authority Social Care | Care Act 2014 | 资产 >£23,250 → 全额自费 |
| Attendance Allowance | 非审查·现金给付 | £73/周（低率）or £109/周（高率） |
| Carer's Allowance | 照护者支持 | £82/周 |
| Better Care Fund | NHS+地方 | — |

## 二、资产审查（2025-26）

| 资产 | 地方承担 |
|:---:|------|
| > **£23,250** | **全额自费** |
| £14,250–23,250 | 部分补贴（£250 资产 = £1/周计入收入） |
| < £14,250 | 地方全额 |

> 自住房产不计入评估（居住期间）——"Care Lottery"的根源。

## 三、费用水平

| 服务 | 市场价格 | 自付示例 |
|------|:---:|------|
| Virtual Ward | £500-900/天 | **£0**（NHS 全额） |
| 居家护理 | £15-25/时 | 资产 >£23,250 → 全额（~40%适用） |
| 护理院 | £800-1,500/周 | 依资产而定 |
| NHS CHC | — | ~6 万人适用 |

## 四、终身上限

Care Act 2014 → £86,000 上限：2020→2023→2025→**2028（新政府承诺）** 延期中。

## 五、NHS England 支付机制与 ICB 委托

2022年7月起，42个 Integrated Care Board（ICB）取代原 CCG 成为 NHS 支付和委托主体：

| 层级 | 职能 | 支付流程 |
|------|------|------|
| **NHS England** | 国家预算分配、支付标准制定 | → 按人口权重向各 ICB 拨款 |
| **ICB** | 委托（commissioning）、合同管理 | → 与 NHS Trust/私立提供者签订合同 |
| **提供者** | 服务交付（NHS Trust/GP/社区护理/私立） | → 按 National Tariff 或 Local Price 结算 |

居家医疗支付通道：
- **CHC**：ICB 直接向护理提供者支付（全额）
- **District Nursing**：NHS Trust 预算内覆盖（社区护理团队）
- **Virtual Ward**：ICB 按床位/人头支付（2024年起试点 Capitation）
- **Better Care Fund**：ICB + 地方政府联合委托

## 六、NHS Continuing Healthcare（CHC）全额资助详解

CHC 是 NHS 居家/护理院场景最高支付级别——**全额 NHS 资助、无资产审查**：

| 要素 | 详情 |
|------|------|
| 资格 | 「Primary Health Need」— DST评估 12领域 |
| 支付范围 | 全额照护费 + 护理院住宿费 + 相关医疗处置 |
| 2024-25 受益人数 | ~60,000人 |
| 人均年費用 | £50,000-100,000（居家）~£40,000-80,000（护理院） |
| 年度总支出 | ~£35-40亿（NHS England） |
| 地区差异 | 获批率从3%（部分地区）到15%（其他地区）—「postcode lottery」 |

> CHC 与 FNC（Funded Nursing Care, £235.88/周）的关键区别：CHC 覆盖全部费用，FNC 仅覆盖护理部分，其余由个人或地方政府承担。

## 七、Personal Health Budget（PHB）

NHS Personal Health Budget 是 CHC 受益人的可选替代方案——个人化预算管理：

| 模式 | 说明 | 适用 |
|------|------|:---:|
| **Direct Payment** | 款项直接拨入个人账户，自行采购 | ~30% PHB 使用者 |
| **Notional Budget** | NHS/ICB 代为管理，与使用者共同决策 | ~50% PHB 使用者 |
| **Third-party** | 独立第三方管理机构代为运作 | ~20% PHB 使用者 |

> PHB 2024-25年覆盖 ~40,000人（含 CHC + 长期健康需求）。优势：灵活选择提供者、可雇佣个人助理（Personal Assistant）；挑战：管理负担、提供者市场不成熟。

## 八、Private Pay 自费市场

约 **40%** 居家护理用户为全额自费（资产 >£23,250）：

| 服务类型 | 价格范围 | 支付方式 |
|------|:---:|------|
| 居家护理（小时制）| £20-35/时 | 直接支付提供者 |
| 住家护理（live-in）| £1,200-2,000/周 | 月结或按周支付 |
| 护理院（residential）| £800-1,500/周 | 含住宿+照护费 |
| 护理院（nursing）| £1,200-2,000/周 | 含住宿+照护+临床护理 |
| 退休社区（retirement village）| £2,000-5,000/月 | 服务费+租金 |

> 自费市场痛點：价格不透明、质量参差不齐、无统一比价平台。约 1/3 自费者在照护末期耗尽资产后转入地方政府资助——即「spend-down」路径。
