# 战略规划

## 愿景目标

**成为全球居家医疗与长护险市场的AI分析师**

## 战略支柱

```
制度理解深化 → 竞争分析精细化 → 定量模型构建 → 跨境洞察输出
```

## 数据来源体系

| 数据源类型 | 具体来源 |
|:---------|:--------|
| 国际组织 | OECD Health Statistics |
| 各国政府 | 各国卫生部门/社保机构官方统计 |
| 企业与市场 | 企业IR报告、行业新闻 |
| 信息流 | RSS订阅、政策动态监测 |

## 路线图

| 阶段 | 重点任务 | 输出物 |
|:----|:--------|:------|
| 第一阶段：制度理解 | 各国居家医疗/长护险制度框架梳理 | 国家专题页 |
| 第二阶段：竞争分析 | 主要市场参与者、竞争格局 | 竞争分析矩阵 |
| 第三阶段：定量模型 | 市场规模测算、支付模型对比 | 量化分析报告 |
| 第四阶段：跨境洞察 | 跨国对比、制度借鉴建议 | 战略建议书 |
