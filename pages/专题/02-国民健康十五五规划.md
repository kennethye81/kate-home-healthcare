# 中国国民健康"十五五"规划

国务院2026年7月14日发布，2026-2030年中国医疗卫生最高级别规划文件。

## 核心条款（居家医疗相关）

| 条款 | 原文要点 | 对HaH影响 |
|:-----|:---------|:----------|
| 居家养老 | "推进社区支持的居家养老，加强健康管理、上门医疗和家庭病床服务" | 🔴🔴🔴 首次列入国家五年规划 |
| 免陪照护 | "二级及以上医院全面推广住院患者免陪照护服务" | 🔴 挤出家属→出院后专业护理需求增 |
| 康复扩容 | 每万人口康复医师0.7人/治疗师1.6人 | 🔴 人才缺口巨大→居家康复是低成本路径 |
| 数智化 | 国家智慧健康检验检查跨省共享平台+AI中试基地 | 🟡 居家RPM基础设施层 |
| 银发消费 | 智慧养老产品+商保与健康管理深度融合 | 🟢 支付端和产品端利好 |

## Kate关键判断

1. "十五五"是居家医疗从"可选项"变为"必选项"的转折点
2. "免陪照护"是隐藏风险——可能加剧护理人力短缺
3. 康复人才目标激进（翻倍）→居家康复是唯一可行路径
4. 对香港投资者的叙事价值极高——最高级别的政策确定性信号
